{{% alert color="primary" %}}
Aspose.Cells for Go erbjuder ett brett utbud av funktioner för att skydda filer och data och ta bort skyddet, i likhet med MS Excel:
{{% /alert %}}

## [**Kryptera och dekryptera Excel-filer**](/cells/sv/go-cpp/encrypt-and-decrypt-excel-files/)
För att hindra andra från att komma åt data i Excel-filer kan du skydda filen med ett lösenord.

## [**Skydda arbetsbok och ta bort skyddet**](/cells/sv/go-cpp/protect-and-unprotect-workbook-structure/)
För att hindra andra användare från att visa dolda kalkylblad, lägga till, flytta, ta bort eller dölja kalkylblad kan du skydda strukturen i din Excel-arbetsbok med ett lösenord.

## [**Skydda kalkylblad och ta bort skyddet**](/cells/sv/go-cpp/protect-and-unprotect-worksheets/)
För att hindra andra användare från att oavsiktligt eller uppsåtligt ändra, flytta eller ta bort data i ett kalkylblad kan du låsa cellerna i ditt Excel-kalkylblad och sedan skydda kalkylbladet med ett lösenord.

## [**Skydda delad arbetsbok och ta bort skyddet**](/cells/sv/go-cpp/password-protect-or-unprotect-the-shared-workbook/)
Skydda den delade arbetsboken och ta bort skyddet.
