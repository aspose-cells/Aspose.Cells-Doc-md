## **Possible Usage Scenarios**
Aspose.Cells allows you to group rows and columns in a worksheet using [Cells.GroupRows()](https://reference.aspose.com/cells/go-cpp/cells/grouprows_int_int_bool/) and [Cells.GroupColumns()](https://reference.aspose.com/cells/go-cpp/cells/groupcolumns_int_int/) methods.

The following sample code shows how to group rows and columns. It groups the rows and columns up to the third level. Please check the [output Excel file](23166998.xlsx) generated with this code.
