## **Find or Search Data**
You can use Aspose.Cells to find or search data in various ways using the following methods.

- [GetEnumerator](https://reference.aspose.com/cells/go-cpp/cells/getenumerator/)
- [GetFormula](https://reference.aspose.com/cells/go-cpp/cell/getformula/)
- [GetType](https://reference.aspose.com/cells/go-cpp/cell/gettype/)
- [GetStringValue](https://reference.aspose.com/cells/go-cpp/cell/getstringvalue_cellvalueformatstrategy/)
- [GetIntValue](https://reference.aspose.com/cells/go-cpp/cell/getintvalue/)
- [GetBoolValue](https://reference.aspose.com/cells/go-cpp/cell/getboolvalue/)
- [GetDateTimeValue](https://reference.aspose.com/cells/go-cpp/cell/getdatetimevalue/)
- [GetDoubleValue](https://reference.aspose.com/cells/go-cpp/cell/getdoublevalue/)
- [GetFloatValue](https://reference.aspose.com/cells/go-cpp/cell/getfloatvalue/)
