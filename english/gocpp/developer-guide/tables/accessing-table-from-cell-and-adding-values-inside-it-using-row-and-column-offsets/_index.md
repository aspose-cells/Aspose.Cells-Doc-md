{{% alert color="primary" %}}  

Normally, you add values inside the Table or List Object using the [**Cell.PutValue()**](https://reference.aspose.com/cells/go-cpp/cell/putvalue_bool/) method. But sometimes, you might need to add values inside the Table or List Object using row and column offsets.  

In order to access a Table or List Object from a cell, use the [**Cell.GetTable()**](https://reference.aspose.com/cells/go-cpp/cell/gettable/) method. To add values inside it using row and column offsets, use the [**ListObject.PutCellValue**](https://reference.aspose.com/cells/go-cpp/listobject/putcellvalue_int_int_object/) method.  

{{% /alert %}}  

The following screenshot shows the source Excel file used in the code. It contains an empty table and highlights cell D5, which lies inside the table. We will access this table from cell D5 using the [**Cell.GetTable()**](https://reference.aspose.com/cells/go-cpp/cell/gettable/) method and then add values inside it using both the [**Cell.PutValue()**](https://reference.aspose.com/cells/go-cpp/cell/putvalue_bool/) and [**ListObject.PutCellValue**](https://reference.aspose.com/cells/go-cpp/listobject/putcellvalue_int_int_object/) methods.
