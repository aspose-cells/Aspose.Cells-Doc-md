{{% alert color="primary" %}}

Please use the [**ImageOrPrintOptions.GetDefaultFont()**](https://reference.aspose.com/cells/go-cpp/imageorprintoptions/getdefaultfont/) property to set the default font while rendering spreadsheets to images. This property will only be effective when the default font of the workbook cannot render the characters. The default font specified with [**ImageOrPrintOptions.GetDefaultFont()**](https://reference.aspose.com/cells/go-cpp/imageorprintoptions/getdefaultfont/) property is used for all those cells which have invalid or non‑existent fonts.

{{% /alert %}}
