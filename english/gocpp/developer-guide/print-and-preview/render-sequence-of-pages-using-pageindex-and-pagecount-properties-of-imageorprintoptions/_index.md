## **Possible Usage Scenarios**

You can render a sequence of pages of your Excel file to images by using Aspose.Cells with [**ImageOrPrintOptions.GetPageIndex()**](https://reference.aspose.com/cells/go-cpp/imageorprintoptions/getpageindex/) and [**ImageOrPrintOptions.GetPageCount()**](https://reference.aspose.com/cells/go-cpp/imageorprintoptions/getpagecount/) properties. These properties are useful when there are many, e.g., thousands of pages in your worksheet, but you want to render only some of them. This will not only save processing time but also reduce memory consumption of the rendering process.
