## **Possible Usage Scenarios**

Sometimes you want to show subtotal and grand total labels in non‑English languages such as Chinese, Japanese, Arabic, Hindi, etc. Aspose.Cells allows you to do this using the [**GlobalizationSettings**](https://reference.aspose.com/cells/go-cpp/globalizationsettings/) class and the [**Workbook.GetGlobalizationSettings()**](https://reference.aspose.com/cells/go-cpp/workbooksettings/getglobalizationsettings/) property. Please see this article on how to use the [**GlobalizationSettings**](https://reference.aspose.com/cells/go-cpp/globalizationsettings/) class:

- [Using GlobalizationSettings Class for Custom Subtotal Labels and Other Labels of Pie Chart](/cells/go-cpp/using-globalizationsettings-class-for-custom-subtotal-labels-and-other-label-of-pie-chart/)
