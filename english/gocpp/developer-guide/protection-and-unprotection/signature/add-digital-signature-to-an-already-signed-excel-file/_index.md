## **Possible Usage Scenarios**

Aspose.Cells provides the [**Workbook::AddDigitalSignature(DigitalSignatureCollectionPtr digitalSignatureCollection)**](https://reference.aspose.com/cells/go-cpp/workbook/adddigitalsignature/) method to add digital signatures to already signed Excel files.

{{% alert color="primary" %}}

Please note that while adding a digital signature to an already signed Excel document, if the original document was generated by Aspose.Cells, it works properly. However, if the document was created by other engines (e.g., Microsoft Excel), Aspose.Cells for Go via C++ cannot preserve the exact file structure after loading and re‑saving, which may invalidate existing signatures.

{{% /alert %}}
