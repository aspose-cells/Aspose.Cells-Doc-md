## **Possible Usage Scenarios**

Sometimes you want to display text in a Far East language font, e.g., Japanese, Chinese, Thai, etc. Aspose.Cells provides [**TextOptions.GetFarEastName()**](https://reference.aspose.com/cells/go-cpp/textoptions/getfareastname/) property that can be used to specify the font name for Far East languages. Besides, you can also specify the Latin font name using [**TextOptions.GetLatinName()**](https://reference.aspose.com/cells/go-cpp/textoptions/getlatinname/) property.
