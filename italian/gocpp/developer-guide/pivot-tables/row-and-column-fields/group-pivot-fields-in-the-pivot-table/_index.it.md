## **Possibili scenari di utilizzo**
Microsoft Excel consente di raggruppare i campi pivot **nella** tabella pivot. Quando esiste una grande quantità di dati correlati a un campo pivot, spesso è utile raggruppare i campi pivot in sezioni. Aspose.Cells offre anche questa funzionalità tramite il metodo [**PivotTable.GroupBy()**](https://reference.aspose.com/cells/go-cpp/pivotfield/groupby_double_bool/).
