## Aggiunta di un campo all'area dati
L'aggiunta di un campo base all'area dati (valori) è il primo passo per definire il modo in cui una tabella pivot aggrega i dati di origine. Aspose.Cells for JavaScript via C++ espone `pivotTable.addFieldToArea(PivotFieldType.Data, "ColumnName")`, un sovraccarico che accetta la costante `PivotFieldType.Data` e il nome della colonna di origine. Una volta aggiunto un campo all'area dati, l'API lo espone tramite la raccolta `pivotTable.getDataFields()`, che restituisce i campi nell'ordine in cui sono stati aggiunti. Per impostazione predefinita, una colonna di origine numerica viene aggregata mediante `ConsolidationFunction.Sum`, mentre per una colonna non numerica la funzione predefinita è `Count`.

        AsposeCells.onReady({

            fontPath: "/fonts/",
            fontList: ["arial.ttf", "NotoSansSC-Regular.ttf"]
        }).then(() => {
            console.log("Aspose.Cells initialized");
        });
        document.getElementById('runExample').addEventListener('click', async () => {

            const worksheet = workbook.worksheets.get(0);
            worksheet.name = "Data";

            for (let j = 0; j < headers.length; j++) {
                worksheet.cells.get(0, j).value = headers[j];
            }
            const data = [
                ["Fruit", "Apple", 2020, 100],
                ["Fruit", "Apple", 2021, 150],
                ["Fruit", "Banana", 2020, 80],
                ["Fruit", "Banana", 2021, 90],
                ["Vegetable", "Carrot", 2020, 50],
                ["Vegetable", "Carrot", 2021, 60],
                ["Vegetable", "Daikon", 2020, 40],
                ["Vegetable", "Daikon", 2021, 45]

            for (let i = 0; i < data.length; i++) {
                for (let j = 0; j < data[i].length; j++) {
                    worksheet.cells.get(i + 1, j).value = data[i][j];
                }

## Modifica della funzione di riepilogo
Una volta presente nell'area dati, un campo viene esposto da Aspose.Cells tramite l'oggetto `PivotField` restituito da `pivotTable.getDataFields()`. Ogni `PivotField` dispone di una proprietà `function` accessibile in scrittura e di tipo `ConsolidationFunction`, che controlla l'aggregato applicato ai valori sottostanti al campo. `ConsolidationFunction` è un'enumerazione i cui membri sono `Sum`, `Count`, `Average`, `Max`, `Min`, `Product`, `StdDev`, `StdDevp`, `Var` e `Varp`: i primi sei coprono la stragrande maggioranza dei casi d'uso reali, mentre gli ultimi quattro sono aggregati statistici utili per l'analisi della varianza.

{{% alert color="primary" %}}
La modifica di `function` influisce solo sull'aggregato; la colonna di origine e la struttura delle righe e delle colonne della tabella pivot non vengono modificate. Per cambiare l'aggregato di un campo dati esistente, chiamare `pivotTable.getDataFields()[i].setFunction(ConsolidationFunction.X)` e quindi `pivotTable.calculateData()` per ricalcolare i dati e aggiornare la visualizzazione della tabella pivot.
{{% /alert %}}

## Posizionamento dei campi valore sugli assi Row o Column
Quando una tabella pivot contiene due o più campi dati, Aspose.Cells espone un ulteriore campo virtuale denominato `pivotTable.getValuesField()`. Questo campo virtuale rappresenta l'aggregato di tutti i campi dati presenti nell'area dati. È possibile trascinarlo nell'area Row o Column come campo base della tabella pivot. Questo permette di disporre più misure affiancate.

{{% alert color="primary" %}}
Il campo virtuale dei valori restituito da `pivotTable.getValuesField()` non è disponibile se non è presente alcun campo valore o se ne è presente soltanto uno.
{{% /alert %}}

```html
<!DOCTYPE html>
<html>
    <head>
        <title>Aspose.Cells Example</title>
    </head>
    <body>
        <h1>Aspose.Cells Example</h1>
        <button id="runExample">Run Example</button>
        <a id="downloadLink" style="display: none;">Download Result</a>
        <div id="result"></div>
    </body>
    <script src="aspose.cells.js.min.js"></script>
    <script type="text/javascript">
        const { Workbook, SaveFormat } = AsposeCells;
        AsposeCells.onReady({
            license: "/lic/aspose.cells.enc",
            fontPath: "/fonts/",
            fontList: ["arial.ttf", "NotoSansSC-Regular.ttf"]
        }).then(() => {
            console.log("Aspose.Cells initialized");
        });
        document.getElementById('runExample').addEventListener('click', async () => {
            const workbook = new Workbook();
            const worksheet = workbook.worksheets.get(0);
            worksheet.name = "Data";
            const cells = worksheet.cells;
            const headers = ["Category", "Item", "Year", "Amount"];
            for (let j = 0; j < headers.length; j++) {
                cells.get(0, j).value = headers[j];
            }
            const data = [
                ["Fruit", "Apple", 2020, 100],
                ["Fruit", "Apple", 2021, 150],
                ["Fruit", "Banana", 2020, 80],
                ["Fruit", "Banana", 2021, 90],
                ["Vegetable", "Carrot", 2020, 50],
                ["Vegetable", "Carrot", 2021, 60],
                ["Vegetable", "Daikon", 2020, 40],
                ["Vegetable", "Daikon", 2021, 45]
            ];
            for (let i = 0; i < data.length; i++) {
                for (let j = 0; j < data[i].length; j++) {
                    cells.get(i + 1, j).value = data[i][j];
                }
            }
            const pivotTable = worksheet.pivotTables.add("=A1:D9", 2, 5);
            pivotTable.addFieldToArea(AsposeCells.PivotFieldType.Row, "Category");
            pivotTable.addFieldToArea(AsposeCells.PivotFieldType.Row, "Item");
            pivotTable.addFieldToArea(AsposeCells.PivotFieldType.Column, "Year");
            pivotTable.addFieldToArea(AsposeCells.PivotFieldType.Data, "Amount");
            pivotTable.addFieldToArea(AsposeCells.PivotFieldType.Data, "Amount");
            pivotTable.dataFields.get(1).function = AsposeCells.ConsolidationFunction.Count;
            pivotTable.addFieldToArea(AsposeCells.PivotFieldType.Column, pivotTable.valuesField.name);
            pivotTable.calculateData();
            const outputData = workbook.save(SaveFormat.Xlsx);
            const blob = new Blob([outputData], {
                type: "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet"
            });
            const downloadLink = document.getElementById('downloadLink');
            downloadLink.href = URL.createObjectURL(blob);
            downloadLink.download = "output_plot.xlsx";
            downloadLink.style.display = "block";
            document.getElementById('result').innerHTML = '<p style="color: green;">Done! Click the download link to get the result file.</p>';
        });
    </script>
</html>
```
