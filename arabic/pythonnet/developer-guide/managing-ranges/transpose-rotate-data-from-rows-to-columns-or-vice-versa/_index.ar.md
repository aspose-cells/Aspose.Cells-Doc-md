## **الأسلوب 1 — تبديل النطاق في موضعه (range.transpose)**
استخدم هذا الأسلوب عندما تريد تبديل البيانات دون استخدام دالة ورقة العمل `TRANSPOSE`. يعمل مع **جميع إصدارات Excel** ولا يعتمد على المصفوفات الديناميكية، مما يجعله الخيار الأكثر أمانًا لضمان التوافق بين الإصدارات. وهو مثالي عندما تحتاج فقط إلى مخرجات التبديل النهائية ولا تحتاج إلى الاحتفاظ بصيغة `TRANSPOSE` الأصلية في المصنف.

### **واجهة API المستخدمة**
`range.transpose()` هي طريقة خاصة بكائنات الفئة `Aspose.Cells.Range`. وعند استدعائها، ينقلب النطاق في موضعه عبر تبديل صفوفه وأعمدته، بحيث يصبح ما كان صفًا عمودًا وما كان عمودًا صفًا. تعدل الطريقة الخلايا الفعلية مباشرةً دون كتابة أي صيغة.

### **الخطوات**
1. افتح مصنف المصدر باستخدام `LoadOptions` المضبوط على تنسيق `.xlsx`، عن طريق استدعاء `Workbook(srcFile, LoadOptions(LoadFormat.XLSX))`.
2. استرجع ورقة العمل الأولى من المصنف باستخدام `workbook.worksheets[0]`.
3. الوصول إلى مجموعة خلايا ورقة العمل من خلال `worksheet.cells`.
4. أنشئ نطاق المصدر الذي يغطي **A1:D5** عن طريق استدعاء `cells.create_range("A1:D5")`.
5. استدعِ `source.transpose()` لتدوير النطاق في موضعه وتبديل الصفوف والأعمدة.
6. احفظ المصنف باستخدام `workbook.save(outputFile)`.
بعد التبديل، يحمل نطاق الإرساء الأولي البيانات بعد تدويرها. وتكون قيم الصف الأول (فارغ، **أوروبا**، **آسيا**، **أمريكا الشمالية**)، فيما تكون قيم العمود الأول (فارغ، **الربع 1**، **الربع 2**، **الربع 3**، **الربع 4**). ويصبح كل عمود من أعمدة بيانات المبيعات الأصلي صفًا في النطاق المبدل.

```python
import aspose.cells as ac
srcFile = "source.xlsx"
outputFile = "transposed.xlsx"
workbook = ac.Workbook(srcFile, ac.LoadOptions(ac.LoadFormat.XLSX))
worksheet = workbook.worksheets[0]
cells = worksheet.cells
source = cells.create_range("A1:D5")
source.transpose()
workbook.save(outputFile)
```

## **الأسلوب 2 — التبديل باستخدام صيغة الصفيف الديناميكي (Excel 365 / 2021)**
استخدم هذا الأسلوب إذا أردت الإبقاء على صيغة `=TRANSPOSE(A1:D5)` كصيغة نشطة في مصنف الإخراج، بحيث تتحدث النتيجة تلقائيًا عند تغيير بيانات المصدر، مع فتح ملف Excel الهدف في **Excel 365 / Excel 2021 أو أحدث**، وهي إصدارات تدعم المصفوفات الديناميكية وعامل الامتداد.

### **واجهة API المستخدمة**
`cell.set_dynamic_array_formula(formula, options, calculate_value)` هي طريقة في `Aspose.Cells.Cell` تضبط صيغة الخلية بوصفها **صيغة صفيف ديناميكي**. يقيّم Excel الصيغة مرة واحدة، ثم تمتد النتيجة تلقائيًا إلى الخلايا المجاورة. المعامل الثالث، عند تعيينه إلى `True`، يطلب من Aspose.Cells حساب القيم الناتجة أيضًا عند وقت الكتابة.

### **الخطوات**
1. حمّل مصنف المصدر باستخدام `Workbook(srcFile, LoadOptions(LoadFormat.XLSX))`.
2. استرجع ورقة العمل الأولى، ثم الوصول إلى مجموعة `cells` الخاصة بها.
3. ضع صيغة الصفيف الديناميكي في الخلية **A6**، أسفل نطاق المصدر مباشرةً، عن طريق استدعاء `cells["A6"].set_dynamic_array_formula("=TRANSPOSE(A1:D5)", None, True)`.
4. يمرر الوسيط `None` خيارات `FormulaParseOptions` الافتراضية، ويطلب الوسيط الثالث `True` من Aspose.Cells التعامل مع الصيغة على أنها مصفوفة ديناميكية وتقييمها، بحيث تُكتب القيم الناتجة الممتدة في المصنف.
5. احفظ المصنف باستخدام `workbook.save(outputFile)`.
تحتوي الخلية **A6** على الصيغة `=TRANSPOSE(A1:D5)`، ويقوم Excel بتمديد النتيجة تلقائيًا إلى النطاق **A6:D10**، وهي كتلة من 5 صفوف و4 أعمدة تطابق البيانات المبدلة.

{{% alert color="primary" %}}
هذا الأسلوب متوافق **فقط مع Excel 365 / 2021 أو أحدث**. لا تمدد إصدارات Excel الأقدم صيغ المصفوفات الديناميكية على نحو صحيح.
{{% /alert %}}

```python
import aspose.cells as ac
srcFile = "source.xlsx"
outFile = "output_transpose_dynamic.xlsx"
workbook = ac.Workbook(srcFile, ac.LoadOptions(ac.LoadFormat.XLSX))
worksheet = workbook.worksheets[0]
cells = worksheet.cells
cells.get("A6").set_dynamic_array_formula("=TRANSPOSE(A1:D5)", ac.FormulaParseOptions(), True)
workbook.save(outFile, ac.SaveFormat.XLSX)
```

## **الأسلوب 3 — التبديل باستخدام صيغة الصفيف الكلاسيكية (CSE)**
استخدم هذا الأسلوب إذا أردت الإبقاء على صيغة `TRANSPOSE` في المصنف، وكان من المحتمل فتح ملف Excel الهدف في **إصدارات Excel الأقدم (قبل 2021، ومنها 2019 و2016 و2013 وغيرها)**، حيث لا تُدعم آلية امتداد المصفوفات الديناميكية. وتُعد صيغة الصفيف الكلاسيكية (CSE) التي تُدخل عبر Ctrl+Shift+Enter البديل المتوافق مع الإصدارات الأقدم، والتي يمكن لجميع إصدارات Excel تقييمها.

### **واجهة API المستخدمة**
`cell.set_array_formula(array_formula, n_rows, n_columns)` هي طريقة في `Aspose.Cells.Cell` تعين **صيغة صفيف كلاسيكية (CSE)** على خلية الإرساء وتحدد أبعاد الصفيف الناتج. يكتب Aspose.Cells علامة صيغة المصفوفة متعددة الخلايا، بحيث يتعامل Excel مع الصيغة على أنها تعبير مصفوفة واحد يملأ النطاق المحدد.

### **الخطوات**
1. حمّل مصنف المصدر كما هو موضح في الأساليب السابقة.
2. استرجع ورقة العمل الأولى، ثم الوصول إلى مجموعة `cells` الخاصة بها.
3. استدعِ `cells["A6"].set_array_formula("=TRANSPOSE(A1:D5)", 4, 5)`. الوسيط الثاني `4` هو عدد صفوف صفيف الوجهة، والوسيطة الثالثة `5` هي عدد أعمدته.
4. احفظ المصنف باستخدام `workbook.save(outputFile)`.
تعد الخلية **A6** خلية الإرساء لصيغة المصفوفة، وتمتد المصفوفة المُقيَّمة عبر 4 صفوف و5 أعمدة بدءًا من A6، بما يطابق أبعاد النطاق المصدر A1:D5 بعد التبديل. ويكتب Excel علامة صيغة مصفوفة واحدة عبر النطاق الناتج، بحيث تقيّمها إصدارات Excel الأقدم على نحو صحيح.

{{% alert color="primary" %}}
صيغ المصفوفات من نوع CSE هي الطريقة الكلاسيكية في Excel لتقييم تعبير `TRANSPOSE`، وهذا الأسلوب متوافق مع جميع إصدارات Excel.
{{% /alert %}}

```python
import aspose.cells as ac
# تحميل مصنف المصدر باستخدام xlsx LoadOptions
srcFile = "source.xlsx"
workbook = ac.Workbook(srcFile, ac.LoadOptions(ac.LoadFormat.XLSX))
# الوصول إلى ورقة العمل الأولى ومجموعة Cells الخاصة بها
worksheet = workbook.worksheets[0]
cells = worksheet.cells
# تعيين صيغة المصفوفة الكلاسيكية CSE في الخلية A6.
# تنقل الصيغة =TRANSPOSE(A1:D5) نطاق المصدر المكون من 5 صفوف و4 أعمدة
# إلى مصفوفة مكونة من 4 صفوف و5 أعمدة. الوسيط الثاني (4) يمثل عدد الصفوف،
# بينما يمثل الوسيط الثالث (5) عدد أعمدة المصفوفة الناتجة.
# يكتب Aspose.Cells علامة صيغة المصفوفة CSE، بحيث يقوم Excel بحسابها
# ك صيغة مصفوفة واحدة تشمل خلايا متعددة، بما يتوافق مع إصدارات Excel الأقدم
# (2019 و2016 و2013 وغيرها) التي لا تدعم الت spilling الديناميكي للمصفوفات.
cells.get("A6").set_array_formula("=TRANSPOSE(A1:D5)", 4, 5)
# حفظ المصنف حتى يتم сохраظ علامة صيغة المصفوفة
workbook.save("output.xlsx")
```
