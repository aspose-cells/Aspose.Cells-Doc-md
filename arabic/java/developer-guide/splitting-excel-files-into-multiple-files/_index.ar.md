{{% alert color="primary" %}}

Aspose.Cells تدعم تقسيم ملف Excel واحد إلى ملفات متعددة. هناك طريقتان أساسيتان للقيام بذلك: (1) عن طريق نسخ كل ورقة عمل من المصنف المصدر إلى مصنف جديد وحفظ كل منها كملف منفصل، و(2) عن طريق نسخ نطاق خلايا محدد من ورقة عمل إلى مصنف جديد. كلتا الطريقتين مفيدتان عندما تحتاج إلى توزيع مجموعات فرعية من البيانات، أو إنشاء تقارير أصغر لمستلمين مختلفين، أو عزل البيانات للمعالجة الفردية.

{{% /alert %}}

## **المقدمة**

هناك العديد من السيناريوهات الواقعية التي يحتاج فيها المطور إلى تقسيم ملف Excel واحد إلى عدة ملفات أصغر. على سبيل المثال، قد يحتوي المصنف على ورقة عمل واحدة لكل قسم، ويحتاج كل رئيس قسم إلى تلقي ورقته فقط. في حالات أخرى، قد ترغب في استخراج جدول أو كتلة بيانات معينة من ورقة عمل وإرسالها كملف مستقل عبر البريد الإلكتروني، دون الكشف عن بقية المصنف. قد تحتاج المصنفات الكبيرة المدمجة أيضًا إلى تقسيمها إلى أجزاء أصغر لسهولة التعامل، أو تحميل أسرع، أو المعالجة اللاحقة بواسطة أنظمة أخرى.

يوفر Aspose.Cells طريقتين مرنتين لهذه المهمة. تتكرر الطريقة الأولى عبر كل ورقة عمل في المصنف المصدر وتنسخ محتواها إلى نسخة `Workbook` جديدة تمامًا، وتحفظ كل منها كملف منفصل. تركز الطريقة الثانية على نطاق خلايا محدد داخل ورقة عمل وتنقل هذا النطاق فقط إلى مصنف جديد. في كلتا الحالتين، يكون التدفق العام هو نفسه: تحميل المصنف المصدر باستخدام فئة `Workbook`، والوصول إلى البيانات ذات الصلة من خلال كائنات `Worksheet` و`Cells`، ونقل المحتوى إلى `Workbook` الوجهة، ثم حفظ الوجهة على القرص.

## **تقسيم ملف Excel عن طريق نسخ كل ورقة عمل إلى مصنف جديد**

### **نظرة عامة على الطريقة**

في هذه الطريقة، يتم فتح المصنف المصدر مرة واحدة، ثم لكل `Worksheet` في مجموعته `Worksheets`، يتم إنشاء `Workbook` وجهة جديدة. ثم يتم نسخ محتوى ورقة العمل المصدرية إلى ورقة العمل الأولى في المصنف الوجهة، ويتم حفظ المصنف الوجهة كملف مشتق اسمه من اسم ورقة العمل المصدرية. النتيجة هي ملف إخراج واحد لكل ورقة عمل، حيث يحتوي كل ملف إخراج على بيانات ورقة مصدر واحدة.

هذه الطريقة هي الخيار الصحيح عندما تمثل كل ورقة عمل في المصنف المصدر وحدة معلومات مستقلة منطقيًا (مثل قسم، منطقة، شهر، أو خط إنتاج) وتريد تسليم أو معالجة كل وحدة بشكل مستقل.

### **الخطوات**

تصف الخطوات التالية كيفية تقسيم ملف Excel عن طريق نسخ كل ورقة عمل إلى مصنف جديد:

1. افتح ملف Excel المصدر عن طريق إنشاء كائن `Workbook` وتمرير مسار الملف إلى المنشئ الخاص به.
2. تكرار عبر مجموعة `Workbook.Worksheets` باستخدام حلقة `for` أو `foreach` بحيث تتم معالجة كل `Worksheet` في الملف المصدر.
3. داخل الحلقة، أنشئ نسخة `Workbook` وجهة جديدة (مصنف فارغ) لورقة العمل الحالية.
4. أضف `Worksheet` جديدة إلى المصنف الوجهة (أو استخدم ورقة العمل الأولى الافتراضية) وقم بتعيين اسم ذو معنى لها، ويفضل أن يكون نفس خاصية `Name` لورقة العمل المصدرية.
5. انسخ محتوى ورقة العمل المصدرية إلى ورقة العمل الوجهة. يمكن القيام بذلك عن طريق التكرار عبر خلايا مجموعة `Cells` الخاصة بورقة العمل المصدرية وكتابة قيمها في الخلايا المقابلة في ورقة العمل الوجهة، أو باستخدام طريقة `Cells.copy` لنقل نطاق كامل دفعة واحدة.
6. أنشئ مسار ملف إخراج يتضمن اسم ورقة العمل المصدرية (على سبيل المثال، `dataDir + worksheet.getName() + ".xls"`) بحيث يكون لكل ملف مُنشأ اسم فريد.
7. استدعِ طريقة `Workbook.save` للوجهة لكتابة الملف على القرص.
8. كرر الخطوات من 3 إلى 7 لورقة العمل التالية حتى تتم معالجة جميع أوراق العمل.

### **مثال على الكود**

```java
import com.aspose.cells.*;

String dataDir = "data/";
Workbook workbook = new Workbook(dataDir + "book1.xls");

for (int i = 0; i < workbook.getWorksheets().getCount(); i++)
{
    Worksheet sourceSheet = workbook.getWorksheets().get(i);
    String sheetName = sourceSheet.getName();
    
    Workbook destWorkbook = new Workbook();
    int destIndex = destWorkbook.getWorksheets().add();
    Worksheet destSheet = destWorkbook.getWorksheets().get(destIndex);
    destSheet.setName(sheetName);
    
    destSheet.copy(sourceSheet);
    
    String destFile = dataDir + sheetName + ".xls";
    destWorkbook.save(destFile, SaveFormat.EXCEL_97_TO_2003);
}
```

الناتج المتوقع هو مجموعة من الملفات الجديدة في دليل البيانات، ملف واحد لكل ورقة عمل من المصنف المصدر. كل ملف مسمى على اسم الورقة المصدرية المقابلة له، ويحتوي الملف على البيانات (واختياريًا التنسيق) لتلك الورقة الواحدة.

## **تقسيم ملف Excel عن طريق نسخ نطاق إلى مصنف جديد**

### **نظرة عامة على الطريقة**

في بعض الأحيان، لا تتوافق البيانات التي تحتاج إلى تقسيمها مع ورقة عمل بأكملها، بل مع منطقة مستطيلة محددة من ورقة عمل، مثل `A1:D10` أو نطاق مسمى يمثل جدولًا معينًا. في هذه الحالات، يكون نسخ أوراق العمل بأكملها مضيعة، وتكون هناك حاجة إلى طريقة أكثر دقة: تحديد النطاق المصدر، ونسخ هذا النطاق فقط إلى مصنف جديد، وحفظ الملف الجديد.

هذه الطريقة مثالية عندما تريد استخراج جدول واحد، أو كتلة تقرير، أو منطقة بيانات من ورقة عمل أكبر مع تجاهل كل المحتوى غير المرتبط. وهي مفيدة أيضًا لتصدير مناطق محددة من قبل المستخدم من ورقة كملفات مستقلة.

### **الخطوات**

تصف الخطوات التالية كيفية تقسيم ملف Excel عن طريق نسخ نطاق محدد إلى مصنف جديد:

1. افتح ملف Excel المصدر عن طريق إنشاء كائن `Workbook` بمسار الملف.
2. استرجع `Worksheet` الهدف التي تحتوي على النطاق الذي تريد نسخه، إما عن طريق الفهرس (على سبيل المثال، الورقة الأولى) أو بالاسم من مجموعة `Worksheets`.
3. حدد النطاق المراد نسخه. يمكن أن يكون نطاق خلايا مشفرًا مثل `A1:C10`، أو نطاق مسمى تم الحصول عليه من خلال مجموعة `Worksheet.Cells`، أو نطاق تم إنشاؤه عبر `Worksheet.Cells.createRange`.
4. أنشئ نسخة `Workbook` وجهة جديدة.
5. الوصول إلى أول `Worksheet` في المصنف الوجهة (الورقة الافتراضية).
6. انسخ النطاق المصدر إلى ورقة العمل الوجهة، عادةً بدءًا من الخلية `A1`. يمكن استخدام طريقة `Cells.copy` على مجموعة `Cells` الوجهة لنسخ نطاق كامل، أو يمكنك التكرار عبر خلايا النطاق المصدر وكتابة قيمها في خلايا الوجهة باستخدام `putValue`. يمكن توفير `CopyOptions` اختيارية للتحكم في ما يتم نقله (القيم فقط، القيم والأنماط، الصيغ، وما إلى ذلك).
7. احفظ المصنف الوجهة إلى مسار ملف جديد على القرص باستخدام طريقة `Workbook.save`.

### **مثال على الكود**

```java
import com.aspose.cells.*;

// تحديد مسار البيانات ومسارات الملفات
String dataDir = "data/";
String sourcePath = dataDir + "book1.xls";
String outputPath = dataDir + "outputrange.xls";

// فتح ملف Excel المصدر
Workbook sourceWorkbook = new Workbook(sourcePath);

// الحصول على ورقة العمل الأولى من مصنف المصدر
Worksheet sourceWorksheet = sourceWorkbook.getWorksheets().get(0);

// تحديد نطاق الخلايا المصدر A1:C10 (10 صفوف، 3 أعمدة تبدأ من الصف 0، العمود 0)
Range sourceRange = sourceWorksheet.getCells().createRange(0, 0, 10, 3);

// إنشاء مصنف وجهة جديد
Workbook destWorkbook = new Workbook();

// الوصول إلى ورقة العمل الأولى في مصنف الوجهة
Worksheet destWorksheet = destWorkbook.getWorksheets().get(0);

// إنشاء نطاق الوجهة في A1 بنفس أبعاد النطاق المصدر
Range destRange = destWorksheet.getCells().createRange(0, 0, 10, 3);

// نسخ النطاق المصدر إلى نطاق الوجهة
destRange.copy(sourceRange);

// حفظ مصنف الوجهة في ملف .xls جديد
destWorkbook.save(outputPath, SaveFormat.EXCEL_97_TO_2003);
```

الناتج المتوقع هو ملف جديد واحد في دليل البيانات يحتوي فقط على القيم (واختياريًا التنسيق) للنطاق المحدد المستخرج من المصنف المصدر. ملف الوجهة لا تربطه أي علاقة بأي بيانات أخرى في الملف المصدر؛ فهو يحتوي فقط على النطاق المستخرج، بدءًا من الخلية `A1` في ورقة العمل الأولى الخاصة به.
