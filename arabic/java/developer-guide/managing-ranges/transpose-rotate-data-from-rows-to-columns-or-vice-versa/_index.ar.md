يدعم Aspose.Cells for Java تبديل (تدوير) البيانات بحيث تصبح الصفوف أعمدة والأعمدة صفوفًا بثلاث طرق مختلفة. يستخدم الأسلوب الأول طريقة `Range.transpose()` لتبديل النطاق في مكانه، ويعمل مع جميع إصدارات Excel، بينما يستخدم الأسلوب الثاني `Cell.setDynamicArrayFormula()` لكتابة صيغة مصفوفة ديناميكية حديثة `=TRANSPOSE(...)` تمتد نتيجتها تلقائيًا في Excel 365 أو Excel 2021. ويستخدم الأسلوب الثالث `Cell.setArrayFormula()` لكتابة صيغة مصفوفة كلاسيكية تُدخل باستخدام Ctrl+Shift+Enter (CSE) ومتوافقة مع إصدارات Excel الأقدم. تشرح هذه المقالة كل أسلوب مع تعليمات خطوة بخطوة وأمثلة كود كاملة.

## **مقدمة**
يعني تبديل النطاق تدويره بحيث يتحول ما كان صفًا إلى عمود وما كان عمودًا إلى صف، أي انعكاس للبيانات عبر قطره الرئيسي. في Microsoft Excel، تنفذ دالة ورقة العمل `TRANSPOSE` هذه العملية، والمرجع المفاهيمي لها موثق في [https://support.microsoft.com/en-us/excel/functions/transpose-function](https://support.microsoft.com/en-us/excel/functions/transpose-function). ويمكن تطبيق هذا المفهوم برمجيًا على نطاق من الخلايا، وهو أمر مفيد في keepers من سيناريوهات الأعمال والتقارير.
- إعادة توجيه تقارير المبيعات الفصلية أو السنوية التي تُعرض فيها أرباع السنة أفقيًا عبر الصفحة والمناطق عموديًا على الصفحة، أو العكس.
- تبديل اتجاه المحاور في لوحات المعلومات أو الرسوم البيانية بحيث تمتد السلاسل الزمنية عموديًا على الصفحة بدلًا من امتدادها أفقيًا.
- إعادة تشكيل البيانات المستوردة من الأنظمة الخارجية لتتوافق مع التخطيط الذي تتوقعه أدوات التحليل أو قوالب التقارير المستهدفة.
لتوضيح بقية المقالة، يستخدم كل مثال جدول المبيعات الصغير التالي، المقسم حسب المنطقة والربع. يشغل هذا الجدول في مصنف العينة النطاق **A1:D5**، مع ترك **A1** فارغة كالركن العلوي الأيسر، وتحتوي **B1:D1** على عناوين المناطق، بينما تحتوي **A2:A5** على عناوين أرباع المبيعات.

## **الأسلوب 1 — تبديل النطاق في مكانه (Range.transpose)**
استخدم هذا الأسلوب كلما أردت تبديل البيانات دون الاستعانة بدالة ورقة العمل `TRANSPOSE`. يعمل مع **جميع إصدارات Excel** ولا يعتمد على المصفوفات الديناميكية، مما يجعله الخيار الأكثر أمانًا من حيث التوافق بين الإصدارات. وهو مثالي عندما تحتاج فقط إلى الناتج المبدّل النهائي ولا تحتاج إلى الإبقاء على صيغة `TRANSPOSE` الأصلية في المصنف.

### **API المستخدمة**
تمثل `Range.transpose()` أسلوبًا على مستوى مثيل الصنف `com.aspose.cells.Range`. ويؤدي استدعاؤها إلى قلب النطاق في مكانه عبر تبديل صفوفه وأعمدته، بحيث يصبح الصف عمودًا والعمود صفًا. يعدّل الأسلوب خلايا النطاق مباشرةً من دون كتابة أي صيغة.

### **الخطوات**
1. افتح مصنف المصدر بتنسيق `.xlsx` باستخدام `LoadOptions` من خلال استدعاء `new Workbook(srcFile, new LoadOptions(LoadFormat.Xlsx))`.
2. استرجع ورقة العمل الأولى من المصنف باستخدام `workbook.getWorksheets().get(0)`.
3. الوصول إلى مجموعة خلايا ورقة العمل عبر `worksheet.getCells()`.
4. أنشئ نطاق المصدر الذي يغطي **A1:D5** من خلال استدعاء `cells.createRange("A1:D5")`.
5. استدعِ `source.transpose()` لتبديل النطاق في مكانه، مع تبديل الصفوف والأعمدة.
6. احفظ المصنف باستخدام `workbook.save(outputFile)`.
بعد التبديل، يحتوي النطاق المثبَّت الأولي على البيانات المبدلة. يعرض الصف الأول القيم (فارغ، **أوروبا**، **آسيا**، **أمريكا الشمالية**)، ويعرض العمود الأول القيم (فارغ، **الربع 1**، **الربع 2**، **الربع 3**، **الربع 4**). يتحول كل عمود أصلي من بيانات المبيعات إلى صف في النطاق المبدّل.

```java
import com.aspose.cells.*;
String srcFile = "source.xlsx";
String outputFile = "transposed.xlsx";
Workbook workbook = new Workbook(srcFile, new LoadOptions(LoadFormat.XLSX));
Worksheet worksheet = workbook.getWorksheets().get(0);
Cells cells = worksheet.getCells();
Range source = cells.createRange("A1:D5");
source.transpose();
workbook.save(outputFile);
```

## **الأسلوب 2 — التبديل باستخدام صيغة مصفوفة ديناميكية (Excel 365 / 2021)**
استخدم هذا الأسلوب عندما تريد الاحتفاظ بصيغة `=TRANSPOSE(A1:D5)` بوصفها صيغة نشطة في مصنف الناتج، بحيث تتحدث النتيجة تلقائيًا إذا تغيّرت بيانات المصدر، وكان ملف Excel الهدف سيُفتح في **Excel 365 / Excel 2021 أو إصدار أحدث** حيث تكون المصفوفات الديناميكية وعامل التمدد مدعومين.

### **API المستخدمة**
تمثل `Cell.setDynamicArrayFormula(String formula, FormulaParseOptions options, boolean calculateValue)` أسلوبًا في `com.aspose.cells.Cell` يضبط صيغة الخلية بوصفها **صيغة مصفوفة ديناميكية**. يقيّم Excel الصيغة مرة واحدة ويمدّد نتيجتها تلقائيًا إلى الخلايا المحيطة. وعندما يُضبط المعامل الثالث على `true`، يوجّه Aspose.Cells إلى حساب القيم الناتجة أيضًا أثناء الكتابة.

### **الخطوات**
1. حمّل مصنف المصدر باستخدام `new Workbook(srcFile, new LoadOptions(LoadFormat.Xlsx))`.
2. استرجع ورقة العمل الأولى، ثم انتقل إلى مجموعة `Cells` الخاصة بها.
3. ضع صيغة المصفوفة الديناميكية في الخلية **A6**، مباشرةً أسفل نطاق المصدر، من خلال استدعاء `cells.get("A6").setDynamicArrayFormula("=TRANSPOSE(A1:D5)", null, true)`.
4. يمرر الوسيط `null` خيارات `FormulaParseOptions` الافتراضية، ويطلب المعامل الثالث `true` من Aspose.Cells معالجة الصيغة كمصفوفة ديناميكية وتقييمها بحيث تُكتب القيم الممتدة إلى المصنف.
5. احفظ المصنف باستخدام `workbook.save(outputFile)`.
تحتوي الخلية **A6** على الصيغة `=TRANSPOSE(A1:D5)`، ويمدّد Excel النتيجة تلقائيًا إلى المنطقة **A6:D10**، وهي كتلة من 5 صفوف × 4 أعمدة تساوي البيانات المبدلة.

{{% alert color="primary" %}}
لا يعمل هذا الأسلوب إلا مع Excel 365 / 2021 أو الإصدارات الأحدث. لن تمتد الصيغ الديناميكية بصورة صحيحة في إصدارات Excel الأقدم.
{{% /alert %}}

```java
import com.aspose.cells.*;
String srcFile = "source.xlsx";
String outFile = "output_transpose_dynamic.xlsx";
Workbook workbook = new Workbook(srcFile, new LoadOptions(LoadFormat.XLSX));
Worksheet worksheet = workbook.getWorksheets().get(0);
Cells cells = worksheet.getCells();
cells.get("A6").setDynamicArrayFormula("=TRANSPOSE(A1:D5)", new FormulaParseOptions(), true);
workbook.save(outFile, SaveFormat.XLSX);
```

## **الأسلوب 3 — التبديل باستخدام صيغة مصفوفة كلاسيكية (CSE)**
استخدم هذا الأسلوب عندما تريد الاحتفاظ بصيغة `TRANSPOSE` في المصنف، لكن قد يُفتح ملف Excel الهدف في **إصدارات Excel الأقدم (ما قبل 2021، بما في ذلك 2019 و2016 و2013 وما إلى ذلك)** حيث لا يكون التمدد الديناميكي للمصفوفات مدعومًا. وتُعد صيغة المصفوفة الكلاسيكية CSE (Ctrl+Shift+Enter) بديلًا متوافقًا مع الإصدارات القديمة، يمكن لجميع إصدارات Excel تقييمه.

### **API المستخدمة**
تمثل `Cell.setArrayFormula(String arrayFormula, int nRows, int nColumns)` أسلوبًا في `com.aspose.cells.Cell` يعين **صيغة مصفوفة كلاسيكية (CSE)** على خلية الارتساء ويحدد أبعاد المصفوفة الناتجة. تكتب Aspose.Cells علامة صيغة المصفوفة متعددة الخلايا، بحيث يقيّم Excel الصيغة كتعبير مصفوفة واحد يملأ النطاق المحدد.

### **الخطوات**
1. حمّل مصنف المصدر كما هو موضح في الأسلوبين السابقين.
2. استرجع ورقة العمل الأولى، ثم انتقل إلى مجموعة `Cells` الخاصة بها.
3. قم باستدعاء `cells.get("A6").setArrayFormula("=TRANSPOSE(A1:D5)", 4, 5)`. المعامل الثاني `4` هو عدد صفوف مصفوفة الوجهة، والمعامل الثالث `5` هو عدد الأعمدة.
4. احفظ المصنف باستخدام `workbook.save(outputFile)`.
الخلية **A6** هي خلية الارتساء لصيغة المصفوفة، وتمتد المصفوفة المقيَّمة عبر 4 صفوف × 5 أعمدة بدءًا من A6، بما يتوافق مع أبعاد النطاق A1:D5 بعد تبديله. يكتب Excel علامة صيغة مصفوفة واحدة عبر النطاق الناتج، بحيث تقيّمها إصدارات Excel الأقدم بصورة صحيحة.

{{% alert color="primary" %}}
صيغ مصفوفات CSE هي طريقة Excel الكلاسيكية لتقييم تعبير `TRANSPOSE`، وهذا الأسلوب متوافق مع جميع إصدارات Excel.
{{% /alert %}}

```java
import com.aspose.cells.*;
// تحميل مصنف المصدر باستخدام LoadOptions بصيغة xlsx
String srcFile = "source.xlsx";
Workbook workbook = new Workbook(srcFile, new LoadOptions(LoadFormat.XLSX));
// الوصول إلى ورقة العمل الأولى ومجموعة Cells الخاصة بها
Worksheet worksheet = workbook.getWorksheets().get(0);
Cells cells = worksheet.getCells();
// تعيين صيغة مصفوفة CSE الكلاسيكية على الخلية A6.
// تعمل الصيغة =TRANSPOSE(A1:D5) على تدوير نطاق المصدر المكوّن من 5 صفوف و4 أعمدة
// إلى مصفوفة من 4 صفوف و5 أعمدة. الوسيط الثاني (4) هو عدد الصفوف
// والوسيط الثالث (5) هو عدد أعمدة المصفوفة الناتجة.
// يكتب Aspose.Cells علامة صيغة المصفوفة CSE، بحيث يقيّمها Excel
// كصيغة مصفوفة واحدة متعددة الخلايا، متوافق مع إصدارات Excel الأقدم
// (2019، 2016، 2013، وما إلى ذلك) التي لا تدعم صبّ المصفوفات الديناميكية.
cells.get("A6").setArrayFormula("=TRANSPOSE(A1:D5)", 4, 5);
// حفظ المصنف حتى تُخزَّن علامة صيغة المصفوفة
workbook.save("output.xlsx");
```
