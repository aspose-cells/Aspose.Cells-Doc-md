{{% alert color="primary" %}}

Aspose.Cells تدعم تقسيم ملف Excel واحد إلى ملفات متعددة. توجد طريقتان رئيسيتان للقيام بذلك: (1) عن طريق نسخ كل ورقة عمل من المصنف المصدر إلى مصنف جديد وحفظ كل منها كملف منفصل، و(2) عن طريق نسخ نطاق خلايا محدد من ورقة عمل إلى مصنف جديد. كلتا الطريقتين مفيدتان عندما تحتاج إلى توزيع مجموعات فرعية من البيانات، أو إنشاء تقارير أصغر لمستلمين مختلفين، أو عزل البيانات للمعالجة الفردية.

{{% /alert %}}

## **المقدمة**

توجد العديد من السيناريوهات الواقعية التي يحتاج فيها المطور إلى تقسيم ملف Excel واحد إلى عدة ملفات أصغر. على سبيل المثال، قد يحتوي المصنف على ورقة عمل واحدة لكل قسم، ويحتاج كل رئيس قسم إلى استلام ورقته فقط. في حالات أخرى، قد ترغب في استخراج جدول أو كتلة بيانات معينة من ورقة عمل وإرسالها كملف مستقل عبر البريد الإلكتروني، دون كشف بقية المصنف. قد تحتاج المصنفات الكبيرة الموحدة أيضًا إلى تقسيمها إلى أجزاء أصغر لتسهيل التعامل معها، أو تحميلها بشكل أسرع، أو معالجتها لاحقًا بواسطة أنظمة أخرى.

توفر Aspose.Cells طريقتين مرنتين لهذه المهمة. تتكرر الطريقة الأولى على كل ورقة عمل في المصنف المصدر وتنسخ محتواها إلى نسخة `Workbook` جديدة تمامًا، وتحفظ كل منها كملف منفصل. تركز الطريقة الثانية على نطاق خلايا محدد داخل ورقة عمل وتنسخ هذا النطاق فقط إلى مصنف جديد. في كلتا الحالتين، يكون التدفق العام هو نفسه: تحميل المصنف المصدر باستخدام فئة `Workbook`، والوصول إلى البيانات ذات الصلة من خلال كائنات `Worksheet` و `Cells`، ونقل المحتوى إلى `Workbook` الوجهة، ثم حفظ الوجهة على القرص.

## **تقسيم ملف Excel عن طريق نسخ كل ورقة عمل إلى مصنف جديد**

### **نظرة عامة على الطريقة**

في هذه الطريقة، يتم فتح المصنف المصدر مرة واحدة، ثم لكل `Worksheet` في مجموعة `Worksheets` الخاصة به، يتم إنشاء `Workbook` وجهة جديدة. ثم يتم نسخ محتوى ورقة العمل المصدر إلى ورقة العمل الأولى في المصنف الوجهة، ويتم حفظ المصنف الوجهة كملف يكون اسمه مشتقًا من اسم ورقة العمل المصدر. النتيجة هي ملف إخراج واحد لكل ورقة عمل، حيث يحتوي كل ملف إخراج على بيانات ورقة مصدر واحدة.

هذه الطريقة هي الخيار الصحيح عندما تمثل كل ورقة عمل في المصنف المصدر وحدة معلومات مستقلة منطقيًا (مثل قسم، أو منطقة، أو شهر، أو خط منتجات) وتريد تسليم أو معالجة كل وحدة بمفردها.

### **الخطوات**

تصف الخطوات التالية كيفية تقسيم ملف Excel عن طريق نسخ كل ورقة عمل إلى مصنف جديد:

1. افتح ملف Excel المصدر عن طريق إنشاء كائن `Workbook` وتمرير مسار الملف إلى منشئه.
2. تكرار عبر مجموعة `Workbook.Worksheets` باستخدام حلقة `for` أو `forEach` بحيث تتم معالجة كل `Worksheet` في الملف المصدر.
3. داخل الحلقة، أنشئ نسخة `Workbook` وجهة جديدة (مصنف فارغ) لورقة العمل الحالية.
4. أضف `Worksheet` جديدة إلى المصنف الوجهة (أو استخدم ورقة العمل الأولى الافتراضية) وعيّن لها اسمًا ذا معنى، ويفضل أن يكون نفس خاصية `Name` لورقة العمل المصدر.
5. انسخ محتوى ورقة العمل المصدر إلى ورقة العمل الوجهة. يمكن القيام بذلك عن طريق تكرار خلايا مجموعة `Cells` لورقة العمل المصدر وكتابة قيمها في الخلايا المقابلة في ورقة العمل الوجهة، أو باستخدام طريقة `Cells.copy` لنقل نطاق كامل دفعة واحدة.
6. أنشئ مسار ملف إخراج يتضمن اسم ورقة العمل المصدر (على سبيل المثال، `dataDir + worksheet.Name + ".xls"`) بحيث يكون لكل ملف مُنشأ اسم فريد.
7. استدعِ طريقة `Workbook.save` للوجهة لكتابة الملف على القرص.
8. كرر الخطوات من 3 إلى 7 لورقة العمل التالية حتى تتم معالجة جميع أوراق العمل.

### **مثال على الكود**

```javascript
const AsposeCells = require("aspose.cells");

const dataDir = "data/";
const workbook = new AsposeCells.Workbook(dataDir + "book1.xls");

for (let i = 0; i < workbook.getWorksheets().getCount(); i++) {
    const sourceSheet = workbook.getWorksheets().get(i);
    const sheetName = sourceSheet.getName();
    
    const destWorkbook = new AsposeCells.Workbook();
    const destIndex = destWorkbook.getWorksheets().add();
    const destSheet = destWorkbook.getWorksheets().get(destIndex);
    destSheet.setName(sheetName);
    
    destSheet.copy(sourceSheet);
    
    const destFile = dataDir + sheetName + ".xls";
    destWorkbook.save(destFile, AsposeCells.SaveFormat.Excel97To2003);
}
```

الناتج المتوقع هو مجموعة من الملفات الجديدة في دليل البيانات، ملف واحد لكل ورقة عمل من المصنف المصدر. كل ملف يحمل اسم الورقة المصدر المقابلة، ويحتوي الملف على البيانات (وبشكل اختياري التنسيق) لتلك الورقة الواحدة.

## **تقسيم ملف Excel عن طريق نسخ نطاق إلى مصنف جديد**

### **نظرة عامة على الطريقة**

في بعض الأحيان، لا تتوافق البيانات التي تحتاج إلى تقسيمها مع ورقة عمل كاملة، بل مع منطقة مستطيلة محددة من ورقة العمل، مثل `A1:D10` أو نطاق مسمى يمثل جدولًا معينًا. في هذه الحالات، يكون نسخ أوراق العمل بأكملها مضيعة، وهناك حاجة إلى طريقة أكثر دقة: تحديد النطاق المصدر، ونسخ هذا النطاق فقط إلى مصنف جديد، وحفظ الملف الجديد.

هذه الطريقة مثالية عندما تريد استخراج جدول واحد، أو كتلة تقرير، أو منطقة بيانات من ورقة عمل أكبر مع تجاهل جميع المحتويات غير ذات الصلة. وهي مفيدة أيضًا لتصدير المناطق التي يحددها المستخدم من ورقة كملفات مستقلة.

### **الخطوات**

تصف الخطوات التالية كيفية تقسيم ملف Excel عن طريق نسخ نطاق محدد إلى مصنف جديد:

1. افتح ملف Excel المصدر عن طريق إنشاء كائن `Workbook` مع مسار الملف.
2. استرجع `Worksheet` الهدف التي تحتوي على النطاق الذي تريد نسخه، إما عن طريق الفهرس (على سبيل المثال، الورقة الأولى) أو بالاسم من مجموعة `Worksheets`.
3. حدد النطاق المراد نسخه. يمكن أن يكون نطاق خلايا مشفرًا مثل `A1:C10`، أو نطاقًا مسمى تم الحصول عليه من خلال مجموعة `Worksheet.Cells`، أو نطاقًا تم إنشاؤه عبر `Worksheet.Cells.createRange`.
4. أنشئ نسخة `Workbook` وجهة جديدة.
5. الوصول إلى `Worksheet` الأولى في المصنف الوجهة (الورقة الافتراضية).
6. انسخ النطاق المصدر إلى ورقة العمل الوجهة، عادةً بدءًا من الخلية `A1`. يمكن استخدام طريقة `Cells.copy` على مجموعة `Cells` الوجهة لنسخ نطاق كامل، أو يمكنك التكرار عبر خلايا النطاق المصدر وكتابة قيمها في خلايا الوجهة باستخدام `putValue`. يمكن توفير `CopyOptions` اختيارية للتحكم فيما يتم نقله (القيم فقط، القيم والأنماط، الصيغ، وما إلى ذلك).
7. احفظ المصنف الوجهة إلى مسار ملف جديد على القرص باستخدام طريقة `Workbook.save`.

### **مثال على الكود**

```javascript
const AsposeCells = require("aspose.cells");

// تحديد مسار البيانات ومسارات الملفات
const dataDir = "data/";
const sourcePath = dataDir + "book1.xls";
const outputPath = dataDir + "outputrange.xls";

// فتح ملف Excel المصدر
const sourceWorkbook = new AsposeCells.Workbook(sourcePath);

// الحصول على ورقة العمل الأولى من مصنف المصدر
const sourceWorksheet = sourceWorkbook.getWorksheets().get(0);

// تحديد نطاق الخلايا المصدر A1:C10 (10 صفوف، 3 أعمدة بدءًا من الصف 0، العمود 0)
const sourceRange = sourceWorksheet.getCells().createRange(0, 0, 10, 3);

// إنشاء مصنف وجهة جديد
const destWorkbook = new AsposeCells.Workbook();

// الوصول إلى ورقة العمل الأولى في مصنف الوجهة
const destWorksheet = destWorkbook.getWorksheets().get(0);

// إنشاء نطاق الوجهة عند A1 بنفس أبعاد نطاق المصدر
const destRange = destWorksheet.getCells().createRange(0, 0, 10, 3);

// نسخ نطاق المصدر إلى نطاق الوجهة
destRange.copy(sourceRange);

// حفظ مصنف الوجهة في ملف .xls جديد
destWorkbook.save(outputPath, AsposeCells.SaveFormat.Excel97To2003);
```

الناتج المتوقع هو ملف جديد واحد في دليل البيانات يحتوي فقط على القيم (وبشكل اختياري التنسيق) للنطاق المحدد المستخرج من المصنف المصدر. ملف الوجهة لا تربطه أي علاقة ببقية البيانات في الملف المصدر؛ يحتوي فقط على النطاق المستخرج، بدءًا من الخلية `A1` في ورقة العمل الأولى الخاصة به.
