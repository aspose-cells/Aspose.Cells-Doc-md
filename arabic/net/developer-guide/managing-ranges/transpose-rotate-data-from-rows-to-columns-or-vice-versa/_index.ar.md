يدعم Aspose.Cells for .NET تبديل (تدوير) البيانات بحيث تصبح الصفوف أعمدة والأعمدة صفوفًا بثلاث طرق مختلفة. تستخدم الطريقة الأولى دالة `Range.Transpose()` الموضعية وتعمل على كل إصدار من Excel، بينما تستخدم الثانية `Cell.SetDynamicArrayFormula()` لكتابة صيغة مصفوفة ديناميكية حديثة بصيغة `=TRANSPOSE(...)` تنتشر تلقائيًا في Excel 365 أو Excel 2021. تستخدم الطريقة الثالثة `Cell.SetArrayFormula()` لكتابة صيغة مصفوفة كلاسيكية من نوع Ctrl+Shift+Enter (CSE) متوافقة مع إصدارات Excel الأقدم. تستعرض هذه المقالة كل طريقة بتعليمات خطوة بخطوة وأمثلة كود كاملة.

## **المقدمة**
يعني تبديل النطاق تدويره بحيث يصبح ما كان صفًا عمودًا وما كان عمودًا صفًا، مما يعكس البيانات فعليًا عبر قطرها الرئيسي. في Microsoft Excel، تؤدي دالة ورقة العمل `TRANSPOSE` هذه العملية، ويوثق المرجع المفاهيمي في [https://support.microsoft.com/en-us/excel/functions/transpose-function](https://support.microsoft.com/en-us/excel/functions/transpose-function). يمكن تطبيق نفس الفكرة برمجيًا على نطاق من الخلايا، وهو أمر مفيد في العديد من سيناريوهات الأعمال والتقارير.
تتضمن السيناريوهات الشائعة التي يكون فيها التبديل مفيدًا ما يلي.
- إعادة توجيه تقارير المبيعات ربع السنوية أو السنوية حيث تمتد الأرباع عادةً عبر الصفحة والمناطق إلى أسفل الصفحة، أو العكس.
- تبديل توجيه المحور في لوحات المعلومات أو الرسوم البيانية بحيث تمتد السلاسل الزمنية إلى أسفل الصفحة بدلاً من امتدادها عرضًا.
- إعادة تشكيل البيانات المستوردة من الأنظمة الخارجية بحيث تتطابق مع التخطيط المتوقع من قبل قوالب التحليل أو التقارير النهائية.
لتكون بقية المقالة ملموسة، يستخدم كل المثال الجدول الصغير التالي للمبيعات حسب المنطقة والربع. في مصنف العينة يشغل هذا الجدول النطاق **A1:D5**، مع ترك **A1** فارغة كزاوية علوية يسرى، و**B1:D1** تحتوي على رؤوس المناطق، و**A2:A5** تحتوي على رؤوس الأرباع.

## **الطريقة 1 — تبديل النطاق في مكانه (Range.Transpose)**
استخدم هذه الطريقة كلما أردت تبديل البيانات دون تضمين دالة ورقة العمل `TRANSPOSE`. تعمل على **كل إصدار من Excel** ولا تعتمد على المصفوفات الديناميكية، مما يجعلها الخيار الأكثر أمانًا للتوافق عبر الإصدارات. وهي مثالية عندما تحتاج فقط إلى الناتج النهائي بعد التبديل ولا تحتاج إلى الاحتفاظ بصيغة `TRANSPOSE` الأصلية في المصنف.

### **واجهة برمجة التطبيقات المستخدمة**
`Range.Transpose()` هي دالة مثيلة على فئة `Aspose.Cells.Range`. يؤدي استدعاؤها إلى قلب النطاق في مكانه عن طريق تبديل صفوفه وأعمدته، بحيث يصبح ما كان صفًا عمودًا وما كان عمودًا صفًا. تعدّل الدالة الخلايا الأساسية مباشرة دون كتابة أي صيغة.

### **الخطوات**
1. افتح مصنف المصدر بإعداد `LoadOptions` على صيغة `.xlsx` عن طريق استدعاء `new Workbook(srcFile, new LoadOptions(LoadFormat.Xlsx))`.
2. استرجع ورقة العمل الأولى من المصنف باستخدام `workbook.Worksheets[0]`.
3. الوصول إلى مجموعة خلايا ورقة العمل من خلال `worksheet.Cells`.
4. أنشئ نطاق المصدر الذي يغطي **A1:D5** عن طريق استدعاء `cells.CreateRange("A1:D5")`.
5. استدعِ `source.Transpose()` لتدوير النطاق في مكانه، مع تبديل الصفوف والأعمدة.
6. احفظ المصنف باستخدام `workbook.Save(outputFile)`.
بعد التبديل يحتفظ النطاق المرجعي الأولي بالبيانات المدوارة. يقرأ الصف الأول (فارغ، **أوروبا**، **آسيا**، **أمريكا الشمالية**) ويقرأ العمود الأول (فارغ، **ربع 1**، **ربع 2**، **ربع 3**، **ربع 4**). يصبح كل عمود أصلي من أعمدة المبيعات صفًا في النطاق المبدّل.

```csharp
using System;
using System.IO;
using Aspose.Cells;
string srcFile = "source.xlsx";
string outputFile = "transposed.xlsx";
Workbook workbook = new Workbook(srcFile, new LoadOptions(LoadFormat.Xlsx));
Worksheet worksheet = workbook.Worksheets[0];
Cells cells = worksheet.Cells;
var source = cells.CreateRange("A1:D5");
source.Transpose();
workbook.Save(outputFile);
```

## **الطريقة 2 — التبديل باستخدام صيغة المصفوفة الديناميكية (Excel 365 / 2021)**
استخدم هذه الطريقة عندما تريد الاحتفاظ بصيغة `=TRANSPOSE(A1:D5)` كصيغة نشطة في مصنف الإخراج بحيث يتم تحديث النتيجة تلقائيًا في حالة تغير بيانات المصدر، وسيتم فتح ملف Excel المستهدف في **Excel 365 / Excel 2021 أو إصدار أحدث** حيث تكون المصفوفات الديناميكية وعامل الانتشار مدعومة.

### **واجهة برمجة التطبيقات المستخدمة**
`Cell.SetDynamicArrayFormula(string formula, FormulaParseOptions options, bool calculateValue)` هي دالة على `Aspose.Cells.Cell` تضبط صيغة الخلية كـ **صيغة مصفوفة ديناميكية**. يقيّم Excel الصيغة مرة واحدة وينتشر الناتج تلقائيًا في الخلايا المحيطة. المعامل الثالث، عند تعيينه إلى `true`، يوجّه Aspose.Cells إلى حساب القيم الناتجة أيضًا في وقت الكتابة.

### **الخطوات**
1. حمّل مصنف المصدر باستخدام `new Workbook(srcFile, new LoadOptions(LoadFormat.Xlsx))`.
2. استرجع ورقة العمل الأولى ووصل إلى مجموعة `Cells` الخاصة بها.
3. ضع صيغة المصفوفة الديناميكية على الخلية **A6**، أسفل نطاق المصدر مباشرة، عن طريق استدعاء `cells["A6"].SetDynamicArrayFormula("=TRANSPOSE(A1:D5)", new FormulaParseOptions(), true)`.
4. تمرر الوسيطة `new FormulaParseOptions()` لـ `FormulaParseOptions` الافتراضية، والوسيطة الثالثة `true` تخبر Aspose.Cells بمعاملة الصيغة كمصفوفة ديناميكية وتقييمها بحيث تُكتب القيم المنتشرة في المصنف.
5. احفظ المصنف باستخدام `workbook.Save(outputFile)`.
تحتوي الخلية **A6** على الصيغة `=TRANSPOSE(A1:D5)` وينشر Excel الناتج تلقائيًا في المنطقة **A6:E9**، وهي كتلة من 4 صفوف × 5 أعمدة مساوية للبيانات المبدّلة.

{{% alert color="primary" %}}
تعمل هذه الطريقة **فقط في Excel 365 / 2021 أو إصدار أحدث**. لن تقوم إصدارات Excel الأقدم بنشر صيغ المصفوفة الديناميكية بشكل صحيح.
{{% /alert %}}

```csharp
using System;
using System.IO;
using Aspose.Cells;
string srcFile = "source.xlsx";
string outFile = "output_transpose_dynamic.xlsx";
Workbook workbook = new Workbook(srcFile, new LoadOptions(LoadFormat.Xlsx));
Worksheet worksheet = workbook.Worksheets[0];
Cells cells = worksheet.Cells;
cells["A6"].SetDynamicArrayFormula("=TRANSPOSE(A1:D5)", new FormulaParseOptions(), true);
workbook.Save(outFile, SaveFormat.Xlsx);
```

## **الطريقة 3 — التبديل باستخدام صيغة المصفوفة الكلاسيكية (CSE)**
استخدم هذه الطريقة عندما تريد الاحتفاظ بصيغة `TRANSPOSE` في المصنف ولكن قد يتم فتح ملف Excel المستهدف في **إصدارات Excel الأقدم (قبل 2021، بما في ذلك 2019 و2016 و2013 وما إلى ذلك)** حيث لا يتم دعم نشر المصفوفات الديناميكية. صيغة المصفوفة الكلاسيكية من نوع CSE (Ctrl+Shift+Enter) هي البديل المتوافق مع الإصدارات الأقدم الذي يمكن لجميع إصدارات Excel تقييمه.

### **واجهة برمجة التطبيقات المستخدمة**
`Cell.SetArrayFormula(string arrayFormula, int nRows, int nColumns)` هي دالة على `Aspose.Cells.Cell` تعين **صيغة مصفوفة كلاسيكية (CSE)** على الخلية المرجعية وتعلن عن أبعاد المصفوفة الناتجة. يكتب Aspose.Cells علامة صيغة المصفوفة متعددة الخلايا بحيث يقيّم Excel الصيغة كتعبير مصفوفة واحد يملأ النطاق المعلن.

### **الخطوات**
1. حمّل مصنف المصدر بنفس الطريقة المستخدمة في الطرق السابقة.
2. استرجع ورقة العمل الأولى ووصل إلى مجموعة `Cells` الخاصة بها.
3. استدعِ `cells["A6"].SetArrayFormula("=TRANSPOSE(A1:D5)", 4, 5)`. الوسيطة الثانية `4` هي عدد صفوف المصفوفة الوجهة والوسيطة الثالثة `5` هي عدد الأعمدة.
4. احفظ المصنف باستخدام `workbook.Save(outputFile)`.
تكون الخلية **A6** هي مرجع صيغة المصفوفة وتمتد المصفوفة المُقيّمة على 4 صفوف × 5 أعمدة بدءًا من A6، مطابقة لأبعاد النطاق A1:D5 المصدر بعد التبديل. يكتب Excel علامة صيغة مصفوفة واحدة عبر النطاق الناتج بحيث تقوم إصدارات Excel الأقدم بتقييمها بشكل صحيح.

{{% alert color="primary" %}}
صيغ المصفوفة CSE هي الطريقة الكلاسيكية في Excel لتقييم تعبير `TRANSPOSE` وهذه الطريقة متوافقة عالميًا عبر إصدارات Excel.
{{% /alert %}}

```csharp
using System;
using System.IO;
using Aspose.Cells;
// تحميل مصنف المصدر باستخدام خيارات تحميل xlsx
string srcFile = "source.xlsx";
Workbook workbook = new Workbook(srcFile, new LoadOptions(LoadFormat.Xlsx));
// الوصول إلى ورقة العمل الأولى ومجموعة الخلايا الخاصة بها
Worksheet worksheet = workbook.Worksheets[0];
Cells cells = worksheet.Cells;
// تعيين صيغة المصفوفة الكلاسيكية CSE على الخلية A6.
// الصيغة =TRANSPOSE(A1:D5) تدور نطاق المصدر الذي يتكون من 5 صفوف × 4 أعمدة
// إلى مصفوفة من 4 صفوف × 5 أعمدة. الوسيط الثاني (4) هو عدد الصفوف
// والوسيط الثالث (5) هو عدد الأعمدة في المصفوفة الناتجة.
// يقوم Aspose.Cells بكتابة علامة صيغة المصفوفة CSE بحيث يقيّمها Excel كـ
// صيغة مصفوفة واحدة متعددة الخلايا، متوافقة مع إصدارات Excel الأقدم
// (2019، 2016، 2013، إلخ) التي لا تدعم انسكاب المصفوفات الديناميكية.
cells["A6"].SetArrayFormula("=TRANSPOSE(A1:D5)", 4, 5);
// حفظ المصنف بحيث يتم الاحتفاظ بعلامة صيغة المصفوفة
workbook.Save("output.xlsx");
```
