{{% alert color="primary" %}}
Aspose.Cells предлагает пять практических способов фильтрации данных, отображаемых в сводной таблице. Можно применять фильтры по меткам к текстовым полям строк или столбцов, использовать фильтры по датам, если поле содержит только ячейки с датой и временем либо пустые ячейки, применять фильтры по значениям к агрегированным числовым данным, использовать фильтр «10 лучших» для ранжирования по полю значений, а также вручную скрывать и отменять скрытие отдельных элементов сводной таблицы с помощью свойства `is_hidden`. Каждый способ реализован с помощью отдельных API в классах `PivotField` и `PivotItem`.
{{% /alert %}}

## **Введение
Сводные таблицы являются мощными аналитическими инструментами, однако первоначальные результаты их построения зачастую содержат больше информации, чем необходимо представить. Фильтрация — это основной механизм, позволяющий сузить сводную таблицу до строк, столбцов или значений, важных для конкретного отчета. Aspose.Cells for Python via .NET предоставляет возможности фильтрации, аналогичные предусмотренным в Microsoft Excel, и обеспечивает программный доступ к ним, чтобы полностью автоматизировать создание отчетов.
В этой статье рассматриваются следующие стратегии фильтрации:
1. **Фильтр по метке** — фильтрует элементы полей строк или столбцов на основе их текстовых меток.
2. **Фильтр по дате** — фильтрует поля строк или столбцов, содержащие только значения даты и времени или пустые ячейки.
3. **Фильтр по значению** — фильтрует элементы на основе агрегированных значений поля данных.
4. **Фильтр 10 лучших** — отображает только N верхних или нижних элементов, ранжированных по полю значений.
5. **Скрытие и отмена скрытия элементов сводной таблицы** — позволяет вручную управлять видимостью каждого отдельного элемента поля.
Каждый подход использует отдельный метод класса `PivotField` или свойство класса `PivotItem`. После применения любого фильтра необходимо вызвать для сводной таблицы методы `refresh_data()` и `calculate_data()`, чтобы кэшированные данные и вычисленные значения соответствовали новому состоянию фильтра.

## **Фильтр по метке
Фильтр по метке позволяет отбирать элементы поля строки или столбца путем сравнения их текстовых подписей с заданным шаблоном. Это полезно, когда требуется отобразить только продукты, названия которых начинаются с определенной буквы, содержат конкретное слово или соответствуют другому критерию, основанному на подписях.
Aspose.Cells предоставляет фильтрацию по меткам с помощью метода `PivotField.filter_by_label(PivotFilterType, label_string)`. Перечисление `PivotFilterType` включает такие значения, как `CaptionBeginsWith`, `CaptionContains`, `CaptionEndsWith`, `CaptionDoesNotContain`, `CaptionIsNotBlank`, `CaptionIsBlank` и другие. Второй аргумент задает строку метки, используемую для сравнения.
В следующем примере загружается рабочая книга с существующей сводной таблицей, применяется фильтр по метке, чтобы оставить видимыми только элементы, подписи которых начинаются с указанного префикса, после чего сводная таблица обновляется и результат сохраняется.

```python
import aspose.cells as ac
from aspose.cells.pivot import PivotFilterType
fileName = "sample.xlsx"
prefix = "B"
# Загрузить существующую книгу, содержащую сводную таблицу
workbook = ac.Workbook(fileName)
# Получить лист по индексу (первый лист)
worksheet = workbook.worksheets[0]
# Получить сводную таблицу по индексу
pivot_table = worksheet.pivot_tables[0]
# Получить первое поле строки PivotField
row_field = pivot_table.row_fields[0]
# Применить фильтр меток — отображать только элементы строк, метки которых начинаются с указанного префикса
row_field.filter_by_label(PivotFilterType.CAPTION_BEGINS_WITH, prefix, "")
# Обновить и пересчитать данные сводной таблицы, чтобы применить фильтр
pivot_table.pivot_cache.refresh()
# Сохранить книгу обратно на диск
workbook.save(fileName)
```

## **Фильтр по дате
Фильтры по дате позволяют сузить сводную таблицу с помощью таких критериев, как сегодня, прошлая неделя, текущий месяц, следующий квартал или конкретный диапазон дат. Это специализированные фильтры, которые применяются только к полям, в которых хранятся сведения о дате и времени.

{{% alert color="primary" %}}
Фильтр по дате работает только тогда, когда область строк или столбцов содержит исключительно ячейки с датой и временем либо пустые ячейки. Если исходное поле содержит другие типы данных, например числа или текст, фильтр по дате не даст ожидаемого результата. Перед применением фильтра убедитесь, что поле отформатировано как дата и что все значения являются допустимыми экземплярами `datetime` или пустыми ячейками.
Aspose.Cells предоставляет фильтрацию по датам с помощью метода `PivotField.filter_by_date(PivotFilterType, *date_times)`. Перечисление `PivotFilterType` содержит специальные значения для фильтрации по дате, такие как `Today`, `Yesterday`, `LastWeek`, `ThisWeek`, `NextWeek`, `LastMonth`, `ThisMonth`, `NextMonth`, `LastQuarter`, `ThisQuarter`, `NextQuarter`, `LastYear`, `ThisYear`, `NextYear` и `Between`. В зависимости от выбранного типа фильтра передается одно или два значения `datetime`; для `Between` передаются начальная и конечная даты.
В следующем примере загружается рабочая книга со сводной таблицей, в области строк которой содержится поле даты. Затем применяется фильтр по дате, ограничивающий видимые элементы определенным диапазоном дат, сводная таблица обновляется, а рабочая книга сохраняется.
{{% /alert %}}

```python
import os
import aspose.cells as ac
from datetime import datetime
from aspose.cells.pivot import PivotFilterType
input_path = "sample.xlsx"
output_path = "output_filtered.xlsx"
if not os.path.exists(input_path):
    raise FileNotFoundError("Source workbook not found.", input_path)
# Загрузить существующую книгу, содержащую сводную таблицу
workbook = ac.Workbook(input_path)
# Получить доступ к листу, на котором находится сводная таблица (по индексу)
worksheet = workbook.worksheets[0]
# Получить доступ к сводной таблице по индексу
pivot_table = worksheet.pivot_tables[0]
# Получить поле PivotField даты из области строк
# (Фильтрация по дате работает только тогда, когда область строк/столбцов содержит исключительно ячейки с датой и временем или пустые ячейки)
date_field = pivot_table.row_fields[0]
# Определить критерии даты для фильтра «Между»
start_date = datetime(2020, 1, 1)
end_date = datetime(2020, 12, 31)
# Применить фильтр по дате к полю сводной таблицы
date_field.filter_by_date(PivotFilterType.DATE_BETWEEN, start_date, end_date)
# Обновить и пересчитать сводную таблицу, чтобы применить фильтр
pivot_table.pivot_cache.refresh()
# Сохранить книгу
workbook.save(output_path)
```

## **Фильтр по значению
Фильтры по значениям работают с агрегированными значениями, которые сводная таблица вычисляет в области данных. Вместо сопоставления текстовых меток они сравнивают числовые итоги с пороговым значением. Типичные сценарии применения включают отображение только продуктов, сумма продаж которых превышает заданное значение, или только регионов, количество транзакций в которых находится в определенном диапазоне.
Aspose.Cells предоставляет фильтрацию по значениям с помощью метода `PivotField.filter_by_value(value_field, PivotFilterType, *thresholds)`. Параметр `PivotFilterType` принимает такие значения, как `ValueGreaterThan`, `ValueLessThan`, `ValueBetween`, `ValueEqual`, `ValueNotEqual`, `ValueGreaterThanOrEqual` и `ValueLessThanOrEqual`. Параметр `value_field` указывает оцениваемое поле данных, а последний аргумент или аргументы задают пороговое значение или значения.
В следующем примере загружается рабочая книга со сводной таблицей, применяется фильтр по значению, который оставляет только элементы с агрегированными продажами выше числового порога, после чего сводная таблица обновляется и рабочая книга сохраняется.

```python
import aspose.cells as ac
from aspose.cells.pivot import PivotFilterType
workbook = ac.Workbook("sample.xlsx")
worksheet = workbook.worksheets[0]
pivot_table = worksheet.pivot_tables[0]
row_field = pivot_table.row_fields[0]
data_field = pivot_table.data_fields[0]
# Вручную найти индекс поля данных, поскольку PivotFieldCollection не имеет IndexOf
data_field_index = -1
for i in range(len(pivot_table.data_fields)):
    if pivot_table.data_fields[i] == data_field:
        data_field_index = i
        break
if data_field_index >= 0:
    row_field.filter_by_value(data_field_index, PivotFilterType.VALUE_GREATER_THAN, 5000.0, float('inf'))
pivot_table.pivot_cache.refresh()
workbook.save("output.xlsx")
```

## **Фильтр 10 лучших
Фильтр 10 лучших — это специализированная форма фильтра по значениям, которая сохраняет только N верхних или нижних элементов на основе выбранного поля значений. Он обычно используется для формирования рейтингов, например в отчетах «10 самых доходных продуктов» или «5 регионов с наименьшим количеством продаж».

{{% alert color="primary" %}}
Фильтр 10 лучших действует только тогда, когда в области данных сводной таблицы находится одно или несколько полей значений. Без хотя бы одного такого поля агрегированная метрика, по которой можно ранжировать элементы, отсутствует, поэтому применить фильтр невозможно.
Aspose.Cells предоставляет фильтрацию 10 лучших с помощью метода `PivotField.filter_top_10(item_count, is_top, value_field, PivotFilterType)`. Параметр `item_count` определяет количество сохраняемых элементов, `is_top` указывает, следует ли сохранить верхние элементы (True) или нижние элементы (False), `value_field` ссылается на поле данных, используемое для ранжирования, а `PivotFilterType` определяет способ вычисления значения (обычно `Sum`, но также `Count` и `Percent`).
В следующем примере загружается рабочая книга со сводной таблицей, содержащей поле значений, применяется фильтр 10 лучших, который оставляет 10 элементов с наибольшей суммой продаж, после чего сводная таблица обновляется и рабочая книга сохраняется.
{{% /alert %}}

```python
import aspose.cells as ac
import aspose.cells.pivot as acp
# Загрузить существующую книгу, содержащую сводную таблицу
inputPath = "input.xlsx"
outputPath = "output.xlsx"
workbook = ac.Workbook(inputPath)
# Получить лист, содержащий сводную таблицу (индекс 0)
worksheet = workbook.worksheets[0]
# Получить сводную таблицу по индексу
pivotTable = worksheet.pivot_tables[0]
# Убедиться, что в области данных есть хотя бы одно поле значений
if len(pivotTable.data_fields) == 0:
    raise Exception("Pivot table has no value (data) PivotField.")
valueField = pivotTable.data_fields[0]
# Получить целевое поле строки (поле, к которому требуется применить фильтр Top 10)
rowField = pivotTable.row_fields[0]
# Первое (и единственное) поле данных находится по индексу 0; фильтр Top 10 ранжирует элементы по нему.
valueFieldIndex = 0
# Применить фильтр Top 10 к полю строки:
#   - itemCount   = 10
#   - filterType  = PivotFilterType.SUM
#   - isTop       = true (Top N; false означает Bottom N)
#   - valueFieldIndex = индекс поля данных, используемого для ранжирования элементов
rowField.filter_top10(10, acp.PivotFilterType.SUM, True, valueFieldIndex)
# Обновить данные сводной таблицы и пересчитать её, чтобы применить фильтр
pivotTable.pivot_cache.refresh()
# Сохранить книгу
workbook.save(outputPath)
```

## **Фильтрация путем скрытия или отмены скрытия элементов сводной таблицы
Помимо структурированных API фильтрации, Aspose.Cells позволяет напрямую управлять видимостью каждого отдельного элемента сводной таблицы. Перебирая коллекцию `PivotItems` класса `PivotField` и переключая свойство `is_hidden`, можно выборочно скрывать определенные элементы без применения фильтра, основанного на формуле. Установка `is_hidden = True` скрывает элемент в сводной таблице; установка `is_hidden = False` отменяет его скрытие и снова делает элемент видимым.
Этот подход полезен, когда правило фильтрации является нестандартным или относится к отдельным элементам, например при необходимости скрыть небольшое количество определенных категорий, которые не должны отображаться в конкретном отчете. В приведенном ниже примере загружается сводная таблица, скрывается конкретный элемент по имени, демонстрируется способ отменить его скрытие, обновляется сводная таблица и сохраняется рабочая книга.

```python
import aspose.cells as ac
# Загрузить существующую книгу, содержащую сводную таблицу
workbook = ac.Workbook("pivot_table_sample.xlsx")
# Получить доступ к первому листу, содержащему сводную таблицу
sheet = workbook.worksheets[0]
# Получить доступ к сводной таблице по индексу (первая сводная таблица на листе)
pivot_table = sheet.pivot_tables[0]
# Получить целевое поле PivotField (первое поле строк, элементы которого можно скрывать и отображать)
pivot_field = pivot_table.row_fields[0]
# Перебрать коллекцию PivotItems выбранного поля PivotField
item_count = pivot_field.pivot_items.count
for i in range(item_count):
    item = pivot_field.pivot_items[i]
    # Скрыть элементы сводной таблицы, соответствующие определенному имени или условию
    if item.name == "Item1" or item.name == "Item2":
        item.is_hidden = True
    # Продемонстрировать отображение: повторно показать ранее скрытый элемент сводной таблицы
    if item.name == "Item3":
        item.is_hidden = False
# Обновить и пересчитать сводную таблицу, чтобы изменения вступили в силу
pivot_table.pivot_cache.refresh()
# Сохранить книгу — скрытые элементы остаются в исходных данных,
# но исключаются из отображаемого результата сводной таблицы
workbook.save("output_pivot_filtered.xlsx")
```
