{{% alert color="primary" %}}
С помощью смарт-маркеров Aspose.Cells может отобразить источник данных в виде массива в одной ячейке. Атрибут `arrayassingle` отключает стандартное поэлементное распределение, а атрибут `arraydelimiter` выбирает разделитель между объединенными элементами — запятую по умолчанию либо любой одиночный символ или указанную вами строку из нескольких символов в кавычках.
{{% /alert %}}

## **Введение**

Смарт-маркеры в Aspose.Cells — это функция на основе шаблонов, которая динамически заполняет данные электронной таблицы с помощью выражений маркеров, таких как `&=DataSource.Field`. Маркер размещается в рабочей книге-дизайнере, а после обработки шаблона с помощью `WorkbookDesigner` маркеры заменяются значениями из предоставленного источника данных.
По умолчанию, когда смарт-маркер ссылается на поле массива, например `&=Product.Tags`, связанное со списком из четырех значений, механизм разворачивает массив и помещает каждый элемент в отдельную ячейку, распределяя значения вертикально вниз по столбцу под маркером. Хотя такое поведение удобно во многих сценариях, иногда предпочтительно отобразить весь массив в одной ячейке, объединив элементы и разделив их выбранным разделителем.
Атрибуты `arrayassingle` и `arraydelimiter`, указанные в круглых скобках смарт-маркера в формате `name:value`, в точности удовлетворяют этому требованию. Они позволяют сохранять компактные и предсказуемые макеты отчетов и при этом работать с источниками данных в виде массивов без преобразований.

## **Почему эта функция необходима**

### **Поведение при распределении массива по умолчанию**

По умолчанию, когда смарт-маркер ссылается на поле массива, Aspose.Cells разворачивает массив по нескольким ячейкам. Например, смарт-маркер `&=Product.Tags` для списка, содержащего четыре значения, помещает каждое значение в отдельную ячейку под маркером, сдвигая остальное содержимое шаблона и нарушая тщательно продуманные макеты отчетов.

### **Когда стандартное поведение не подходит**

Существует множество практических сценариев, в которых стандартное распределение нежелательно:
- **Отчеты со сводными данными**, которым требуется компактный макет с одной строкой для каждой записи.
- **Списки тегов, меток или ключевых слов**, которые должны отображаться в одной ячейке в виде значений, разделенных запятыми или вертикальной чертой.
- **Фильтры-чипы или индикаторы состояния**, объединяющие несколько значений в одном месте для удобства чтения.
- **Последующие конвейеры обработки** — экспорт CSV, рендеринг PDF, слияние почты, — ожидающие одно объединенное значение в каждой ячейке вместо развернутого диапазона.
- **Совместимость между платформами**, поскольку некоторые получатели данных не допускают массивов, распределяющихся по нескольким ячейкам.

### **Устранение ограничения**

Без встроенного механизма разработчикам пришлось бы предварительно обрабатывать данные в Python, объединяя списки в строки с разделителями перед их привязкой к книге-дизайнеру. Это дублирует логику, усложняет модели данных и повышает вероятность ошибок. Атрибуты `arrayassingle` и `arraydelimiter` устраняют необходимость в таком обходном решении, выполняя форматирование декларативно внутри самого смарт-маркера.

## **Преимущества функции**

Использование атрибутов `arrayassingle` и `arraydelimiter` в смарт-маркерах дает несколько преимуществ:
- **Размещение в одной ячейке**: Все элементы массива отображаются ровно в одной ячейке, сохраняя компактный и предсказуемый макет.
- **Настройка разделителя**: Можно указать нужный разделитель — стандартную запятую, точку с запятой, дефис, вертикальную черту или строку из нескольких символов в кавычках, например `" | "`.
- **Форматирование на основе шаблона**: Для предварительной обработки данных не требуется дополнительный код; правила форматирования задаются внутри тега смарт-маркера.
- **Более чистые отчеты**: Данные массива больше не сдвигают соседнее содержимое шаблона в другие строки или столбцы.
- **Различные типы данных**: Работает со списками строк и числовыми списками, переданными в виде строк JSON.
- **Обратная совместимость**: Если атрибуты не указаны, сохраняется исходное поведение распределения, поэтому существующие шаблоны продолжают работать без изменений.

## **Как использовать эту функцию**

### **Синтаксис смарт-маркера**

Атрибуты `arrayassingle` и `arraydelimiter` используют синтаксис атрибутов Aspose.Cells в формате `name:value` внутри круглых скобок стандартного смарт-маркера. Общий синтаксис:

```
&=DataSource.ArrayField(arrayassingle:true,arraydelimiter:;)
```

Маркер состоит из следующих частей:
- `&=DataSource.ArrayField` — стандартный смарт-маркер, ссылающийся на поле массива в привязанном источнике данных.
- `arrayassingle:true` — instructs the engine to render the whole array into a single cell instead of spreading the elements.
- `arraydelimiter:;` — optional; defines the separator placed between array elements. When it is omitted, a comma is used.

{{% alert color="warning" %}}
Записывайте атрибуты в форме `name:value` (двоеточие, а не знак равенства) и разделяйте несколько атрибутов запятой **без пробелов**. Пробел после запятой сдвигает разбираемое значение на один символ — `(arrayassingle:true, arraydelimiter:;)` присоединит элементы с ошибочным разделителем `:;` вместо `;`.
{{% /alert %}}

### **Варианты записи разделителя**

- Одиночный символ указывается сразу после двоеточия: `arraydelimiter:;`, `arraydelimiter:-`, `arraydelimiter:*`.
- Многосимвольный разделитель заключается в двойные кавычки: `arraydelimiter:" | "`, `arraydelimiter:" - "`.

### **Пошаговый порядок действий**

Ниже описан порядок действий для отображения массива в одной ячейке с помощью смарт-маркеров.
1. **Подготовьте источник данных**: оформите каждую запись как объект JSON, поле которого содержит массив, например `{"Tags": ["C#", "Aspose"]}`. Обычные экземпляры классов Python, словари и списки, переданные в `set_data_source`, не связывают поля массивов на этой платформе — поддерживается табличная форма в виде строк JSON.
2. **Создайте книгу-дизайнер**: создайте новый `Workbook`, добавьте строку заголовков и поместите ячейку со смарт-маркером, ссылающимся на поле массива, с атрибутом `arrayassingle` и атрибутом `arraydelimiter`, если требуется пользовательский разделитель.
3. **Создайте экземпляр `WorkbookDesigner`**: создайте `WorkbookDesigner` для книги и присоедините строки JSON с помощью `set_json_data_source`.
4. **Обработайте маркеры**: вызовите метод `WorkbookDesigner.process()`, чтобы развернуть смарт-маркеры и заполнить книгу реальными данными.
5. **Сохраните результат**: сохраните полученную книгу на диск в формате XLSX или любом другом поддерживаемом формате файла.

### **Пример кода 1 — Базовый рендеринг массива строк**

```python
import aspose.cells as ac

workbook = ac.Workbook()
worksheet = workbook.worksheets[0]
worksheet.cells.get("A1").put_value("Tags")
# No spaces inside the parentheses: attributes are name:value pairs
worksheet.cells.get("A2").put_value("&=Product.Tags(arrayassingle:true)")
designer = ac.WorkbookDesigner(workbook)
designer.set_json_data_source(
    "Product",
    '[{"Tags": ["C#", "Aspose", "SmartMarker", "Excel"]}]')
designer.process()
print(worksheet.cells.get("A2").string_value)
workbook.save("output-array-single.xlsx")
```

В примере выводится объединенное значение всего массива. Четыре тега помещаются в одну ячейку и разделяются запятой по умолчанию:

```
C#,Aspose,SmartMarker,Excel
```

### **Пример кода 2 — Числовой массив с пользовательским разделителем**

```python
import aspose.cells as ac

workbook = ac.Workbook()
worksheet = workbook.worksheets[0]
worksheet.cells.get("A1").put_value("Scores")
# arraydelimiter:- joins the numbers with a hyphen
worksheet.cells.get("A2").put_value("&=Student.Scores(arrayassingle:true,arraydelimiter:-)")
designer = ac.WorkbookDesigner(workbook)
designer.set_json_data_source(
    "Student",
    '[{"Scores": [95, 88, 76, 100, 67]}]')
designer.process()
print(worksheet.cells.get("A2").string_value)
workbook.save("output-array-numeric.xlsx")
```

Числа в формате JSON объединяются точно так же, как строки: каждый элемент сохраняет исходное текстовое представление числа:

```
95-88-76-100-67
```

### **Пример кода 3 — Сравнение рендеринга по умолчанию и рендеринга в одной ячейке**

```python
import aspose.cells as ac

workbook = ac.Workbook()
cells = workbook.worksheets[0].cells
# Column B: default marker — values spread vertically down the column
cells.get("B1").put_value("Default")
cells.get("B2").put_value("&=Order.Items")
# Column C: single-cell rendering — the whole array joins into one cell
cells.get("C1").put_value("Single cell")
cells.get("C2").put_value("&=Order.Items(arrayassingle:true)")
designer = ac.WorkbookDesigner(workbook)
designer.set_json_data_source(
    "Order",
    '[{"Items": ["Apple", "Banana", "Cherry", "Date"]}]')
designer.process()
for row in range(1, 6):
    b = cells.get(row, 1).string_value or ""
    c = cells.get(row, 2).string_value or ""
    if b or c:
        print(f"B{row + 1}=[{b}]  C{row + 1}=[{c}]")
workbook.save("output-array-comparison.xlsx")
```

Маркер по умолчанию заполняет ячейки в столбце B — по одной для каждого элемента, тогда как маркер `arrayassingle` объединяет тот же массив в одной ячейке столбца C:

```
B2=[Apple]  C2=[Apple,Banana,Cherry,Date]
B3=[Banana]  C3=[]
B4=[Cherry]  C4=[]
B5=[Date]  C5=[]
```

### **Примечания и рекомендации**

При работе с атрибутами `arrayassingle` и `arraydelimiter` учитывайте следующее:
- Значения атрибутов задаются в форме `name:value`. Форма со знаком равенства, например `arrayassingle=true`, не распознается, и механизм без предупреждения возвращается к стандартному поведению распределения.
- Атрибуты разделяются запятой без пробелов; пробел после запятой сдвигает значение разделителя на один символ, как указано в предупреждении выше.
- Значением `arraydelimiter` может быть одиночный символ, указанный сразу после двоеточия, или многосимвольная строка в двойных кавычках.
- Если `arraydelimiter` не указан, элементы объединяются запятой.
- Передавайте поля массивов через объекты строк в `set_json_data_source`. Обычные объекты Python и словари, переданные в `set_data_source`, не связываются на этой платформе, а пользовательский `ICellsDataTable`, столбец которого возвращает список Python, отображает текстовое представление контейнера списка вместо объединения его элементов.
- Числа JSON сохраняют обычный целочисленный формат в объединенном результате.
