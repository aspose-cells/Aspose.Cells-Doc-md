{{% alert color="primary" %}}
Aspose.Cells позволяет с помощью смарт-маркеров отобразить в одной ячейке данные из источника, содержащего массив. Атрибут `arrayassingle` отключает стандартное поэлементное распределение, а атрибут `arraydelimiter` задаёт разделитель между объединёнными элементами: по умолчанию используется запятая, но можно указать любой одиночный символ или многосимвольную строку в кавычках.
{{% /alert %}}

## **Введение**

Смарт-маркеры в Aspose.Cells — это функция на основе шаблонов, которая позволяет динамически заполнять электронную таблицу с помощью выражений смарт-маркеров, таких как `&=DataSource.Field`. Маркер размещается в рабочей книге конструктора, а после обработки шаблона с помощью `WorkbookDesigner` маркеры заменяются значениями из переданного источника данных.
По умолчанию, если смарт-маркер ссылается на поле, содержащее массив (например, `&=Product.Tags`, связанный со списком из четырёх значений), движок разворачивает массив и помещает каждый элемент в отдельную ячейку, последовательно записывая значения сверху вниз в столбце под маркером. Хотя такое поведение удобно во многих сценариях, иногда предпочтительнее отобразить весь массив в одной ячейке, объединив элементы и разделив их выбранным разделителем.
Атрибуты `arrayassingle` и `arraydelimiter`, записываемые в круглых скобках смарт-маркера в формате `name:value`, позволяют решить именно эту задачу. Они помогают сохранять компактность и предсказуемость макетов отчётов, не отказываясь от работы с источниками данных, содержащими массивы.

## **Зачем нужна эта функция**

### **Стандартное распределение массива**

По умолчанию, когда смарт-маркер ссылается на поле, содержащее массив, Aspose.Cells распределяет массив по нескольким ячейкам. Например, смарт-маркер вида `&=Product.Tags`, связанный со списком из четырёх значений, помещает каждое значение в отдельную ячейку под маркером, вытесняя остальное содержимое шаблона и тем самым нарушая продуманные макеты отчётов.

### **Когда стандартное распределение не подходит**

Стандартное распределение не подходит во многих практических сценариях:
- **Отчёты со сводными данными**, для которых требуется компактная компоновка с одной строкой на каждую запись.
- **Списки тегов, меток или ключевых слов**, которые необходимо отображать в одной ячейке в виде значений, разделённых запятыми или вертикальной чертой.
- **Элементы фильтрации или индикаторы состояния**, объединяющие несколько значений в одном месте для удобства чтения.
- **Последующие конвейеры обработки данных** (экспорт в CSV, отрисовка в PDF, слияние почты), ожидающие по одному объединённому значению в каждой ячейке, а не диапазон с развёрнутыми значениями.
- **Совместимость между платформами**, когда некоторые потребители не допускают, чтобы массивы занимали несколько ячеек.

### **Какую проблему это решает**

Без встроенного механизма разработчикам пришлось бы предварительно обрабатывать данные в Python, объединяя списки в строки с разделителями перед их передачей в `WorkbookDesigner`. Такой подход дублирует логику, усложняет модели данных и повышает вероятность ошибок. Атрибуты `arrayassingle` и `arraydelimiter` устраняют необходимость в таком обходном решении: формат задаётся декларативно непосредственно в смарт-маркере.

## **Преимущества функции**

Использование атрибутов `arrayassingle` и `arraydelimiter` в смарт-маркерах даёт несколько преимуществ:
- **Размещение в одной ячейке**: все элементы массива отображаются ровно в одной ячейке, поэтому макеты остаются компактными и предсказуемыми.
- **Настраиваемый разделитель**: можно указать стандартную запятую, точку с запятой, дефис, вертикальную черту или многосимвольную строку в кавычках, например `" | "`.
- **Форматирование по шаблону**: для предварительной обработки данных не требуется дополнительный код; правила форматирования задаются внутри тега смарт-маркера.
- **Аккуратные отчёты**: данные массива больше не вытесняют соседнее содержимое шаблона в другие строки или столбцы.
- **Гибкость типов данных**: поддерживаются массивы строк, передаваемые в виде строк JSON, в том числе числовые значения, представленные в виде строк.
- **Обратная совместимость**: если атрибуты не указаны, сохраняется исходное поведение распределения, поэтому существующие шаблоны продолжают работать без изменений.

## **Как использовать эту функцию**

### **Синтаксис смарт-маркера**

Атрибуты `arrayassingle` и `arraydelimiter` задаются в соответствии с синтаксисом атрибутов Aspose.Cells (`name:value`) в круглых скобках стандартного смарт-маркера. Общий синтаксис:

```
&=DataSource.ArrayField(arrayassingle:true,arraydelimiter:;)
```

Маркер состоит из следующих частей:
- `&=DataSource.ArrayField` — стандартный смарт-маркер, ссылающийся на поле, содержащее массив, в привязанном источнике данных.
- `arrayassingle:true` — предписывает движку отображать весь массив в одной ячейке вместо распределения его элементов.
- `arraydelimiter:;` — необязательный атрибут; задаёт разделитель между элементами массива. Если он не указан, используется запятая.

{{% alert color="warning" %}}
Записывайте атрибуты в форме `name:value` (с двоеточием, а не со знаком равенства) и разделяйте несколько атрибутов запятой **без пробелов**. Пробел после запятой сдвигает считанное значение на один символ: `(arrayassingle:true, arraydelimiter:;)` приведёт к объединению элементов с ошибочным разделителем `:;` вместо `;`.
{{% /alert %}}

### **Формы разделителя**

- Одиночный символ указывается непосредственно после двоеточия: `arraydelimiter:;`, `arraydelimiter:-`, `arraydelimiter:*`.
- Многосимвольный разделитель записывается в двойных кавычках: `arraydelimiter:" | "`, `arraydelimiter:" - "`.

### **Пошаговая инструкция**

Ниже описан порядок действий для отображения массива в одной ячейке с помощью смарт-маркеров.
1. **Подготовьте источник данных**: оформите каждую запись в виде объекта JSON, в котором одно из полей содержит массив, например `{"Tags": ["C#", "Aspose"]}`. Обычные экземпляры классов Python и словари, переданные в `setDataSource`, на этой платформе не привязываются; поддерживается табличное представление в виде строк JSON.
2. **Создайте рабочую книгу конструктора**: создайте новый `Workbook`, добавьте строку заголовка и поместите в ячейку смарт-маркер, ссылающийся на поле, содержащее массив, с атрибутом `arrayassingle` и, если нужен пользовательский разделитель, также с атрибутом `arraydelimiter`.
3. **Создайте экземпляр `WorkbookDesigner`**: создайте объект `WorkbookDesigner` для рабочей книги и передайте ему строки JSON с помощью `setJsonDataSource`.
4. **Обработайте маркеры**: вызовите метод `WorkbookDesigner.process()`, чтобы раскрыть смарт-маркеры и заполнить рабочую книгу реальными данными.
5. **Сохраните результат**: сохраните полученную рабочую книгу на диске в формате XLSX или любом другом поддерживаемом формате файлов.

### **Пример 1 — базовое отображение массива строк**

```python
import jpype
import asposecells
jpype.startJVM()
from asposecells.api import Workbook, WorkbookDesigner

workbook = Workbook()
worksheet = workbook.getWorksheets().get(0)
worksheet.getCells().get("A1").putValue("Tags")
# No spaces inside the parentheses: attributes are name:value pairs
worksheet.getCells().get("A2").putValue("&=Product.Tags(arrayassingle:true)")
designer = WorkbookDesigner(workbook)
designer.setJsonDataSource(
    "Product",
    '[{"Tags": ["C#", "Aspose", "SmartMarker", "Excel"]}]')
designer.process()
print(worksheet.getCells().get("A2").getStringValue())
workbook.save("output-array-single.xlsx")
```

В примере выводится объединённое значение всего массива. Четыре тега помещаются в одну ячейку и разделяются запятой по умолчанию:

```
C#,Aspose,SmartMarker,Excel
```

### **Пример 2 — числовые значения с пользовательским разделителем**

```python
import jpype
import asposecells
jpype.startJVM()
from asposecells.api import Workbook, WorkbookDesigner

workbook = Workbook()
worksheet = workbook.getWorksheets().get(0)
worksheet.getCells().get("A1").putValue("Scores")
# arraydelimiter:- joins the values with a hyphen
worksheet.getCells().get("A2").putValue("&=Student.Scores(arrayassingle:true,arraydelimiter:-)")
designer = WorkbookDesigner(workbook)
designer.setJsonDataSource(
    "Student",
    '[{"Scores": ["95", "88", "76", "100", "67"]}]')
designer.process()
print(worksheet.getCells().get("A2").getStringValue())
workbook.save("output-array-numeric.xlsx")
```

При передаче оценок в виде строк JSON в объединённом результате сохраняется обычное представление чисел:

```
95-88-76-100-67
```

{{% alert color="note" %}}
При передаче через движок Java числа в JSON поступают как числа двойной точности, поэтому `[95, 88]` будут объединены как `95.0-88.0`. Заключите числа в кавычки в строках JSON, если в объединённой ячейке требуется сохранить точный текст целого числа.
{{% /alert %}}

### **Пример 3 — сравнение стандартной отрисовки и отрисовки в одной ячейке**

```python
import jpype
import asposecells
jpype.startJVM()
from asposecells.api import Workbook, WorkbookDesigner

workbook = Workbook()
cells = workbook.getWorksheets().get(0).getCells()
# Column B: default marker — values spread vertically down the column
cells.get("B1").putValue("Default")
cells.get("B2").putValue("&=Order.Items")
# Column C: single-cell rendering — the whole array joins into one cell
cells.get("C1").putValue("Single cell")
cells.get("C2").putValue("&=Order.Items(arrayassingle:true)")
designer = WorkbookDesigner(workbook)
designer.setJsonDataSource(
    "Order",
    '[{"Items": ["Apple", "Banana", "Cherry", "Date"]}]')
designer.process()
for row in range(1, 6):
    b = cells.get(row, 1).getStringValue() or ""
    c = cells.get(row, 2).getStringValue() or ""
    if b or c:
        print(f"B{row + 1}=[{b}]  C{row + 1}=[{c}]")
workbook.save("output-array-comparison.xlsx")
```

Маркер по умолчанию заполняет отдельную ячейку для каждого элемента в столбце B, тогда как маркер с `arrayassingle` помещает тот же массив в одну ячейку столбца C:

```
B2=[Apple]  C2=[Apple,Banana,Cherry,Date]
B3=[Banana]  C3=[]
B4=[Cherry]  C4=[]
B5=[Date]  C5=[]
```

### **Примечания и рекомендации**

При работе с атрибутами `arrayassingle` и `arraydelimiter` учитывайте следующее:
- Значения атрибутов записываются в форме `name:value`. Форма со знаком равенства, например `arrayassingle=true`, не распознаётся, и система без предупреждения возвращается к стандартному поведению распределения.
- Разделяйте атрибуты запятой без пробелов; пробел после запятой сдвигает значение разделителя на один символ (см. предупреждение выше).
- Значение `arraydelimiter` может быть одиночным символом, записанным непосредственно после двоеточия, или многосимвольной строкой в двойных кавычках.
- Если `arraydelimiter` не указан, элементы объединяются запятой.
- Передавайте поля, содержащие массивы, через `setJsonDataSource` в объектах строк; обычные объекты Python и словари, переданные в `setDataSource`, на этой платформе не привязываются.
- Числа в JSON поступают через движок Java как числа двойной точности (`95` объединяется как `95.0`); заключайте числовые значения в кавычки в строках JSON, если требуется сохранить точный текст целого числа.
- Размещайте смарт-маркер в ячейке достаточной ширины, чтобы отобразить полученную объединённую строку; в противном случае содержимое может визуально переходить в соседние ячейки в зависимости от формата.
