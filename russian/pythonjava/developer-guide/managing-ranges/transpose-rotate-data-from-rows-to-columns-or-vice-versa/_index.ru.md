{{% alert color="primary" %}}
Aspose.Cells for Python via Java поддерживает транспонирование (поворот) данных таким образом, что строки становятся столбцами, а столбцы — строками, тремя различными способами. Первый способ использует метод `Range.transpose()`, который работает на месте и совместим с любой версией Excel, тогда как второй использует `Cell.setDynamicArrayFormula()` для записи современной формулы динамического массива `=TRANSPOSE(...)`, которая автоматически распределяется в Excel 365 или Excel 2021. Третий способ использует `Cell.setArrayFormula()` для записи классической формулы массива Ctrl+Shift+Enter (CSE), совместимой со старыми версиями Excel. В этой статье каждый способ рассматривается с пошаговыми инструкциями и полными примерами кода.
{{% /alert %}}

## **Введение**
Транспонирование диапазона означает его поворот таким образом, чтобы строка стала столбцом, а столбец — строкой, фактически отражая данные относительно их главной диагонали. В Microsoft Excel эту операцию выполняет функция листа `TRANSPOSE`, концептуальное описание которой приведено по адресу [https://support.microsoft.com/en-us/excel/functions/transpose-function](https://support.microsoft.com/en-us/excel/functions/transpose-function). Эту же идею можно применить программно к диапазону ячеек, что полезно во многих бизнес-сценариях и сценариях формирования отчётов.
Распространённые сценарии, в которых полезно транспонирование, включают следующие.
- Изменение ориентации квартальных или годовых отчётов о продажах, где кварталы обычно располагаются по горизонтали, а регионы — по вертикали, или наоборот.
- Изменение ориентации осей в информационных панелях или диаграммах таким образом, чтобы временной ряд шёл по вертикали, а не по горизонтали.
- Изменение формы данных, импортированных из внешних систем, чтобы они соответствовали компоновке, ожидаемой шаблонами анализа или отчётности.
Чтобы сделать дальнейшее изложение конкретным, во всех примерах используется следующая небольшая таблица продаж по регионам по кварталам. В образце рабочей книги эта таблица занимает диапазон **A1:D5**, при этом ячейка **A1** оставлена пустой как левый верхний угол, **B1:D1** содержат заголовки регионов, а **A2:A5** — заголовки кварталов.

| Qtr 2             | 17987034  | 12214447  | 10873099      |
| Qtr 3             | 19485029  | 14356879  | 15689543      |
| Qtr 4             | 22567894  | 15763492  | 17456723      |
Затем в статье представлены три различных способа транспонирования этих данных с помощью Aspose.Cells for Python via Java, каждый из которых подходит для определённой версии Excel и случая использования.

## **Подход 1 — Транспонирование диапазона на месте (Range.transpose)**
Используйте этот подход, когда требуется транспонировать данные без привлечения функции листа `TRANSPOSE`. Он работает в **любой версии Excel** и не зависит от динамических массивов, что делает его самым безопасным кросс-версионным вариантом. Он идеально подходит, когда вам нужны только итоговые транспонированные значения и нет необходимости сохранять исходную формулу `TRANSPOSE` в рабочей книге.

### **Используемый API**
`Range.transpose()` — метод экземпляра класса `com.aspose.cells.Range`. При его вызове диапазон переворачивается на месте путём обмена его строк и столбцов, так что строка становится столбцом, а столбец — строкой. Метод напрямую изменяет базовые ячейки без записи формулы.

### **Шаги**
1. Откройте исходную рабочую книгу с `LoadOptions`, установленными в формат `.xlsx`, вызвав `Workbook(srcFile, LoadOptions(LoadFormat.Xlsx))`.
2. Получите первый рабочий лист из рабочей книги с помощью `workbook.getWorksheets().get(0)`.
3. Получите доступ к коллекции ячеек рабочего листа через `worksheet.getCells()`.
4. Создайте исходный диапазон, охватывающий **A1:D5**, вызвав `cells.createRange("A1:D5")`.
5. Вызовите `source.transpose()`, чтобы повернуть диапазон на месте, поменяв местами строки и столбцы.
6. Сохраните рабочую книгу с помощью `workbook.save(outputFile)`.
После транспонирования тот же самый опорный диапазон содержит повёрнутые данные. Первая строка читается как (пусто, **Europe**, **Asia**, **North America**), а первый столбец — как (пусто, **Qtr 1**, **Qtr 2**, **Qtr 3**, **Qtr 4**). Каждый исходный столбец продаж становится строкой в транспонированном диапазоне.

```python
import jpype
import asposecells
jpype.startJVM()
from asposecells.api import Workbook
from asposecells.api import Workbook, Worksheet, Cells, Range, LoadOptions, LoadFormat
srcFile = "source.xlsx"
outputFile = "transposed.xlsx"
loadOptions = LoadOptions(LoadFormat.Xlsx)
workbook = Workbook(srcFile, loadOptions)
worksheet = workbook.getWorksheets().get(0)
cells = worksheet.getCells()
source = cells.createRange("A1:D5")
source.transpose()
workbook.save(outputFile)
jpype.shutdownJVM()
```

## **Подход 2 — Транспонирование с формулой динамического массива (Excel 365 / 2021)**
Используйте этот подход, когда требуется сохранить формулу `=TRANSPOSE(A1:D5)` как живую формулу в выходной рабочей книге, чтобы результат автоматически обновлялся при изменении исходных данных, и при этом целевой файл Excel будет открываться в **Excel 365 / Excel 2021 или более поздней версии**, где поддерживаются динамические массивы и оператор распределения (spill).

### **Используемый API**
`Cell.setDynamicArrayFormula(String formula, FormulaParseOptions options, boolean calculateValue)` — метод класса `com.aspose.cells.Cell`, который задаёт формулу ячейки как **формулу динамического массива**. Excel однократно вычисляет формулу и автоматически распределяет результат в окружающие ячейки. Третий параметр, установленный в `True`, указывает Aspose.Cells также вычислить результирующие значения во время записи.

### **Шаги**
1. Загрузите исходную рабочую книгу с помощью `Workbook(srcFile, LoadOptions(LoadFormat.Xlsx))`.
2. Получите первый рабочий лист и доступ к его коллекции `Cells`.
3. Поместите формулу динамического массива в ячейку **A6**, прямо под исходным диапазоном, вызвав `cells.get("A6").setDynamicArrayFormula("=TRANSPOSE(A1:D5)", None, True)`.
4. Аргумент `None` передаёт значения по умолчанию для `FormulaParseOptions`, а третий аргумент `True` указывает Aspose.Cells рассматривать формулу как формулу динамического массива и вычислить её, чтобы распределённые значения были записаны в рабочую книгу.
5. Сохраните рабочую книгу с помощью `workbook.save(outputFile)`.
Ячейка **A6** содержит формулу `=TRANSPOSE(A1:D5)`, и Excel автоматически распределяет результат в область **A6:D10** — блок размером 5 строк на 4 столбца, равный транспонированным данным.

{{% alert color="primary" %}}
Этот подход работает **только в Excel 365 / 2021 или более поздней версии**. Более старые версии Excel не смогут корректно распределять формулы динамических массивов.
{{% /alert %}}

```python
import jpype
import asposecells
jpype.startJVM()
from asposecells.api import Workbook
from asposecells.api import Workbook, Worksheet, Cells, LoadOptions, LoadFormat, FormulaParseOptions, SaveFormat
# портированный код здесь
srcFile = "source.xlsx"
outFile = "output_transpose_dynamic.xlsx"
workbook = Workbook(srcFile, LoadOptions(LoadFormat.Xlsx))
worksheet = workbook.getWorksheets().get(0)
cells = worksheet.getCells()
cells.get("A6").setDynamicArrayFormula("=TRANSPOSE(A1:D5)", FormulaParseOptions(), True)
workbook.save(outFile, SaveFormat.Xlsx)
jpype.shutdownJVM()
```

## **Подход 3 — Транспонирование с классической формулой массива (CSE)**
Используйте этот подход, когда требуется сохранить формулу `TRANSPOSE` в рабочей книге, но целевой файл Excel может открываться в **более старых версиях Excel (до 2021, включая 2019, 2016, 2013 и т. д.)**, где динамическое распределение массивов не поддерживается. Классическая формула массива CSE (Ctrl+Shift+Enter) — это альтернативный вариант, совместимый с устаревшими версиями, который могут вычислять все версии Excel.

### **Используемый API**
`Cell.setArrayFormula(String arrayFormula, int nRows, int nColumns)` — метод класса `com.aspose.cells.Cell`, который присваивает **классическую формулу массива (CSE)** опорной ячейке и объявляет размерности результирующего массива. Aspose.Cells записывает маркер многоячеечной формулы массива, чтобы Excel вычислял формулу как одно массивное выражение, заполняющее объявленный диапазон.

### **Шаги**
1. Загрузите исходную рабочую книгу так же, как в предыдущих подходах.
2. Получите первый рабочий лист и доступ к его коллекции `Cells`.
3. Вызовите `cells.get("A6").setArrayFormula("=TRANSPOSE(A1:D5)", 4, 5)`. Второй аргумент `4` — количество строк результирующего массива, а третий аргумент `5` — количество столбцов.
4. Сохраните рабочую книгу с помощью `workbook.save(outputFile)`.
Ячейка **A6** является опорной для формулы массива, и вычисленный массив охватывает 4 строки и 5 столбцов, начиная с A6, что соответствует транспонированным размерностям источника A1:D5. Excel записывает единый маркер формулы массива по всему результирующему диапазону, чтобы более старые версии Excel корректно её вычисляли.

{{% alert color="primary" %}}
Формулы массива CSE — это классический способ Excel вычислить выражение `TRANSPOSE`, и этот подход универсально совместим со всеми версиями Excel.
{{% /alert %}}

```python
import jpype
import asposecells
jpype.startJVM()
from asposecells.api import Workbook
from asposecells.api import Workbook, LoadOptions, LoadFormat, Worksheet, Cells
# Загрузить исходную книгу с помощью параметров загрузки xlsx
srcFile = "source.xlsx"
workbook = Workbook(srcFile, LoadOptions(LoadFormat.Xlsx))
# Получить доступ к первому листу и его коллекции Cells
worksheet = workbook.getWorksheets().get(0)
cells = worksheet.getCells()
# Установить классическую CSE формулу массива в ячейке A6.
# Формула =TRANSPOSE(A1:D5) транспонирует исходный диапазон 5 строк x 4 столбца
# в массив 4 строки x 5 столбцов. Второй аргумент (4) — это количество строк
# а третий аргумент (5) — количество столбцов результирующего массива.
# Aspose.Cells записывает маркер CSE формулы массива, чтобы Excel вычислял её как
# единую многоячеечную формулу массива, совместимую со старыми версиями Excel
# (2019, 2016, 2013 и т.д.), которые не поддерживают динамическое распыление массива.
cells.get("A6").setArrayFormula("=TRANSPOSE(A1:D5)", 4, 5)
# Сохранить книгу, чтобы маркер формулы массива был сохранён
workbook.save("output.xlsx")
jpype.shutdownJVM()
```

## **Сравнение — Когда использовать каждый подход**
| Approach | API / Method | Excel Version | Source formula preserved? | Output range |
|----------|--------------|---------------|--------------------------|--------------|
| Подход 1 — Транспонирование на месте | `Range.transpose()` | Все версии Excel | Нет (только значения) | Тот же опорный диапазон, 5×4 |
| Подход 2 — Формула динамического массива | `Cell.setDynamicArrayFormula` | Excel 365 / 2021+ | Да (распределяется динамически) | Распределяется от опорной ячейки |
| Подход 3 — Классическая формула массива (CSE) | `Cell.setArrayFormula` | Все версии Excel | Да (многоячеечная формула массива) | Явный размер, 4×5 |
Используйте **Подход 1**, когда требуется быстрое кросс-версионное преобразование и нужно только записать транспонированные значения в файл. Используйте **Подход 2**, когда гарантировано использование современного Excel и требуется, чтобы формула оставалась живой и обновлялась при изменении источника. Используйте **Подход 3**, когда требуется максимальная совместимость с сохранённой формулой во всех версиях Excel, включая более старые выпуски, не поддерживающие динамические массивы.
