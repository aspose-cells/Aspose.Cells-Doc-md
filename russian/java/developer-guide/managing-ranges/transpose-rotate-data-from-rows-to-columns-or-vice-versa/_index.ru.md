{{% alert color="primary" %}}
Aspose.Cells for Java поддерживает транспонирование (поворот) данных, при котором строки становятся столбцами, а столбцы — строками, тремя различными способами. Первый подход использует метод на месте `Range.transpose()` и работает в любой версии Excel, тогда как второй применяет `Cell.setDynamicArrayFormula()` для записи современной формулы динамического массива `=TRANSPOSE(...)`, которая автоматически распределяется в Excel 365 или Excel 2021. Третий подход использует `Cell.setArrayFormula()` для записи классической формулы массива Ctrl+Shift+Enter (CSE), совместимой со старыми версиями Excel. В этой статье каждый подход рассматривается с пошаговыми инструкциями и полными примерами кода.
{{% /alert %}}

## **Введение**
Транспонирование диапазона означает его поворот таким образом, чтобы строка становилась столбцом, а столбец — строкой, эффективно отражая данные по главной диагонали. В Microsoft Excel эту операцию выполняет функция рабочего листа `TRANSPOSE`, концептуальная справка по которой задокументирована по адресу [https://support.microsoft.com/en-us/excel/functions/transpose-function](https://support.microsoft.com/en-us/excel/functions/transpose-function). Ту же идею можно применить программно к диапазону ячеек, что полезно во многих бизнес-сценариях и сценариях формирования отчётов.
К типичным сценариям, в которых полезно транспонирование, относятся следующие.
- Переориентация квартальных или годовых отчётов о продажах, где кварталы обычно располагаются по горизонтали страницы, а регионы — по вертикали, или наоборот.
- Изменение ориентации осей на информационных панелях или диаграммах таким образом, чтобы временной ряд располагался вертикально, а не горизонтально.
- Преобразование формы данных, импортированных из внешних систем, чтобы они соответствовали компоновке, ожидаемой шаблонами последующего анализа или отчётности.
Чтобы сделать дальнейшее изложение предметным, в каждом примере используется следующая небольшая таблица продаж по регионам и кварталам. В примере рабочей книги эта таблица занимает диапазон **A1:D5**, при этом ячейка **A1** оставлена пустой в качестве левого верхнего угла, в ячейках **B1:D1** расположены заголовки регионов, а в ячейках **A2:A5** — заголовки кварталов.
| Region            | Europe    | Asia      | North America |
|-------------------|-----------|-----------|---------------|
| Qtr 1             | 21704714  | 8774099   | 12094215      |
| Qtr 2             | 17987034  | 12214447  | 10873099      |
| Qtr 3             | 19485029  | 14356879  | 15689543      |
| Qtr 4             | 22567894  | 15763492  | 17456723      |
Далее в статье представлены три различных способа транспонирования этих данных с помощью Aspose.Cells for Java, каждый из которых подходит для определённой версии Excel и случая использования.

## **Подход 1 — Транспонирование диапазона на месте (Range.transpose)**
Используйте этот подход, когда требуется транспонировать данные без использования функции рабочего листа `TRANSPOSE`. Он работает в **любой версии Excel** и не зависит от динамических массивов, что делает его наиболее безопасным кросс-версионным вариантом. Он идеально подходит, когда нужен только конечный транспонированный результат и нет необходимости сохранять исходную формулу `TRANSPOSE` в рабочей книге.

### **Используемый API**
`Range.transpose()` — это метод экземпляра класса `com.aspose.cells.Range`. При его вызове диапазон переворачивается на месте путём обмена его строк и столбцов, так что строка становится столбцом, а столбец — строкой. Метод изменяет базовые ячейки напрямую, без записи формулы.

### **Шаги**
1. Откройте исходную рабочую книгу с `LoadOptions`, установленным в формат `.xlsx`, вызвав `new Workbook(srcFile, new LoadOptions(LoadFormat.Xlsx))`.
2. Получите первый рабочий лист из рабочей книги с помощью `workbook.getWorksheets().get(0)`.
3. Получите доступ к коллекции ячеек рабочего листа через `worksheet.getCells()`.
4. Создайте исходный диапазон, охватывающий **A1:D5**, вызвав `cells.createRange("A1:D5")`.
5. Вызовите `source.transpose()`, чтобы повернуть диапазон на месте, обменивая строки и столбцы.
6. Сохраните рабочую книгу с помощью `workbook.save(outputFile)`.
После транспонирования тот же опорный диапазон содержит повёрнутые данные. Первая строка читается как (пусто, **Europe**, **Asia**, **North America**), а первый столбец — как (пусто, **Qtr 1**, **Qtr 2**, **Qtr 3**, **Qtr 4**). Каждый исходный столбец продаж становится строкой в транспонированном диапазоне.

```java
import com.aspose.cells.*;
String srcFile = "source.xlsx";
String outputFile = "transposed.xlsx";
Workbook workbook = new Workbook(srcFile, new LoadOptions(LoadFormat.XLSX));
Worksheet worksheet = workbook.getWorksheets().get(0);
Cells cells = worksheet.getCells();
source.transpose();
workbook.save(outputFile);
```

## **Подход 2 — Транспонирование с помощью формулы динамического массива (Excel 365 / 2021)**
Используйте этот подход, когда требуется сохранить формулу `=TRANSPOSE(A1:D5)` в качестве действующей формулы в выходной рабочей книге, чтобы результат автоматически обновлялся при изменении исходных данных, а целевой файл Excel будет открываться в **Excel 365 / Excel 2021 или более поздней версии**, где поддерживаются динамические массивы и оператор распределения.

### **Используемый API**
`Cell.setDynamicArrayFormula(String formula, FormulaParseOptions options, boolean calculateValue)` — это метод класса `com.aspose.cells.Cell`, который задаёт формулу ячейки как **формулу динамического массива**. Excel вычисляет формулу один раз и автоматически распределяет результат в окружающие ячейки. Третий параметр, установленный в `true`, указывает Aspose.Cells также вычислить результирующие значения во время записи.

### **Шаги**
1. Загрузите исходную рабочую книгу с помощью `new Workbook(srcFile, new LoadOptions(LoadFormat.Xlsx))`.
2. Получите первый рабочий лист и доступ к его коллекции `Cells`.
3. Поместите формулу динамического массива в ячейку **A6**, непосредственно под исходным диапазоном, вызвав `cells.get("A6").setDynamicArrayFormula("=TRANSPOSE(A1:D5)", null, true)`.
4. Аргумент `null` передаёт `FormulaParseOptions` по умолчанию, а третий аргумент `true` указывает Aspose.Cells обрабатывать формулу как динамический массив и вычислить её, чтобы распределённые значения были записаны в рабочую книгу.
5. Сохраните рабочую книгу с помощью `workbook.save(outputFile)`.
Ячейка **A6** содержит формулу `=TRANSPOSE(A1:D5)`, и Excel автоматически распределяет результат в область **A6:D10** — блок размером 5 строк на 4 столбца, равный транспонированным данным.

{{% alert color="primary" %}}
Этот подход работает **только в Excel 365 / 2021 или более поздней версии**. В более старых версиях Excel формулы динамических массивов не распределяются корректно.
{{% /alert %}}

```java
import com.aspose.cells.*;
String srcFile = "source.xlsx";
String outFile = "output_transpose_dynamic.xlsx";
Workbook workbook = new Workbook(srcFile, new LoadOptions(LoadFormat.XLSX));
Worksheet worksheet = workbook.getWorksheets().get(0);
Cells cells = worksheet.getCells();
cells.get("A6").setDynamicArrayFormula("=TRANSPOSE(A1:D5)", new FormulaParseOptions(), true);
workbook.save(outFile, SaveFormat.XLSX);
```

## **Подход 3 — Транспонирование с помощью классической формулы массива (CSE)**
Используйте этот подход, когда требуется сохранить формулу `TRANSPOSE` в рабочей книге, но целевой файл Excel может быть открыт в **более старых версиях Excel (до 2021, включая 2019, 2016, 2013 и т. д.)**, где распределение динамических массивов не поддерживается. Классическая формула массива CSE (Ctrl+Shift+Enter) — это альтернатива, совместимая с предыдущими версиями, которую могут вычислить все версии Excel.

### **Используемый API**
`Cell.setArrayFormula(String arrayFormula, int nRows, int nColumns)` — это метод класса `com.aspose.cells.Cell`, который присваивает **классическую формулу массива (CSE)** опорной ячейке и объявляет размерности результирующего массива. Aspose.Cells записывает маркер многоячеечной формулы массива, чтобы Excel вычислял формулу как одно выражение массива, заполняющее объявленный диапазон.

### **Шаги**
1. Загрузите исходную рабочую книгу так же, как в предыдущих подходах.
2. Получите первый рабочий лист и доступ к его коллекции `Cells`.
3. Вызовите `cells.get("A6").setArrayFormula("=TRANSPOSE(A1:D5)", 4, 5)`. Второй аргумент `4` — это количество строк целевого массива, а третий аргумент `5` — количество столбцов.
4. Сохраните рабочую книгу с помощью `workbook.save(outputFile)`.
Ячейка **A6** является опорной точкой формулы массива, а вычисленный массив охватывает 4 строки на 5 столбцов, начиная с A6, что соответствует транспонированным размерностям источника A1:D5. Excel записывает единый маркер формулы массива по результирующему диапазону, чтобы старые версии Excel вычисляли его корректно.

{{% alert color="primary" %}}
Формулы массива CSE — это классический способ Excel для вычисления выражения `TRANSPOSE`, и этот подход универсально совместим со всеми версиями Excel.
{{% /alert %}}

```java
import com.aspose.cells.*;
// Загрузить исходную книгу с параметрами загрузки xlsx
String srcFile = "source.xlsx";
Workbook workbook = new Workbook(srcFile, new LoadOptions(LoadFormat.XLSX));
// Получить доступ к первому листу и его коллекции Cells
Worksheet worksheet = workbook.getWorksheets().get(0);
Cells cells = worksheet.getCells();
// Установить классическую формулу массива CSE в ячейке A6.
// Формула =TRANSPOSE(A1:D5) поворачивает исходный диапазон 5 строк x 4 столбца
// в массив 4 строки x 5 столбцов. Второй аргумент (4) — это количество строк
// а третий аргумент (5) — это количество столбцов результирующего массива.
// Aspose.Cells записывает маркер формулы массива CSE, чтобы Excel вычислял её как
// единую многоячеечную формулу массива, совместимую со старыми версиями Excel
// (2019, 2016, 2013 и т.д.), которые не поддерживают динамическое распыление массива.
cells.get("A6").setArrayFormula("=TRANSPOSE(A1:D5)", 4, 5);
// Сохранить книгу, чтобы маркер формулы массива был сохранён
workbook.save("output.xlsx");
```

## **Сравнение — когда использовать каждый подход**
| Подход | API / Метод | Версия Excel | Сохраняется ли исходная формула? | Выходной диапазон |
|--------|-------------|--------------|----------------------------------|-------------------|
| Подход 1 — Транспонирование на месте | `Range.transpose()` | Все версии Excel | Нет (только значения) | Тот же опорный диапазон, 5×4 |
| Подход 2 — Формула динамического массива | `Cell.setDynamicArrayFormula` | Excel 365 / 2021+ | Да (распределяется динамически) | Распределяется от опорной точки |
| Подход 3 — Классическая формула массива (CSE) | `Cell.setArrayFormula` | Все версии Excel | Да (многоячеечная формула массива) | Явный размер, 4×5 |
Используйте **Подход 1**, когда требуется быстрое кросс-версионное преобразование и нужно только записать транспонированные значения в файл. Используйте **Подход 2**, когда гарантировано использование современного Excel и требуется, чтобы формула оставалась действующей и обновлялась при изменении источника. Используйте **Подход 3**, когда нужна максимальная совместимость с сохранённой формулой во всех версиях Excel, включая старые выпуски, которые не поддерживают динамические массивы.
