{{% alert color="primary" %}}
Aspose.Cells for Java предлагает три разных способа транспонирования (поворота) данных, при которых строки становятся столбцами, а столбцы — строками. Первый подход использует метод `Range.transpose()`, изменяющий диапазон на месте, и подходит для всех версий Excel. Второй подход использует `Cell.setDynamicArrayFormula()` для записи современной формулы динамического массива `=TRANSPOSE(...)`, результат которой автоматически распространяется на соседние ячейки в Excel 365 или Excel 2021. Третий подход использует `Cell.setArrayFormula()` для записи классической формулы массива Ctrl+Shift+Enter (CSE), совместимой с более старыми версиями Excel. В этой статье каждый подход рассматривается пошагово и сопровождается полными примерами кода.
{{% /alert %}}

## **Введение**
Транспонирование диапазона означает его поворот таким образом, чтобы строки становились столбцами, а столбцы — строками, то есть данные отражались относительно главной диагонали. В Microsoft Excel эту операцию выполняет функция рабочего листа `TRANSPOSE`, справочная информация о которой доступна по адресу [https://support.microsoft.com/en-us/excel/functions/transpose-function](https://support.microsoft.com/en-us/excel/functions/transpose-function). Эту операцию можно программно применять к диапазону ячеек, что полезно во многих сценариях бизнеса и отчетности.
- Изменение ориентации квартальных или годовых отчетов о продажах, в которых кварталы обычно располагаются поперек страницы, а регионы — вдоль нее, или наоборот.
- Изменение ориентации осей на дашбордах или диаграммах, чтобы временной ряд располагался вдоль страницы, а не поперек нее.
- Преобразование данных, импортированных из внешних систем, чтобы они соответствовали структуре, необходимой для последующего анализа или шаблонам отчетности.
Чтобы сделать дальнейшие примеры наглядными, в каждом из них используется небольшая таблица продаж по регионам и кварталам. В демонстрационной рабочей книге эта таблица занимает диапазон **A1:D5**, причем **A1** оставлен пустым; это верхний левый угол таблицы. **B1:D1** содержит заголовки регионов, а **A2:A5** — заголовки кварталов.
| Регион | Европа | Азия | Северная Америка |
|-------------------|-----------|-----------|---------------|
| 1-й квартал | 21704714 | 8774099 | 12094215 |
| 2-й квартал | 17987034 | 12214447 | 10873099 |
| 3-й квартал | 19485029 | 14356879 | 15689543 |
| 4-й квартал | 22567894 | 15763492 | 17456723 |
Затем в статье представлены три разных способа транспонирования этих данных с помощью Aspose.Cells for Java, каждый из которых подходит для определенной версии Excel и сценария использования.

## **Подход 1 — Транспонирование диапазона на месте (Range.transpose)**
Используйте этот подход, если необходимо транспонировать данные без применения функции рабочего листа `TRANSPOSE`. Он работает во **всех версиях Excel** и не зависит от динамических массивов, поэтому считается наиболее безопасным вариантом с точки зрения совместимости. Этот подход идеален, когда требуется только получить итоговый транспонированный результат и при этом не нужно сохранять исходную формулу `TRANSPOSE` в рабочей книге.

### **Используемый API**
`Range.transpose()` — метод экземпляра класса `com.aspose.cells.Range`. При его вызове диапазон изменяется на месте: строки и столбцы меняются местами, поэтому строки становятся столбцами, а столбцы — строками. Метод напрямую изменяет базовые ячейки, не записывая формулу.

### **Шаги**
1. Откройте исходную рабочую книгу с помощью объекта `LoadOptions`, настроенного на формат `.xlsx`, вызвав `new Workbook(srcFile, new LoadOptions(LoadFormat.Xlsx))`.
2. Получите первый рабочий лист рабочей книги с помощью `workbook.getWorksheets().get(0)`.
3. Получите доступ к коллекции ячеек рабочего листа через `worksheet.getCells()`.
4. Создайте исходный диапазон, охватывающий **A1:D5**, вызвав `cells.createRange("A1:D5")`.
5. Вызовите `source.transpose()`, чтобы транспонировать диапазон на месте, поменяв местами строки и столбцы.
6. Сохраните рабочую книгу с помощью `workbook.save(outputFile)`.
После транспонирования исходный диапазон с той же начальной ячейкой содержит транспонированные данные. Первая строка содержит значения (пусто, **Европа**, **Азия**, **Северная Америка**), а первый столбец — (пусто, **1-й квартал**, **2-й квартал**, **3-й квартал**, **4-й квартал**). Каждый исходный столбец с данными о продажах становится строкой транспонированного диапазона.

```java
import com.aspose.cells.*;
String srcFile = "source.xlsx";
String outputFile = "transposed.xlsx";
Workbook workbook = new Workbook(srcFile, new LoadOptions(LoadFormat.XLSX));
Worksheet worksheet = workbook.getWorksheets().get(0);
Cells cells = worksheet.getCells();
Range source = cells.createRange("A1:D5");
source.transpose();
workbook.save(outputFile);
```

## **Подход 2 — Транспонирование с помощью формулы динамического массива (Excel 365 / 2021)**
Используйте этот подход, если необходимо сохранить формулу `=TRANSPOSE(A1:D5)` в итоговой рабочей книге и оставить ее активной, чтобы результат автоматически обновлялся при изменении исходных данных. Этот подход подходит, если целевой файл Excel будет открываться в **Excel 365 / Excel 2021 или более поздней версии**, где поддерживаются динамические массивы и оператор раскрытия.

### **Используемый API**
`Cell.setDynamicArrayFormula(String formula, FormulaParseOptions options, boolean calculateValue)` — метод класса `com.aspose.cells.Cell`, который устанавливает в ячейке **формулу динамического массива**. Excel вычисляет такую формулу один раз и автоматически распространяет результат на соседние ячейки. Если третий параметр установлен в `true`, Aspose.Cells также вычисляет полученные значения при записи файла.

### **Шаги**
1. Загрузите исходную рабочую книгу с помощью `new Workbook(srcFile, new LoadOptions(LoadFormat.Xlsx))`.
2. Получите первый рабочий лист и доступ к его коллекции `Cells`.
3. Разместите формулу динамического массива в ячейке **A6**, непосредственно под исходным диапазоном, вызвав `cells.get("A6").setDynamicArrayFormula("=TRANSPOSE(A1:D5)", null, true)`.
4. Аргумент `null` указывает использовать параметры `FormulaParseOptions` по умолчанию, а третий аргумент `true` сообщает Aspose.Cells обработать формулу как формулу динамического массива и вычислить ее, чтобы значения, полученные в результате раскрытия формулы, были записаны в рабочую книгу.
5. Сохраните рабочую книгу с помощью `workbook.save(outputFile)`.
Ячейка **A6** содержит формулу `=TRANSPOSE(A1:D5)`, а Excel автоматически распространяет результат на область **A6:D10** — блок из 5 строк и 4 столбцов, соответствующий транспонированным данным.

{{% alert color="primary" %}}
Этот подход работает **только в Excel 365 / 2021 или более поздних версиях**. Более старые версии Excel не выполняют корректное раскрытие формул динамических массивов.
{{% /alert %}}

```java
import com.aspose.cells.*;
String srcFile = "source.xlsx";
String outFile = "output_transpose_dynamic.xlsx";
Workbook workbook = new Workbook(srcFile, new LoadOptions(LoadFormat.XLSX));
Worksheet worksheet = workbook.getWorksheets().get(0);
Cells cells = worksheet.getCells();
cells.get("A6").setDynamicArrayFormula("=TRANSPOSE(A1:D5)", new FormulaParseOptions(), true);
workbook.save(outFile, SaveFormat.XLSX);
```

## **Подход 3 — Транспонирование с помощью классической формулы массива (CSE)**
Используйте этот подход, если необходимо сохранить формулу `TRANSPOSE` в рабочей книге, а целевой файл Excel может открываться в **более старых версиях (до 2021 года, включая 2019, 2016, 2013 и т. д.)**, где не поддерживается раскрытие формул динамических массивов. Классическая формула массива CSE (Ctrl+Shift+Enter) — это совместимая с предыдущими версиями альтернатива, которую могут вычислять все версии Excel.

### **Используемый API**
`Cell.setArrayFormula(String arrayFormula, int nRows, int nColumns)` — метод класса `com.aspose.cells.Cell`, который устанавливает в начальной ячейке **классическую формулу массива (CSE)** и задает размеры результирующего массива. Aspose.Cells записывает маркер формулы массива для нескольких ячеек, чтобы Excel вычислял формулу как единое выражение массива, заполняющее указанный диапазон.

### **Шаги**
1. Загрузите исходную рабочую книгу, как описано в предыдущих подходах.
2. Получите первый рабочий лист и доступ к его коллекции `Cells`.
3. Вызовите `cells.get("A6").setArrayFormula("=TRANSPOSE(A1:D5)", 4, 5)`. Второй аргумент `4` задает количество строк целевого массива, а третий аргумент `5` — количество столбцов.
4. Сохраните рабочую книгу с помощью `workbook.save(outputFile)`.
Ячейка **A6** является начальной ячейкой формулы массива, а вычисленный массив занимает 4 строки и 5 столбцов, начиная с A6, что соответствует транспонированным размерам исходного диапазона A1:D5. Excel записывает единый маркер формулы массива для полученного диапазона, поэтому более старые версии Excel корректно вычисляют формулу.

{{% alert color="primary" %}}
Формулы массива CSE — это классический способ вычисления выражения `TRANSPOSE` в Excel, и данный подход совместим со всеми версиями Excel.
{{% /alert %}}

```java
import com.aspose.cells.*;
// Загрузить исходную книгу с помощью LoadOptions для XLSX
String srcFile = "source.xlsx";
Workbook workbook = new Workbook(srcFile, new LoadOptions(LoadFormat.XLSX));
// Получить доступ к первому листу и его коллекции Cells
Worksheet worksheet = workbook.getWorksheets().get(0);
Cells cells = worksheet.getCells();
// Установить классическую формулу массива CSE в ячейке A6.
// Формула =TRANSPOSE(A1:D5) транспонирует исходный диапазон 5 строк x 4 столбца
// в массив 4 строки x 5 столбцов. Второй аргумент (4) задает количество строк,
// а третий аргумент (5) — количество столбцов результирующего массива.
// Aspose.Cells записывает маркер формулы массива CSE, чтобы Excel вычислял ее как
// единую формулу массива для нескольких ячеек, совместимую с более старыми версиями Excel
// (2019, 2016, 2013 и т. д.), которые не поддерживают динамическое распространение массивов.
cells.get("A6").setArrayFormula("=TRANSPOSE(A1:D5)", 4, 5);
// Сохранить книгу, чтобы маркер формулы массива был сохранен
workbook.save("output.xlsx");
```

## **Сравнение — Когда использовать каждый подход**
| Подход | API / метод | Версия Excel | Сохранена формула источника? | Выходной диапазон |
|----------|--------------|---------------|--------------------------|--------------|
| Подход 1 — Транспонирование на месте | `Range.transpose()` | Все версии Excel | Нет (только значения) | Начальный диапазон, 5×4 |
| Подход 2 — Формула динамического массива | `Cell.setDynamicArrayFormula` | Excel 365 / 2021+ | Да (динамическое раскрытие) | Раскрывается от начальной ячейки |
| Подход 3 — Классическая формула массива (CSE) | `Cell.setArrayFormula` | Все версии Excel | Да (формула массива для нескольких ячеек) | Явный размер, 4×5 |
Используйте **Подход 1**, если необходимо быстро выполнить преобразование, совместимое с любой версией Excel, и записать в файл только транспонированные значения. Используйте **Подход 2**, если точно известно, что будет использоваться современная версия Excel, и формула должна оставаться активной и обновляться при изменении источника. Используйте **Подход 3**, если необходима максимальная совместимость при сохранении формулы во всех версиях Excel, включая более старые выпуски, не поддерживающие динамические массивы.
