Камера Excel — это объект рабочего листа, который отображает динамическое изображение диапазона ячеек и располагается на слое графических объектов как обычный рисунок. Aspose.Cells поддерживает два способа создания: динамическое изображение, которое автоматически обновляется при изменении исходных данных, и статическое изображение, содержащее однократный снимок диапазона. В этой статье рассматриваются оба подхода, чтобы вы могли выбрать подходящий вариант.

## Что такое Камера Excel?
Камера Excel по сути представляет собой объект рисунка, привязанный к определённой строке и столбцу на слое графических объектов рабочего листа. В отличие от обычной вставленной картинки, Камера связана с исходным диапазоном посредством формулы в стиле A1, например `"A1:F10"`. При изменении любой ячейки этого диапазона изображение Камеры автоматически обновляется, отражая новое содержимое. Камера сохраняет всё форматирование исходной области — границы, цвета фона, шрифты и числовые форматы, — поэтому всё, что отображается в ячейках, появляется и на изображении Камеры. Благодаря этому Камера особенно полезна для информационных панелей, сводок, боковых панелей и макетов отчётов, где требуется предварительно просматривать содержимое другой области без прокрутки или дублирования данных. Необходимо учитывать два момента: перед сохранением рабочей книги следует вызвать `updateSelectedValue()`, а файл необходимо экспортировать в HTML или PDF, поскольку в этих форматах используются встроенные данные изображения, а не пересчёт в реальном времени.

## Метод 1 — Добавление динамической Камеры
Динамическая Камера — наиболее распространённый подход, максимально близкий к встроенному инструменту «Камера» в Excel. Для этого добавляется рисунок без начального изображения, а затем ему назначается свойство `Formula`, содержащее ссылку на исходный диапазон. После назначения формулы вызов `updateSelectedValue()` обновляет встроенные данные изображения, синхронизируя их с отображаемыми ячейками. Камера не реализована с помощью отдельного класса — она полностью основана на стандартном типе `Picture`.
Основные API:
- `PictureCollection.add(int upperLeftRow, int upperLeftColumn, InputStream stream)` — добавляет рисунок, привязанный к заданным строке и столбцу. Передача `null` для параметра `stream` создаёт пустой рисунок, используемый в качестве заполнителя для динамической Камеры. Метод возвращает индекс нового рисунка.
- `worksheet.getPictures().get(index)` — получение определённого объекта `Picture` из коллекции по индексу.
- `Picture.Formula` — строковое свойство (`getFormula()`/`setFormula()`), содержащее ссылку в стиле A1 на исходный диапазон, отображаемый Камерой, например `"A1:F10"`.
- `Picture.updateSelectedValue()` — метод без возвращаемого значения, обновляющий встроенные данные изображения на основе ячеек, на которые ссылается `Formula`.

{{% alert color="primary" %}}
Перед сохранением документа необходимо вызвать `updateSelectedValue()`, если итоговый файл экспортируется в формат HTML или PDF. В противном случае экспортированный файл не будет содержать данных изображения, а при отображении Камера будет пустой.
{{% /alert %}}

Следующий код создаёт рабочую книгу, добавляет пустой рисунок в позиции на пересечении строки 10 и столбца 6, связывает его с исходным диапазоном `A1:F10` посредством свойства `Formula`, обновляет встроенные данные изображения и сохраняет рабочую книгу.

```javascript
const aspose = require("aspose.cells");
let workbook = new aspose.Workbook();
let worksheet = workbook.getWorksheets().get(0);
worksheet.setName("CameraDemo");
// Динамическая камера: добавить пустое изображение, связать его через формулу с A1:F10, затем обновить
let pictures = worksheet.getPictures();
let index = pictures.add(10, 6, null);
pictures.get(index).setFormula("A1:F10");
pictures.get(index).updateSelectedValue();
workbook.save("output_dynamic.xlsx", aspose.SaveFormat.XLSX);
```

## Метод 2 — Добавление статической Камеры
Статическая Камера по сути представляет собой однократно сформированное предварительное изображение диапазона ячеек. Вместо создания динамической связи диапазон однократно визуализируется в массив байтов изображения. Эти байты передаются в `ByteArrayInputStream`, после чего рисунок добавляется как обычный. Содержимое изображения фиксируется в момент создания и не обновляется автоматически при изменении исходных ячеек.
Основные API:
- `Cells.createRange(String address)` — создаёт объект `Range` по адресу в стиле A1, например `"A1:F10"`.
- `Range.toImage(ImageOrPrintOptions options)` — визуализирует диапазон в массив байтов изображения. Передача `null` использует параметры визуализации по умолчанию; для более точной настройки параметров вывода существуют перегруженные варианты метода.
- `new ByteArrayInputStream(byte[] buffer)` — передаёт байты визуализированного изображения в `ByteArrayInputStream`, который можно использовать в `PictureCollection.add`.
- `PictureCollection.add(int upperLeftRow, int upperLeftColumn, InputStream stream)` — добавляет рисунок, привязанный к заданным строке и столбцу; при этом в метод передаётся `ByteArrayInputStream`, полученный в результате визуализации.
Следующий код создаёт рабочую книгу, формирует `Range` для `A1:F10`, визуализирует его в массив байтов изображения с помощью `range.toImage(null)`, передаёт байты в `ByteArrayInputStream`, добавляет рисунок в позиции на пересечении строки 10 и столбца 6 и сохраняет рабочую книгу.

```javascript
const aspose = require("aspose.cells");
let workbook = new aspose.Workbook();
let worksheet = workbook.getWorksheets().get(0);
worksheet.setName("CameraDemo");
// Статичная камера: создаём Range, рендерим в байты, оборачиваем в ByteArrayInputStream, добавляем как изображение
let range = worksheet.getCells().createRange("A1:F10");
let imageBytes = range.toImage(null);
let pictures = worksheet.getPictures();
pictures.add(10, 6, new aspose.ByteArrayInputStream(imageBytes));
workbook.save("output_static.xlsx", aspose.SaveFormat.XLSX);
```

## Выбор между динамической и статической Камерой
- **Динамическая Камера:** обновляется при каждом пересчёте, поддерживает экспорт в HTML и PDF после вызова `updateSelectedValue()` и сохраняет динамическую связь на протяжении всего срока существования файла.
- **Статическая Камера:** однократная визуализация без последующего обновления. Такой вариант полезен, если при создании файла требуется встроить фиксированный снимок, а не динамическое отображение данных.
Aspose.Cells поддерживает как динамическую, автоматически обновляемую Камеру, построенную на `Picture.Formula` и `updateSelectedValue()`, так и статическую Камеру для однократной визуализации, построенную на `Range.toImage` и `ByteArrayInputStream`. Выбирайте динамический подход, если выходной файл должен оставаться синхронизированным с исходными ячейками, и статический подход, если при формировании файла достаточно фиксированного визуального снимка.
