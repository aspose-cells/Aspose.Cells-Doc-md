## **Возможные сценарии использования**
- Группировка полей сводной таблицы полезна, когда поле строки или столбца сводной таблицы содержит множество различных значений, например поле даты с сотнями дат или числовое поле с большим количеством разрозненных значений. Группировка объединяет эти значения в осмысленные разделы: даты — в месяцы, кварталы и годы, а числа — в диапазоны, такие как 0-1, 2-3, 4-5. Это делает большую сводную таблицу компактной и более удобной для анализа. Aspose.Cells предоставляет эту возможность через метод `PivotField.Group()` (автоматическая группировка по типу данных) и `PivotField.Group(PivotFieldGroupOptions)` (пользовательские параметры группировки).
- Группировка по датам объединяет отдельные даты в более крупные периоды, такие как дни, месяцы, кварталы и годы, и формирует временную иерархию (например, «Годы», «Кварталы», «Месяцы»). Тенденции во времени становятся видны с первого взгляда, и каждый уровень периода становится отдельным полем сводной таблицы в области строк или столбцов сводной таблицы.
- Группировка доступна только для полей, размещённых в области СТРОК или СТОЛБЦОВ сводной таблицы. Поле данных (значения) нельзя сгруппировать напрямую. Чтобы сгруппировать такое поле, необходимо сначала добавить его в область строк или столбцов сводной таблицы.

## **Автоматическая группировка полей сводной таблицы**
Перегрузка `PivotField.Group()` без параметров анализирует тип данных поля и группирует его автоматически. Поле, содержащее только даты (и пустые значения), группируется по месяцам. Поле, содержащее только числа (и пустые значения), группируется в числовые диапазоны с использованием автоматического интервала.

```csharp
using Aspose.Cells.Pivot;
// Загрузить образец книги
Workbook wb = new Workbook("sampleGroupPivotFieldsInPivotTable.xlsx");
// Получить доступ ко второму рабочему листу и его сводной таблице
PivotTable pt = wb.Worksheets[1].PivotTables[0];
// Сгруппировать первое поле строки автоматически.
// Поле содержит даты, поэтому оно группируется по месяцам.
PivotField field = pt.RowFields[0];
field.Group();
// Вычислить данные сводной таблицы и сохранить выходной файл
pt.CalculateData();
wb.Save("outputAutoGroupPivotField.xlsx");
```

## **Группировка полей сводной таблицы с пользовательскими параметрами**
Класс `PivotFieldGroupOptions` предоставляет пользовательскую конфигурацию группировки. Для полей дат задайте `StartDate`, `EndDate` и `GroupTypes`. Для числовых полей задайте `StartNumber`, `EndNumber` и `Interval`. Свойство `NewPivotField` управляет тем, создаёт ли группировка новые поля сводной таблицы рядом с исходным (см. раздел «Примечание» в конце этой статьи).

### **Группировка поля даты по месяцам и кварталам**
Следующий пример группирует поле строки с датами образца сводной таблицы по месяцам и кварталам в пределах начальной и конечной даты. Код загружает [образец Excel-файла](sampleGroupPivotFieldsInPivotTable.xlsx), выполняет группировку, вычисляет данные сводной таблицы и сохраняет сгруппированный результат. На снимке экрана показан результат: поле строки с датами теперь сгруппировано по кварталам и месяцам.
Обратите внимание, что порядок значений в `options.GroupTypes` игнорируется. Независимо от того, в каком порядке перечислены типы групп, сгруппированные поля всегда отображаются от самого крупного периода к самому мелкому: годы, кварталы, месяцы, дни, часы, минуты, секунды. В этом примере месяцы перечислены перед кварталами в `options.GroupTypes`, однако кварталы отображаются как внешний уровень, а месяцы — как внутренний.

```csharp
using Aspose.Cells.Pivot;
// Загрузить образец книги
Workbook wb = new Workbook("sampleGroupPivotFieldsInPivotTable.xlsx");
// Получить доступ ко второму рабочему листу и его сводной таблице
PivotTable pt = wb.Worksheets[1].PivotTables[0];
// Сгруппировать первое поле строки (поле даты) по месяцам и кварталам
PivotFieldGroupOptions options = new PivotFieldGroupOptions();
options.StartDate = new DateTime(2008, 1, 1);
options.EndDate = new DateTime(2008, 9, 5);
options.GroupTypes = new PivotGroupByType[] { PivotGroupByType.Months, PivotGroupByType.Quarters };
pt.RowFields[0].Group(options);
// Рассчитать данные сводной таблицы и сохранить выходной файл
pt.CalculateData();
wb.Save("outputGroupPivotFieldsInPivotTable.xlsx");
```

### **Группировка числового поля в диапазоны**
`FieldTwo` образца сводной таблицы изначально является полем данных (значения). Поскольку группировать можно только поля строк или столбцов, код сначала вызывает `PivotTable.AddFieldToArea(PivotFieldType.Row, "FieldTwo")`, чтобы переместить `FieldTwo` в область строк, обновляет сводную таблицу, а затем группирует числовое поле в диапазоны 0-1, 2-3 и 4-5, используя `StartNumber = 0`, `EndNumber = 5` и `Interval = 2`.

```csharp
using Aspose.Cells.Pivot;
// Загрузить образец книги
Workbook wb = new Workbook("sampleGroupPivotFieldsInPivotTable.xlsx");
// Получить доступ ко второму листу и его сводной таблице
PivotTable pt = wb.Worksheets[1].PivotTables[0];
// FieldTwo является полем данных: сначала переместить его в область строк,
// поскольку группировать можно только поля строк/столбцов
pt.AddFieldToArea(PivotFieldType.Row, "FieldTwo");
pt.CalculateData();
// Сгруппировать числовое поле по диапазонам 0-1, 2-3, 4-5
PivotFieldGroupOptions options = new PivotFieldGroupOptions();
options.StartNumber = 0;
options.EndNumber = 5;
options.Interval = 2;
pt.RowFields[1].Group(options);
// Вычислить данные сводной таблицы и сохранить выходной файл
pt.CalculateData();
wb.Save("outputNumberGroupPivotField.xlsx");
```

## **Примечание**

{{% alert color="primary" %}}
- Перегрузки метода `PivotField.GroupBy()` устарели и удалены из API. `PivotField.Group()` и `PivotField.Group(PivotFieldGroupOptions)` являются их заменой.
- В Microsoft Excel при группировке числового поля исходное поле сводной таблицы ЗАМЕНЯЕТСЯ сгруппированными диапазонами, тогда как при группировке поля даты создаются НОВЫЕ поля сводной таблицы (по одному для каждого уровня группы, например «Кварталы» и «Месяцы») рядом с исходным полем. Начиная с Aspose.Cells 26.10 методы `PivotField.Group()` следуют тому же поведению, что и Excel. Свойство `PivotFieldGroupOptions.NewPivotField` существует для совместимости со старыми версиями: по умолчанию оно имеет значение false для числовой группировки и true для группировки по дате и времени; установите его в значение false, если требуется, чтобы при группировке по дате исходное поле сводной таблицы заменялось, а не создавались новые поля.
- Свойство `PivotFieldGroupOptions.Interval` действует только для числовой группировки и для группировки дат по дням (например, группировка дат в 7-дневные периоды); оно игнорируется при группировке дат по месяцам, кварталам или годам.
{{% /alert %}}
