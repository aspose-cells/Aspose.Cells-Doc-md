{{% alert color="primary" %}}
Aspose.Cells поддерживает разделение одного файла Excel на несколько файлов. Существует два основных способа: (1) копирование каждого рабочего листа исходной рабочей книги в новую рабочую книгу с сохранением полученной книги в отдельный файл и (2) копирование определенного диапазона ячеек из рабочего листа в новую рабочую книгу. Оба подхода полезны, если необходимо разбить данные на подмножества, создать небольшие отчеты для разных получателей или изолировать данные для их отдельной обработки.
{{% /alert %}}

## **Введение
Существует множество реальных сценариев, в которых разработчику необходимо разбить один файл Excel на несколько меньших файлов. Например, рабочая книга может содержать по одному рабочему листу для каждого подразделения, при этом каждому руководителю подразделения необходимо получить только свой лист. В других случаях может потребоваться извлечь определенную таблицу или блок данных из рабочего листа и отправить его в виде отдельного файла по электронной почте, не раскрывая остальные сведения о рабочей книге. Большие консолидированные рабочие книги также могут потребовать разделения на меньшие части для упрощения обработки, ускорения загрузки и последующей обработки другими системами.
Aspose.Cells предлагает два гибких подхода к решению этой задачи. Первый подход предусматривает перебор всех рабочих листов исходной рабочей книги и копирование содержимого каждого листа в новый экземпляр `Workbook`, после чего каждый экземпляр сохраняется в отдельный файл. Второй подход ориентирован на определенный диапазон ячеек в пределах рабочего листа и копирует только этот диапазон в новую рабочую книгу. В обоих случаях общий порядок действий одинаков: загрузить исходную рабочую книгу с помощью класса `Workbook`, получить доступ к необходимым данным через объекты `Worksheet` и `Cells`, передать содержимое в целевую рабочую книгу `Workbook`, а затем сохранить целевую рабочую книгу на диск.

## **Разделение файла Excel путем копирования каждого рабочего листа в новую рабочую книгу

### **Обзор подхода
В рамках этого подхода исходная рабочая книга открывается один раз, после чего для каждого `Worksheet` в ее коллекции `Worksheets` создается новый целевой объект `Workbook`. Содержимое исходного рабочего листа копируется в первый рабочий лист целевой рабочей книги, после чего целевая рабочая книга сохраняется в файле, имя которого формируется на основе имени исходного рабочего листа. В результате для каждого рабочего листа создается отдельный выходной файл, содержащий данные только одного соответствующего исходного листа.
Этот метод подходит, если каждый рабочий лист исходной рабочей книги представляет собой логически независимую единицу информации, например подразделение, регион, месяц или товарную линию, которую необходимо передать или обработать отдельно.

### **Шаги
Следующие шаги описывают, как разделить файл Excel путем копирования каждого рабочего листа в новую рабочую книгу:
1. Открыть исходный файл Excel, создав объект `Workbook` и передав путь к файлу в его конструктор.
2. Перебрать коллекцию `Workbook.Worksheets` с помощью цикла `for` или `foreach`, чтобы обработать каждый `Worksheet` исходного файла.
3. Внутри цикла создать новый экземпляр `Workbook` (пустую рабочую книгу) для текущего рабочего листа.
4. Скопировать содержимое исходного рабочего листа в целевой рабочий лист. Это можно сделать путем перебора ячеек коллекции `Cells` исходного рабочего листа и записи их значений в соответствующие ячейки целевого рабочего листа либо с помощью метода `Cells.Copy` для копирования всего диапазона целиком.
5. Сформировать путь к выходному файлу, содержащий имя исходного рабочего листа, например `dataDir + worksheet.Name + ".xls"`, чтобы каждый созданный файл имел уникальное имя.
6. Вызвать метод `Workbook.Save` целевой рабочей книги, чтобы записать файл на диск.
7. Повторить шаги 3–6 для следующего рабочего листа, пока не будут обработаны все рабочие листы.

### **Пример кода

```csharp
using System;
using System.IO;
using Aspose.Cells;
string dataDir = "data/";
Workbook workbook = new Workbook(dataDir + "book1.xls");
for (int i = 0; i < workbook.Worksheets.Count; i++)
{
    Worksheet sourceSheet = workbook.Worksheets[i];
    string sheetName = sourceSheet.Name;
    
    Workbook destWorkbook = new Workbook();
    int destIndex = destWorkbook.Worksheets.Add();
    Worksheet destSheet = destWorkbook.Worksheets[destIndex];
    destSheet.Name = sheetName;
    
    destSheet.Copy(sourceSheet);
    
    string destFile = dataDir + sheetName + ".xls";
    destWorkbook.Save(destFile, SaveFormat.Excel97To2003);
}
```

Ожидаемый результат — набор новых файлов в каталоге данных, по одному файлу для каждого рабочего листа исходной рабочей книги. Каждый файл получает имя соответствующего исходного листа и содержит только данные этого листа и, при необходимости, его форматирование.

## **Разделение файла Excel путем копирования диапазона в новую рабочую книгу

### **Обзор подхода
Иногда данные, которые необходимо выделить, не занимают весь рабочий лист, а находятся в определенной прямоугольной области, например `A1:D10`, или представлены именованным диапазоном, соответствующим конкретной таблице. В таких случаях копирование целых рабочих листов нецелесообразно и требуется более точный подход: определить исходный диапазон, скопировать только его в новую рабочую книгу и сохранить новый файл.
Этот подход подходит, если требуется извлечь из большого рабочего листа отдельную таблицу, блок отчета или область данных, отбросив все остальное содержимое. Он также полезен для экспорта выбранных пользователем областей рабочего листа в отдельные файлы.

### **Шаги
Следующие шаги описывают, как разделить файл Excel путем копирования определенного диапазона в новую рабочую книгу:
1. Открыть исходный файл Excel, создав объект `Workbook` и передав путь к файлу.
2. Получить целевой объект `Worksheet`, содержащий копируемый диапазон, из коллекции `Worksheets` по индексу, например выбрав первый лист, или по имени.
3. Определить копируемый диапазон. Это может быть фиксированный диапазон ячеек, например `A1:C10`, именованный диапазон, полученный через коллекцию `Worksheet.Cells`, либо диапазон, созданный с помощью `Worksheet.Cells.CreateRange`.
4. Создать новый экземпляр целевой рабочей книги `Workbook`.
5. Получить доступ к первому объекту `Worksheet` целевой рабочей книги, то есть к рабочему листу по умолчанию.
6. Скопировать исходный диапазон в целевой рабочий лист, разместив его, как правило, начиная с ячейки `A1`. Для копирования всего диапазона можно использовать метод `Cells.Copy` коллекции `Cells` целевого рабочего листа. Также можно перебрать ячейки исходного диапазона и записать их значения в целевые ячейки с помощью `PutValue`. При необходимости можно передать необязательный объект `CopyOptions`, определяющий состав переносимых данных, например только значения, значения и стили, формулы и т. д.
7. Сохранить целевую рабочую книгу по новому пути на диске с помощью метода `Workbook.Save`.

### **Пример кода
Ожидаемый результат — один новый файл в каталоге данных, содержащий только значения указанного диапазона, извлеченного из исходной рабочей книги, а также, при необходимости, его форматирование. Целевой файл содержит только извлеченный диапазон, начиная с ячейки `A1` первого рабочего листа, и не включает другие данные исходного файла.
