{{% alert color="primary" %}}
Aspose.Cells for .NET поддерживает транспонирование (поворот) данных так, чтобы строки становились столбцами, а столбцы — строками, тремя различными способами. Первый подход использует метод `Range.Transpose()` для транспонирования на месте и работает в любой версии Excel, тогда как второй применяет `Cell.SetDynamicArrayFormula()` для записи современной формулы динамического массива `=TRANSPOSE(...)`, которая автоматически «проливается» в Excel 365 или Excel 2021. Третий подход использует `Cell.SetArrayFormula()` для записи классической формулы массива, вводимой сочетанием Ctrl+Shift+Enter (CSE), совместимой со старыми версиями Excel. В этой статье каждый подход рассматривается пошагово с полными примерами кода.
{{% /alert %}}

## **Введение**
Транспонирование диапазона означает его поворот так, чтобы то, что было строкой, стало столбцом, а то, что было столбцом, — строкой, фактически отражая данные относительно их главной диагонали. В Microsoft Excel эту операцию выполняет функция рабочего листа `TRANSPOSE`, а её концептуальное описание приведено по ссылке [https://support.microsoft.com/en-us/excel/functions/transpose-function](https://support.microsoft.com/en-us/excel/functions/transpose-function). Ту же идею можно применить программно к диапазону ячеек, что полезно во множестве бизнес-сценариев и сценариев формирования отчётности.
Типичные сценарии, в которых транспонирование оказывается полезным, перечислены ниже.
- Изменение ориентации квартальных или годовых отчётов о продажах, в которых кварталы обычно расположены поперёк страницы, а регионы — вдоль, или наоборот.
- Смена ориентации осей в дашбордах или диаграммах, чтобы временной ряд шёл вдоль страницы, а не поперёк.
- Изменение формы данных, импортированных из внешних систем, чтобы они соответствовали компоновке, заданной шаблонами последующего анализа или отчётности.
Чтобы сделать дальнейшие примеры конкретными, во всех случаях используется следующая небольшая таблица продаж по регионам и кварталам. В демонстрационной рабочей книге эта таблица занимает диапазон **A1:D5**, при этом ячейка **A1** оставлена пустой в качестве левого верхнего угла, ячейки **B1:D1** содержат заголовки регионов, а ячейки **A2:A5** — заголовки кварталов.
| Регион           | Европа     | Азия       | Северная Америка |
|------------------|-----------|-----------|------------------|
| Квартал 1        | 21704714  | 8774099   | 12094215         |
| Квартал 2        | 17987034  | 12214447  | 10873099         |
| Квартал 3        | 19485029  | 14356879  | 15689543         |
| Квартал 4        | 22567894  | 15763492  | 17456723         |
Далее в статье представлены три различных способа транспонирования этих данных с помощью Aspose.Cells for .NET, каждый из которых подходит для определённой версии Excel и случая использования.

## **Подход 1 — Транспонирование диапазона на месте (Range.Transpose)**
Используйте этот подход, когда требуется транспонировать данные без обращения к функции рабочего листа `TRANSPOSE`. Он работает в **любой версии Excel** и не зависит от динамических массивов, что делает его наиболее безопасным кросс-версионным вариантом. Он идеально подходит, когда нужен только итоговый транспонированный результат и нет необходимости сохранять исходную формулу `TRANSPOSE` в рабочей книге.

### **Используемый API**
`Range.Transpose()` — метод экземпляра класса `Aspose.Cells.Range`. Его вызов переворачивает диапазон на месте, меняя местами его строки и столбцы, так что то, что было строкой, становится столбцом, а то, что было столбцом, — строкой. Метод напрямую изменяет соответствующие ячейки, не записывая формулу.

### **Шаги**
1. Откройте исходную рабочую книгу с `LoadOptions`, установленным в формат `.xlsx`, вызвав `new Workbook(srcFile, new LoadOptions(LoadFormat.Xlsx))`.
2. Получите первый рабочий лист из рабочей книги с помощью `workbook.Worksheets[0]`.
3. Получите доступ к коллекции ячеек рабочего листа через `worksheet.Cells`.
4. Создайте исходный диапазон, охватывающий **A1:D5**, вызвав `cells.CreateRange("A1:D5")`.
5. Вызовите `source.Transpose()`, чтобы повернуть диапазон на месте, поменяв строки и столбцы местами.
6. Сохраните рабочую книгу с помощью `workbook.Save(outputFile)`.
После транспонирования тот же опорный диапазон содержит повёрнутые данные. Первая строка читается как (пусто, **Европа**, **Азия**, **Северная Америка**), а первый столбец — как (пусто, **Квартал 1**, **Квартал 2**, **Квартал 3**, **Квартал 4**). Каждый исходный столбец с данными о продажах становится строкой в транспонированном диапазоне.

```csharp
using System;
using System.IO;
using Aspose.Cells;
string srcFile = "source.xlsx";
string outputFile = "transposed.xlsx";
Workbook workbook = new Workbook(srcFile, new LoadOptions(LoadFormat.Xlsx));
Worksheet worksheet = workbook.Worksheets[0];
Cells cells = worksheet.Cells;
var source = cells.CreateRange("A1:D5");
source.Transpose();
workbook.Save(outputFile);
```

## **Подход 2 — Транспонирование с помощью формулы динамического массива (Excel 365 / 2021)**
Используйте этот подход, когда требуется сохранить формулу `=TRANSPOSE(A1:D5)` в выходной рабочей книге как «живую» формулу, чтобы результат автоматически обновлялся при изменении исходных данных, а целевой файл Excel будет открываться в **Excel 365 / Excel 2021 или более поздней версии**, где поддерживаются динамические массивы и оператор проливания.

### **Используемый API**
`Cell.SetDynamicArrayFormula(string formula, FormulaParseOptions options, bool calculateValue)` — метод класса `Aspose.Cells.Cell`, который задаёт формулу ячейки как **формулу динамического массива**. Excel вычисляет формулу один раз и автоматически «проливает» результат в окружающие ячейки. Третий параметр, установленный в `true`, указывает Aspose.Cells также вычислить результирующие значения в момент записи.

### **Шаги**
1. Загрузите исходную рабочую книгу с помощью `new Workbook(srcFile, new LoadOptions(LoadFormat.Xlsx))`.
2. Получите первый рабочий лист и доступ к его коллекции `Cells`.
3. Поместите формулу динамического массива в ячейку **A6**, непосредственно под исходным диапазоном, вызвав `cells["A6"].SetDynamicArrayFormula("=TRANSPOSE(A1:D5)", new FormulaParseOptions(), true)`.
4. Аргумент `null` передаёт `FormulaParseOptions` со значениями по умолчанию, а третий аргумент `true` указывает Aspose.Cells обрабатывать формулу как динамический массив и вычислить её, чтобы «пролитые» значения были записаны в рабочую книгу.
5. Сохраните рабочую книгу с помощью `workbook.Save(outputFile)`.
Ячейка **A6** содержит формулу `=TRANSPOSE(A1:D5)`, а Excel автоматически «проливает» результат в область **A6:D10** — блок 5 строк на 4 столбца, соответствующий транспонированным данным.

{{% alert color="primary" %}}
Этот подход работает **только в Excel 365 / 2021 или более поздней версии**. В более ранних версиях Excel формулы динамических массивов не «проливаются» корректно.
{{% /alert %}}

```csharp
using System;
using System.IO;
using Aspose.Cells;
string srcFile = "source.xlsx";
string outFile = "output_transpose_dynamic.xlsx";
Workbook workbook = new Workbook(srcFile, new LoadOptions(LoadFormat.Xlsx));
Worksheet worksheet = workbook.Worksheets[0];
Cells cells = worksheet.Cells;
cells["A6"].SetDynamicArrayFormula("=TRANSPOSE(A1:D5)", new FormulaParseOptions(), true);
workbook.Save(outFile, SaveFormat.Xlsx);
```

## **Подход 3 — Транспонирование с помощью классической формулы массива (CSE)**
Используйте этот подход, когда требуется сохранить формулу `TRANSPOSE` в рабочей книге, но целевой файл Excel может быть открыт в **более ранних версиях Excel (до 2021, включая 2019, 2016, 2013 и т. д.)**, где проливание динамических массивов не поддерживается. Классическая формула массива CSE (Ctrl+Shift+Enter) представляет собой альтернативу, совместимую с устаревшими версиями, которую могут вычислить все версии Excel.

### **Используемый API**
`Cell.SetArrayFormula(string arrayFormula, int nRows, int nColumns)` — метод класса `Aspose.Cells.Cell`, который назначает **классическую формулу массива (CSE)** опорной ячейке и задаёт размерности результирующего массива. Aspose.Cells записывает маркер многоячеечной формулы массива, чтобы Excel вычислил формулу как одно массивное выражение, заполняющее объявленный диапазон.

### **Шаги**
1. Загрузите исходную рабочую книгу так же, как в предыдущих подходах.
2. Получите первый рабочий лист и доступ к его коллекции `Cells`.
3. Вызовите `cells["A6"].SetArrayFormula("=TRANSPOSE(A1:D5)", 4, 5)`. Второй аргумент `4` — количество строк результирующего массива, а третий аргумент `5` — количество столбцов.
4. Сохраните рабочую книгу с помощью `workbook.Save(outputFile)`.
Ячейка **A6** является опорной для формулы массива, а вычисленный массив охватывает 4 строки и 5 столбцов, начиная с A6, что соответствует транспонированным размерностям исходного диапазона A1:D5. Excel записывает единый маркер формулы массива по результирующему диапазону, чтобы более ранние версии Excel корректно её вычисляли.

{{% alert color="primary" %}}
Формулы массива CSE — классический способ Excel вычислить выражение `TRANSPOSE`, и этот подход универсально совместим со всеми версиями Excel.
{{% /alert %}}

```csharp
using System;
using System.IO;
using Aspose.Cells;
// Загрузить исходную книгу с параметрами загрузки xlsx
string srcFile = "source.xlsx";
Workbook workbook = new Workbook(srcFile, new LoadOptions(LoadFormat.Xlsx));
// Получить доступ к первому листу и его коллекции Cells
Worksheet worksheet = workbook.Worksheets[0];
Cells cells = worksheet.Cells;
// Установить классическую формулу массива CSE в ячейке A6.
// Формула =TRANSPOSE(A1:D5) транспонирует исходный диапазон 5 строк x 4 столбца
// в массив 4 строки x 5 столбцов. Второй аргумент (4) — это количество строк,
// а третий аргумент (5) — количество столбцов результирующего массива.
// Aspose.Cells записывает маркер формулы массива CSE, чтобы Excel вычислял её как
// единую многоячеечную формулу массива, совместимую со старыми версиями Excel
// (2019, 2016, 2013 и т.д.), которые не поддерживают динамическое распыление массивов.
cells["A6"].SetArrayFormula("=TRANSPOSE(A1:D5)", 4, 5);
// Сохранить книгу, чтобы маркер формулы массива был сохранён
workbook.Save("output.xlsx");
```

## **Сравнение — Когда использовать каждый подход**
| Подход | API / Метод | Версия Excel | Сохраняется исходная формула? | Выходной диапазон |
|--------|-------------|--------------|-------------------------------|------------------|
| Подход 1 — Транспонирование на месте | `Range.Transpose()` | Все версии Excel | Нет (только значения) | Тот же опорный диапазон, 5×4 |
| Подход 2 — Формула динамического массива | `Cell.SetDynamicArrayFormula` | Excel 365 / 2021+ | Да (проливается динамически) | Проливается из опорной ячейки |
| Подход 3 — Классическая формула массива (CSE) | `Cell.SetArrayFormula` | Все версии Excel | Да (многоячеечная формула массива) | Явный размер, 4×5 |
Используйте **Подход 1**, когда требуется быстрое кросс-версионное преобразование и нужно лишь записать транспонированные значения в файл. Используйте **Подход 2**, когда гарантировано использование современной версии Excel и требуется, чтобы формула оставалась «живой» и обновлялась при изменении источника. Используйте **Подход 3**, когда необходима максимальная совместимость с сохранением формулы во всех версиях Excel, включая более старые выпуски, не поддерживающие динамические массивы.
