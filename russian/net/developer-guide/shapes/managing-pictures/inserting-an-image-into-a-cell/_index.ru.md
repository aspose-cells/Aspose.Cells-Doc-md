{{% alert color="primary" %}}
Aspose.Cells предоставляет два различных способа связать изображение с одной ячейкой. Плавающее изображение — это фигура на слое рисунков рабочего листа, которая визуально накладывается на диапазон ячеек, тогда как встроенное изображение хранится внутри самой ячейки и автоматически масштабируется по области отображения ячейки. Выберите подход, который лучше всего соответствует вашим требованиям к макету.

## **Введение**
Точное вписывание изображения в одну ячейку — распространённая задача при разработке электронных таблиц, которые служат визуальными отчётами, каталогами продукции, справочниками сотрудников, панелями мониторинга или списками инвентаря. Вместо того чтобы растягивать изображение на множество ячеек или размещать его свободно на рабочем листе, вам может потребоваться чистое изображение, привязанное к ячейке, которое остаётся выровненным с владеющей им ячейкой.
Aspose.Cells поддерживает этот сценарий двумя взаимодополняющими способами:
- **Подход 1 — размещение плавающего изображения над ячейкой.** Добавьте `Picture` на рабочий лист, установите его свойство `Placement` в значение `MoveAndSize` и настройте ячейки привязки (`UpperLeftRow`, `UpperLeftColumn`, `LowerRightRow`, `LowerRightColumn`) так, чтобы изображение покрывало ровно одну ячейку.
- **Подход 2 — встраивание изображения непосредственно в ячейку.** Присвойте байты изображения свойству `EmbeddedImage` ячейки. Изображение автоматически масштабируется по области отображения ячейки и перемещается вместе с ней.
Далее в статье подробно рассматриваются оба подхода, объясняются соответствующие API и демонстрируется их использование в коде.

## **Подход 1: размещение изображения над ячейкой**
Плавающее изображение — это объект `Picture`, который находится на слое рисунков рабочего листа. Хотя он не принадлежит какой-либо одной ячейке, он привязан к диапазону ячеек. Ячейки привязки изображения — его верхний левый и нижний правый углы — определяют его визуальные границы на рабочем листе. По умолчанию только что добавленное изображение охватывает несколько ячеек.
Чтобы плавающее изображение покрывало **ровно одну ячейку**, необходимо:
1. Добавить изображение с помощью `Worksheet.Pictures.Add(int row, int column, Stream stream)`, что привязывает новое изображение к заданной ячейке.
2. Установить четыре свойства привязки так, чтобы ограничивающий прямоугольник изображения совпадал с целевой ячейкой.
3. Установить `Picture.Placement` в значение `PlacementType.MoveAndSize`, чтобы изображение перемещалось и изменяло размер вместе с базовой ячейкой при изменении пользователем ширины столбца или высоты строки.

### **Привязка изображения к одной ячейке**
Привязка изображения определяется четырьмя индексами (начиная с нуля):
- `Picture.UpperLeftRow` — индекс строки верхнего края изображения.
- `Picture.UpperLeftColumn` — индекс столбца левого края изображения.
- `Picture.LowerRightRow` — индекс строки нижнего края изображения. Чтобы нижний край изображения оказался у нижней границы строки `r`, установите значение `r + 1`.
- `Picture.LowerRightColumn` — индекс столбца правого края изображения. Чтобы правый край изображения оказался у правой границы столбца `c`, установите значение `c + 1`.

{{% alert color="primary" %}}
Индексы строк и столбцов в Aspose.Cells **начинаются с нуля**. Ячейка C6 имеет индекс строки 5 и индекс столбца 2. Ошибки смещения на единицу в нижней правой привязке — самая распространённая причина того, что изображения визуально заходят на соседнюю ячейку.

### **Управление поведением размещения**
`Picture.Placement` — это перечисление типа `PlacementType`, которое управляет поведением изображения при изменении пользователем размера строки или столбца под ним. Рекомендуемое значение для изображения в одной ячейке — `PlacementType.MoveAndSize`, благодаря которому изображение перемещается и изменяет размер вместе с базовой ячейкой, сохраняя точное соответствие.

### **Пошаговые инструкции**
1. Создайте новую рабочую книгу `Workbook` (или откройте существующую).
2. Получите доступ к целевому рабочему листу `Worksheet` через `workbook.Worksheets[0]`.
3. Откройте файл изображения с диска в `FileStream`, используя блок `using`, чтобы поток был корректно освобождён.
4. Вызовите `worksheet.Pictures.Add(5, 2, stream)`, чтобы добавить изображение, привязанное к ячейке C6. Сохраните возвращённую ссылку на `Picture`.
5. Установите четыре координаты привязки так, чтобы изображение покрывало только ячейку C6: `UpperLeftRow = 5`, `UpperLeftColumn = 2`, `LowerRightRow = 6`, `LowerRightColumn = 3`.
6. Установите `picture.Placement = PlacementType.MoveAndSize`, чтобы изображение оставалось выровненным с C6 при изменении ширины столбца или высоты строки.
7. При желании добавьте пример текста в соседние ячейки, чтобы продемонстрировать, что только ячейка C6 содержит изображение.
8. Сохраните рабочую книгу на диск как файл `.xlsx`.
Следующий код демонстрирует полный подход.

```csharp
using System;
using System.IO;
using Aspose.Cells;
using Aspose.Cells.Drawing;
Workbook workbook = new Workbook();
Worksheet worksheet = workbook.Worksheets[0];
using (FileStream fs = new FileStream("logo.png", FileMode.Open, FileAccess.Read))
{
    int picIndex = worksheet.Pictures.Add(5, 2, fs);
    Picture picture = worksheet.Pictures[picIndex];
    picture.UpperLeftRow = 5;
    picture.UpperLeftColumn = 2;
    picture.LowerRightRow = 6;
    picture.LowerRightColumn = 3;
    picture.Placement = PlacementType.MoveAndSize;
}
workbook.Save("output.xlsx", SaveFormat.Xlsx);
```

## **Подход 2: встраивание изображения непосредственно в ячейку**
Aspose.Cells также предоставляет более простой механизм для изображений, привязанных к ячейкам: свойство `Cell.EmbeddedImage`. Присвоение байтов изображения этому свойству прикрепляет изображение к самой ячейке, как если бы оно было встроенным содержимым.

### **Как работают встроенные изображения**
- Изображение хранится как часть содержимого ячейки, а не как фигура на слое рисунков.
- Изображение автоматически масштабируется по отображаемым границам ячейки. Никакие координаты привязки или параметры размещения не нужны.
- Ячейка остаётся полноценной ячейкой с реальным адресом, на который можно ссылаться в формулах, сортировать как часть строки или использовать в других операциях на уровне ячеек.
Это делает `Cell.EmbeddedImage` самым лаконичным вариантом, когда ваша цель — просто «изображение, которое живёт внутри этой ячейки».

### **Пошаговые инструкции**
1. Создайте новую рабочую книгу `Workbook` (или откройте существующую).
2. Получите доступ к целевому рабочему листу `Worksheet` через `workbook.Worksheets[0]`.
3. Прочитайте файл изображения с диска в массив `byte[]` (например, с помощью `File.ReadAllBytes`).
4. Получите ссылку на целевую ячейку — либо через `worksheet.Cells["C6"]`, либо через `worksheet.Cells[5, 2]`.
5. Присвойте массив байтов свойству `EmbeddedImage` ячейки.
6. При желании настройте высоту строки и ширину столбца целевой строки и столбца, чтобы встроенное изображение выглядело более выразительно.
7. Сохраните рабочую книгу на диск как файл `.xlsx`.
Следующий код демонстрирует полный подход.

```csharp
var workbook = new Workbook();
var worksheet = workbook.Worksheets[0];
// Получить целевую ячейку C6
var cell = worksheet.Cells["C6"];
// Считать файл изображения в массив байтов
byte[] imageData = File.ReadAllBytes("logo.png");
// Встроить изображение непосредственно в ячейку
cell.EmbeddedImage = imageData;
// При необходимости настроить высоту строки и ширину столбца, чтобы встроенное изображение было более заметным
worksheet.Cells.SetColumnWidth(2, 30);   // Столбец C (индекс 2)
worksheet.Cells.SetRowHeight(5, 100);     // Строка 6 (индекс 5)
// Сохранить полученную рабочую книгу как файл .xlsx
workbook.Save("output.xlsx", SaveFormat.Xlsx);
```

## **Выбор подходящего подхода**
Оба подхода дают изображение, которое помещается в одной ячейке, но различаются по способу хранения и поведению:
- **Используйте плавающее изображение (Подход 1), когда:**
  - Вам нужен более тонкий контроль над размещением, наслоением или выравниванием относительно других объектов рисования.
  - Вы хотите, чтобы изображение вело себя как фигура, которую можно выделять, переупорядочивать или группировать с другими фигурами.
  - Вам требуется обратная совместимость с кодом, который уже работает с `PictureCollection`.
  - Вам нужно динамически вычислять координаты привязки на основе макета рабочего листа.
- **Используйте встроенное изображение (Подход 2), когда:**
  - Вам нужна самая простая вставка изображения в ячейку.
  - Изображение должно перемещаться вместе с ячейкой как любое другое содержимое ячейки.
  - Вам не нужно манипулировать изображением как фигурой.
