{{% alert color="primary" %}}
Aspose.Cells поддерживает разделение одного файла Excel на несколько файлов. Существует два основных способа: (1) копирование каждого рабочего листа исходной рабочей книги в новую рабочую книгу с сохранением каждой из них в отдельный файл и (2) копирование определенного диапазона ячеек из рабочего листа в новую рабочую книгу. Оба подхода полезны, когда необходимо распределить подмножества данных, создать небольшие отчеты для разных получателей или изолировать данные для отдельной обработки.
{{% /alert %}}

## **Введение**
Существует множество реальных сценариев, в которых разработчику необходимо разделить один файл Excel на несколько меньших файлов. Например, рабочая книга может содержать по одному рабочему листу для каждого подразделения, при этом каждому руководителю подразделения необходимо получить только свой лист. В других случаях может потребоваться извлечь определенную таблицу или блок данных из рабочего листа и отправить его по электронной почте в виде отдельного файла, не раскрывая остальную часть рабочей книги. Большие объединенные рабочие книги также могут потребовать разделения на меньшие части для упрощения обработки, ускорения загрузки или последующей обработки другими системами.
Aspose.Cells предлагает два гибких подхода для выполнения этой задачи. Первый подход перебирает каждый рабочий лист исходной рабочей книги и копирует его содержимое в совершенно новый экземпляр `Workbook`, сохраняя каждый лист в отдельный файл. Второй подход ориентирован на определенный диапазон ячеек в рабочем листе и копирует только этот диапазон в новую рабочую книгу. В обоих случаях общий процесс одинаков: загрузить исходную рабочую книгу с помощью класса `Workbook`, получить доступ к соответствующим данным через объекты `Worksheet` и `Cells`, перенести содержимое в целевой объект `Workbook`, а затем сохранить целевую рабочую книгу на диске.

## **Разделение файла Excel путем копирования каждого рабочего листа в новую рабочую книгу**

### **Обзор подхода**
В рамках этого подхода исходная рабочая книга открывается один раз, после чего для каждого `Worksheet` в ее коллекции `Worksheets` создается новый целевой объект `Workbook`. Содержимое исходного рабочего листа копируется в первый рабочий лист целевой рабочей книги, после чего целевая рабочая книга сохраняется в файле, имя которого формируется на основе имени исходного рабочего листа. В результате для каждого рабочего листа создается отдельный выходной файл, содержащий данные одного исходного листа.
Этот метод подходит, если каждый рабочий лист исходной рабочей книги представляет логически независимый набор информации, например сведения о подразделении, регионе, месяце или товарной линейке, и каждый набор необходимо передать или обработать отдельно.

### **Шаги**
Следующие шаги описывают, как разделить файл Excel путем копирования каждого рабочего листа в новую рабочую книгу:
1. Откройте исходный файл Excel, создав объект `Workbook` и передав путь к файлу в его конструктор.
2. Переберите коллекцию `Workbook.Worksheets` с помощью цикла `for` или `forEach`, чтобы обработать каждый `Worksheet` в исходном файле.
3. Внутри цикла создайте новый экземпляр целевого `Workbook`, то есть пустую рабочую книгу для текущего рабочего листа.
4. Скопируйте содержимое исходного рабочего листа в целевой рабочий лист. Это можно сделать путем перебора ячеек коллекции `Cells` исходного рабочего листа и записи их значений в соответствующие ячейки целевого рабочего листа либо с помощью метода `Cells.copy` для одновременного переноса всего диапазона.
5. Сформируйте путь к выходному файлу, включающий имя исходного рабочего листа, например `dataDir + worksheet.Name + ".xls"`, чтобы каждый создаваемый файл имел уникальное имя.
6. Вызовите метод целевого объекта `Workbook.save`, чтобы записать файл на диск.
7. Повторите шаги 3–6 для следующего рабочего листа, пока не будут обработаны все рабочие листы.

### **Пример кода**

```javascript
const AsposeCells = require("aspose.cells.node");
const dataDir = "data/";
const workbook = new AsposeCells.Workbook(dataDir + "book1.xls");
for (let i = 0; i < workbook.getWorksheets().getCount(); i++) {
    const sourceSheet = workbook.getWorksheets().get(i);
    const sheetName = sourceSheet.getName();
    const destWorkbook = new AsposeCells.Workbook();
    const destIndex = destWorkbook.getWorksheets().add();
    const destSheet = destWorkbook.getWorksheets().get(destIndex);
    destSheet.setName(sheetName);
    destSheet.copy(sourceSheet);
    const destFile = dataDir + sheetName + ".xls";
    destWorkbook.save(destFile, AsposeCells.SaveFormat.Excel97To2003);
}
```

Ожидаемый результат — набор новых файлов в каталоге данных, по одному файлу для каждого рабочего листа исходной рабочей книги. Каждый файл назван в соответствии со своим исходным листом и содержит данные, а при необходимости также форматирование, только одного листа.

## **Разделение файла Excel путем копирования диапазона в новую рабочую книгу**

### **Обзор подхода**
Иногда данные, которые необходимо разделить, соответствуют не всему рабочему листу, а определенной прямоугольной области рабочего листа, например `A1:D10` или именованному диапазону, представляющему конкретную таблицу. В таких случаях копировать целые рабочие листы нецелесообразно и требуется более точный подход: определить исходный диапазон, скопировать только его в новую рабочую книгу и сохранить новый файл.
Этот подход идеален, если необходимо извлечь отдельную таблицу, блок отчета или область данных из большого рабочего листа, отбросив все не связанное с ними содержимое. Он также полезен для экспорта выбранных пользователем областей листа в виде отдельных файлов.

### **Шаги**
Следующие шаги описывают, как разделить файл Excel путем копирования определенного диапазона в новую рабочую книгу:
1. Откройте исходный файл Excel, создав объект `Workbook` с путем к файлу.
2. Получите целевой объект `Worksheet`, содержащий диапазон, который необходимо скопировать, по индексу, например для первого листа, либо по имени из коллекции `Worksheets`.
3. Определите копируемый диапазон. Это может быть жестко заданный диапазон ячеек, например `A1:C10`, именованный диапазон, полученный через коллекцию `Worksheet.Cells`, или диапазон, созданный с помощью `Worksheet.Cells.createRange`.
4. Создайте новый экземпляр целевого объекта `Workbook`.
5. Получите доступ к первому объекту `Worksheet` целевой рабочей книги, то есть к листу по умолчанию.
6. Скопируйте исходный диапазон в целевой рабочий лист, как правило начиная с ячейки `A1`. Для копирования всего диапазона можно использовать метод `Cells.copy` коллекции `Cells` целевого рабочего листа. Альтернативно можно перебрать ячейки исходного диапазона и записать их значения в целевые ячейки с помощью `putValue`. При необходимости можно передать необязательный объект `CopyOptions`, чтобы указать, что именно переносится: только значения, значения и стили, формулы и т. д.
7. Сохраните целевую рабочую книгу по новому пути на диске с помощью метода `Workbook.save`.

### **Пример кода**
Ожидаемый результат — один новый файл в каталоге данных, содержащий только значения, а при необходимости также форматирование указанного диапазона, извлеченного из исходной рабочей книги. Целевой файл никак не связан с другими данными исходного файла: он содержит только извлеченный диапазон, начиная с ячейки `A1` первого рабочего листа.
