{{% alert color="primary" %}}
Aspose.Cells обеспечивает полноценную поддержку чтения и записи файлов DBF (dBASE). Вы можете загружать существующие файлы dBASE III и dBASE IV в объект `Workbook`, изменять данные с помощью расширенного API Aspose.Cells и сохранять рабочую книгу в формате DBF для последующего использования в устаревших приложениях для работы с базами данных.
{{% /alert %}}

## **Введение**
DBF (DataBase File) — это устаревший формат файлов базы данных, впервые появившийся в dBASE в начале 1980-х годов. Несмотря на возраст формата, файлы DBF по-прежнему широко используются во многих отраслях для хранения структурированных данных, в частности, в бухгалтерском учете, ГИС и других специализированных приложениях. Aspose.Cells позволяет легко интегрировать такие устаревшие файлы в современные сценарии работы с электронными таблицами на C++.
Библиотека поддерживает как чтение, так и запись файлов DBF, что позволяет:
- Импортировать данные из существующих файлов DBF в объекты `Workbook` библиотеки Aspose.Cells для дальнейшей обработки или преобразования в другие форматы.
- Создавать новые файлы DBF с нуля или путем преобразования данных из других форматов электронных таблиц.
- Сохранять определения полей, типы данных и структуры записей при импорте данных из формата DBF и экспорте в него.
Файлы DBF также можно открывать непосредственно в Microsoft Excel и других приложениях для работы с электронными таблицами, что делает их удобным связующим звеном между устаревшими системами и современными инструментами обработки электронных таблиц.

## **Поддерживаемые версии DBF и возможности**
Aspose.Cells поддерживает следующие версии формата DBF:
- **dBASE III** — первоначальный и наиболее широко поддерживаемый вариант формата DBF.
- **dBASE IV** — расширенная версия, поддерживающая дополнительные типы данных и больший размер полей.

### Поддерживаемые возможности
Библиотека обеспечивает полноценную поддержку следующих операций:
- Чтение данных DBF в объект `Workbook` с сохранением всех записей и определений полей.
- Запись данных рабочей книги обратно в формат DBF для экспорта в приложения, совместимые с dBASE.
- Обработка распространенных типов данных, используемых в файлах DBF, включая символьные, числовые, датовые и логические поля.
- Сохранение определений полей, таких как имя поля, тип и длина, при операциях чтения и записи.

### Ограничения и рекомендации
При работе с файлами DBF учитывайте следующие ограничения:
- Максимальное количество полей в одном файле — **128**.
- Максимальный размер записи — **4000 байт**.
- Имена полей ограничены **10 символами**, должны быть записаны в верхнем регистре и не могут содержать пробелы.
- Значения дат в файлах DBF хранятся в формате `YYYYMMDD`.
- Кодировка символов может различаться в зависимости от исходного приложения. Как правило, используются Windows-1252 или кодовые страницы OEM.

## **Чтение файла DBF**
Aspose.Cells позволяет легко загружать данные из файла DBF в объект `Workbook`. Библиотека использует класс `LoadOptions` для указания исходного формата, обеспечивая корректную интерпретацию данных в процессе загрузки.

### Чтение файла DBF с помощью Aspose.Cells
Чтобы прочитать файл DBF, необходимо создать экземпляр `LoadOptions`, установить его свойство `LoadFormat` в значение `LoadFormat.Dbf` и передать его вместе с путем к файлу в конструктор `Workbook`. После загрузки данные становятся доступны через коллекцию `Worksheets`, где можно перебирать ячейки, извлекать значения или изменять данные по мере необходимости.
В следующем примере показано, как загрузить существующий файл DBF в Aspose.Cells, получить доступ к первому рабочему листу и прочитать значения ячеек.

```cpp
#include "Aspose.Cells.h"
#include <string>
#include <iostream>
using namespace Aspose::Cells;
int main() {
    Aspose::Cells::Startup();
    std::string dataDir = "Data/";
    std::string filePath = dataDir + "example.dbf";
    LoadOptions loadOptions(LoadFormat::Dbf);
    Workbook workbook(U16String(filePath.c_str()), loadOptions);
    Worksheet worksheet = workbook.GetWorksheets().Get(0);
    Cells cells = worksheet.GetCells();
    std::string sb = "";
    int maxRow = cells.GetMaxDataRow();
    int maxCol = cells.GetMaxDataColumn();
    for (int i = 0; i <= maxRow; i++) {
        for (int j = 0; j <= maxCol; j++) {
            Cell cell = cells.Get(i, j);
            U16String value = cell.GetStringValue();
            sb += "|";
            sb += value.ToUtf8();
        }
        sb += "|";
        sb += "\n";
    }
    std::cout << sb << std::endl;
    std::string outputPath = dataDir + "output.xlsx";
    workbook.Save(U16String(outputPath.c_str()), SaveFormat::Xlsx);
    std::cout << "DBF file loaded successfully. Converted XLSX saved at: " << outputPath << std::endl;
    Aspose::Cells::Cleanup();
    return 0;
}
```

Файлы DBF можно открыть непосредственно в Microsoft Excel, выбрав файл в диалоговом окне «Открыть». Excel будет интерпретировать файл DBF как электронную таблицу и отображать его записи в табличном виде. Это полезно для быстрой проверки данных после чтения или записи данных с помощью Aspose.Cells.
{{% /alert %}}

## **Запись файла DBF**
Запись данных в файл DBF выполняется по тому же принципу, что и сохранение любого другого формата электронных таблиц с помощью Aspose.Cells. Создайте или загрузите `Workbook`, заполните рабочий лист данными, а затем вызовите метод `Save`, указав `SaveFormat.Dbf` в качестве целевого формата.

### Запись файла DBF с помощью Aspose.Cells
Чтобы создать файл DBF, выполните следующие шаги:
1. Создайте новый экземпляр `Workbook`.
2. Получите доступ к первому рабочему листу из коллекции `Worksheets`.
3. Заполните рабочий лист данными, включая заголовки в первой строке, а записи — в последующих строках.
4. Вызовите метод `Workbook.Save`, передав путь к файлу и `SaveFormat.Dbf` в качестве параметров.
В следующем примере показано, как создать новый файл DBF с нуля. Пример заполняет рабочий лист демонстрационными данными, содержащими различные типы данных (строки, числа и даты), чтобы показать, как обрабатываются типы полей при экспорте в формат DBF.

```cpp
#include "Aspose.Cells.h"
#include <string>
#include <filesystem>
using namespace Aspose::Cells;
int main() {
    Aspose::Cells::Startup();
    std::string outputDir = "C:/Output/";
    std::string filePath = outputDir + "output.dbf";
    if (!std::filesystem::exists(outputDir)) {
        std::filesystem::create_directories(outputDir);
    }
    Workbook workbook;
    Worksheet worksheet = workbook.GetWorksheets().Get(0);
    Cells cells = worksheet.GetCells();
    // Заголовки столбцов
    cells.Get(0, 0).PutValue(u"ID");
    cells.Get(0, 1).PutValue(u"Name");
    cells.Get(0, 2).PutValue(u"Department");
    cells.Get(0, 3).PutValue(u"Salary");
    cells.Get(0, 4).PutValue(u"HireDate");
    // Строка данных 1
    cells.Get(1, 0).PutValue(101);
    cells.Get(1, 1).PutValue(u"John Smith");
    cells.Get(1, 2).PutValue(u"Engineering");
    cells.Get(1, 3).PutValue(75000.50);
    Date hireDate1{2020, 3, 15, 0, 0, 0, 0};
    cells.Get(1, 4).PutValue(hireDate1);
    // Строка данных 2
    cells.Get(2, 0).PutValue(102);
    cells.Get(2, 1).PutValue(u"Jane Doe");
    cells.Get(2, 2).PutValue(u"Marketing");
    cells.Get(2, 3).PutValue(68000.75);
    Date hireDate2{2019, 7, 22, 0, 0, 0, 0};
    cells.Get(2, 4).PutValue(hireDate2);
    // Строка данных 3
    cells.Get(3, 0).PutValue(103);
    cells.Get(3, 1).PutValue(u"Bob Johnson");
    cells.Get(3, 2).PutValue(u"Finance");
    cells.Get(3, 3).PutValue(82000.00);
    Date hireDate3{2021, 1, 10, 0, 0, 0, 0};
    cells.Get(3, 4).PutValue(hireDate3);
    // Строка данных 4
    cells.Get(4, 0).PutValue(104);
    cells.Get(4, 1).PutValue(u"Alice Brown");
    cells.Get(4, 2).PutValue(u"Human Resources");
    cells.Get(4, 3).PutValue(71000.25);
    Date hireDate4{2018, 11, 5, 0, 0, 0, 0};
    cells.Get(4, 4).PutValue(hireDate4);
    // Строка данных 5
    cells.Get(5, 0).PutValue(105);
    cells.Get(5, 1).PutValue(u"Charlie Wilson");
    cells.Get(5, 2).PutValue(u"Operations");
    cells.Get(5, 3).PutValue(79500.80);
    Date hireDate5{2022, 5, 30, 0, 0, 0, 0};
    cells.Get(5, 4).PutValue(hireDate5);
    // Установить ширины столбцов для лучшей читаемости
    worksheet.GetCells().SetColumnWidth(0, 8);
    worksheet.GetCells().SetColumnWidth(1, 20);
    worksheet.GetCells().SetColumnWidth(2, 20);
    worksheet.GetCells().SetColumnWidth(3, 12);
    worksheet.GetCells().SetColumnWidth(4, 14);
    workbook.Save(U16String(filePath.c_str()), SaveFormat::Dbf);
    Aspose::Cells::Cleanup();
    return 0;
}
```

{{% alert color="primary" %}}
При записи данных в файл DBF убедитесь, что данные соответствуют ограничениям формата. Имена полей не должны превышать 10 символов и содержать пробелы. Записи, превышающие 4000 байт в совокупности, не будут сохранены корректно. Даты должны быть корректными и допускать представление в формате YYYYMMDD.
{{% /alert %}}

## **Особенности типов данных и форматирования**
При обмене данными между Aspose.Cells и форматом DBF важно понимать, как типы данных сопоставляются между двумя системами, чтобы обеспечить целостность данных.

### Сопоставление типов ячеек с типами полей DBF
Значения ячеек Aspose.Cells автоматически преобразуются в соответствующие типы полей DBF при сохранении:
- **Строки** сопоставляются с символьными (C) полями.
- **Числовые значения** (целые числа и десятичные дроби) сопоставляются с числовыми (N) полями.
- **Значения даты** сопоставляются с датовыми (D) полями в формате `YYYYMMDD`.
- **Логические значения** сопоставляются с логическими (L) полями.

### Кодировка
Файлы DBF могут использовать разные кодировки символов в зависимости от приложения, в котором они были созданы. Aspose.Cells в большинстве случаев автоматически обрабатывает кодировку, однако при возникновении проблем с отображением символов может потребоваться дополнительная проверка кодировки исходного файла.

### Правила имен полей
Имена полей DBF должны соответствовать следующим правилам:
- Максимальная длина имени поля — 10 символов.
- Должны начинаться с буквы.
- Не могут содержать пробелы или специальные символы.
- Хранятся в верхнем регистре независимо от регистра символов во входных данных.

### Проверка результата
После записи файла DBF результат можно проверить, открыв его в Microsoft Excel или любом приложении, совместимом с dBASE. Данные должны отображаться в табличном виде: имена полей должны использоваться в качестве заголовков столбцов, а записи — содержать переданные вами данные.

## **Преобразование между DBF и другими форматами**
Один из наиболее практичных сценариев использования Aspose.Cells для чтения и записи файлов DBF — преобразование данных между форматом DBF и современными форматами электронных таблиц, такими как XLSX, XLS или CSV. Поскольку Aspose.Cells поддерживает широкий спектр форматов, вы можете легко загрузить файл DBF и сохранить его в любом другом поддерживаемом формате или выполнить обратное преобразование.
