{{% alert color="primary" %}}
Aspose.Cells предлагает два разных способа связать изображение с одной ячейкой. Плавающее изображение — это фигура на слое рисунков рабочего листа, визуально накладывающаяся на диапазон ячеек, тогда как встроенное изображение хранится в самой ячейке и автоматически масштабируется под размер области отображения ячейки. Выберите подход, который лучше всего соответствует требованиям к макету.
{{% /alert %}}

## **Введение**
При разработке электронных таблиц, используемых в качестве визуальных отчётов, каталогов продукции, справочников сотрудников, панелей мониторинга или списков запасов, часто требуется разместить изображение точно по границам одной ячейки. Вместо растяжения изображения на несколько ячеек или его свободного размещения на рабочем листе может потребоваться изображение, точно вписанное в ячейку и сохраняющее с ней выравнивание.
Aspose.Cells поддерживает этот сценарий двумя взаимодополняющими способами:
- **Подход 1 — размещение плавающего изображения поверх ячейки.** Добавьте `Picture` на рабочий лист, установите для `Placement` значение `MoveAndSize` и настройте ячейки привязки (`UpperLeftRow`, `UpperLeftColumn`, `LowerRightRow`, `LowerRightColumn`) так, чтобы изображение покрывало ровно одну ячейку.
- **Подход 2 — встраивание изображения непосредственно в ячейку.** Присвойте байты изображения свойству `EmbeddedImage` ячейки. Изображение автоматически масштабируется в соответствии с размерами ячейки и перемещается вместе с ней.
Далее рассматриваются оба подхода, соответствующие API и примеры их использования в коде.

## **Подход 1: размещение изображения поверх ячейки**
Плавающее изображение — это объект `Picture`, расположенный на слое рисунков рабочего листа. Хотя он не является частью отдельной ячейки, он привязан к диапазону ячеек. Ячейки привязки в левом верхнем и правом нижнем углах определяют визуальные границы изображения на рабочем листе. По умолчанию изображение после добавления занимает несколько ячеек.
Чтобы плавающее изображение занимало **ровно одну ячейку**, необходимо:
1. Добавьте изображение с помощью `Worksheet.Pictures.Add(int row, int column, Vector<uint8_t> stream)`, чтобы привязать его к указанной ячейке.
2. Задайте четыре свойства привязки так, чтобы ограничивающий прямоугольник изображения совпадал с целевой ячейкой.
3. Задайте для `Picture.Placement` значение `PlacementType.MoveAndSize`, чтобы изображение перемещалось и изменяло размер вместе с ячейкой при изменении пользователем ширины столбца или высоты строки.

### **Привязка изображения к одной ячейке**
Привязка изображения задается четырьмя свойствами, значения которых являются индексами с нуля:
- `Picture.UpperLeftRow` — индекс строки верхней границы изображения.
- `Picture.UpperLeftColumn` — индекс столбца левой границы изображения.
- `Picture.LowerRightRow` — индекс строки нижней границы изображения. Чтобы нижняя граница изображения совпала с нижней границей строки `r`, установите это значение равным `r + 1`.
- `Picture.LowerRightColumn` — индекс столбца правой границы изображения. Чтобы правая граница изображения совпала с правой границей столбца `c`, установите это значение равным `c + 1`.

{{% alert color="primary" %}}
Индексы строк и столбцов в Aspose.Cells **начинаются с нуля**. Ячейка C6 имеет индекс строки 5 и индекс столбца 2. Чаще всего из-за ошибки на единицу в индексах правой нижней точки привязки изображение частично перекрывает соседнюю ячейку.
{{% /alert %}}

### **Управление поведением размещения**
`Picture.Placement` — это перечисление типа `PlacementType`, определяющее поведение изображения, когда пользователь изменяет размер расположенной под ним строки или столбца. Для изображения, занимающего одну ячейку, рекомендуется значение `PlacementType.MoveAndSize`: оно обеспечивает перемещение и изменение размера изображения вместе с ячейкой, сохраняя его точное совпадение с ней.

### **Пошаговые инструкции**
1. Создайте новую `Workbook` или откройте существующую.
2. Получите целевой `Worksheet` из `workbook.GetWorksheets().Get(0]`.
3. Считайте файл изображения с диска в буфер байтов `Vector<uint8_t>` для передачи байтов изображения в API.
4. Вызовите `worksheet.Pictures.Add(5, 2, imageData)`, чтобы добавить изображение, привязанное к ячейке C6. Сохраните возвращаемую ссылку на `Picture`.
5. Задайте четыре координаты привязки так, чтобы изображение занимало только ячейку C6: `UpperLeftRow = 5`, `UpperLeftColumn = 2`, `LowerRightRow = 6`, `LowerRightColumn = 3`.
6. Установите `picture.Placement = PlacementType.MoveAndSize`, чтобы изображение оставалось выровненным с C6 при изменении ширины столбца или высоты строки.
7. По желанию добавьте демонстрационный текст в окружающие ячейки, чтобы показать, что изображение занимает только ячейку C6.
8. Сохраните рабочую книгу на диск в виде файла `.xlsx`.
Ниже приведен полный пример реализации этого подхода.

```cpp
#include "Aspose.Cells.h"
#include <fstream>
#include <vector>
#include <iterator>
using namespace Aspose::Cells;
int main() {
    Aspose::Cells::Startup();
    Workbook workbook;
    Worksheet worksheet = workbook.GetWorksheets().Get(0);
    std::ifstream fs("logo.png", std::ios::binary);
    std::vector<uint8_t> stdData((std::istreambuf_iterator<char>(fs)),
                                  std::istreambuf_iterator<char>());
    fs.close();
    Vector<uint8_t> imageData(reinterpret_cast<const uint8_t*>(stdData.data()),
                              static_cast<int32_t>(stdData.size()));
    int picIndex = worksheet.GetPictures().Add(5, 2, imageData);
    Picture picture = worksheet.GetPictures().Get(picIndex);
    picture.SetUpperLeftRow(5);
    picture.SetUpperLeftColumn(2);
    picture.SetLowerRightRow(6);
    picture.SetLowerRightColumn(3);
    picture.SetPlacement(PlacementType::MoveAndSize);
    workbook.Save(u"output.xlsx", SaveFormat::Xlsx);
    Aspose::Cells::Cleanup();
    return 0;
}
```

## **Подход 2: встраивание изображения непосредственно в ячейку**
Aspose.Cells также предоставляет более простой механизм для изображений, связанных с ячейками: свойство `Cell.EmbeddedImage`. Присвоение байтов изображения этому свойству встраивает изображение в саму ячейку.

### **Как работают встроенные изображения**
- Изображение хранится как часть содержимого ячейки, а не как фигура на слое рисунков.
- Изображение автоматически масштабируется в пределах отображаемых границ ячейки. Координаты привязки и параметры размещения не требуются.
- Ячейка остаётся полноценной ячейкой с адресом, на который могут ссылаться формулы; её можно сортировать вместе с другими ячейками строки и применять к ней другие операции на уровне ячейки.
Таким образом, `Cell.EmbeddedImage` — наиболее простой вариант, если требуется просто разместить изображение внутри этой ячейки.

### **Пошаговые инструкции**
1. Создайте новую `Workbook` или откройте существующую.
2. Получите целевой `Worksheet` из `workbook.GetWorksheets().Get(0]`.
3. Считайте файл изображения с диска в массив байтов `Vector<uint8_t>`.
4. Получите ссылку на целевую ячейку — либо через `worksheet.GetCells().Get("C6"]`, либо через `worksheet.GetCells().Get(5, 2]`.
5. Присвойте массив байтов свойству `EmbeddedImage` ячейки.
6. По желанию задайте высоту целевой строки и ширину целевого столбца, чтобы встроенное изображение отображалось более крупно.
7. Сохраните рабочую книгу на диск в виде файла `.xlsx`.
Ниже приведен полный пример реализации этого подхода.

```cpp
#include "Aspose.Cells.h"
#include <vector>
#include <fstream>
#include <iterator>
using namespace Aspose::Cells;
int main() {
    Aspose::Cells::Startup();
    Workbook wb;
    Worksheet worksheet = wb.GetWorksheets().Get(0);
    Cell cell = worksheet.GetCells().Get(u"C6");
    // Прочитать файл изображения в массив байтов
    std::ifstream file("logo.png", std::ios::binary);
    std::vector<uint8_t> stdImageData((std::istreambuf_iterator<char>(file)), std::istreambuf_iterator<char>());
    file.close();
    // Преобразовать std::vector в Aspose::Cells::Vector с помощью конструктора, принимающего указатель и размер
    Vector<uint8_t> imageData(stdImageData.data(), (int32_t)stdImageData.size());
    // Встроить изображение непосредственно в ячейку
    cell.SetEmbeddedImage(imageData);
    // При необходимости отрегулировать высоту строки и ширину столбца, чтобы встроенное изображение было более заметным
    worksheet.GetCells().SetColumnWidth(2, 30);   // Столбец C (индекс 2)
    worksheet.GetCells().SetRowHeight(5, 100);    // Строка 6 (индекс 5)
    // Сохранить полученную книгу в файл .xlsx
    wb.Save(u"output.xlsx", SaveFormat::Xlsx);
    Aspose::Cells::Cleanup();
    return 0;
}
```

## **Выбор подходящего подхода**
Оба подхода обеспечивают размещение изображения в границах одной ячейки, но различаются способом его хранения и поведением:
- **Используйте плавающее изображение (подход 1), когда:**
  - Требуется более точный контроль над размещением, порядком наложения или выравниванием относительно других графических объектов.
  - Изображение должно вести себя как фигура, которую можно выделить, изменить порядок её отображения или сгруппировать с другими фигурами.
  - Необходима совместимость с устаревшим кодом, в котором уже используется `PictureCollection`.
  - Координаты привязки необходимо вычислять динамически с учётом макета рабочего листа.
- **Используйте встроенное изображение (подход 2), когда:**
  - Нужна максимально простая вставка изображения в ячейку.
  - Изображение должно перемещаться вместе с ячейкой, как любое другое её содержимое.
