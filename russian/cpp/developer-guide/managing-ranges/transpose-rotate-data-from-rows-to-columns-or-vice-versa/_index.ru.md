{{% alert color="primary" %}}
Aspose.Cells for C++ поддерживает транспонирование (поворот) данных, при котором строки становятся столбцами, а столбцы — строками, тремя разными способами. Первый подход использует метод `Range.Transpose()`, изменяющий данные на месте, и работает во всех версиях Excel. Второй подход использует `Cell.SetDynamicArrayFormula()` для записи современной формулы динамического массива `=TRANSPOSE(...)`, которая автоматически раскрывается в Excel 365 или Excel 2021. Третий подход использует `Cell.SetArrayFormula()` для записи классической формулы массива Ctrl+Shift+Enter (CSE), совместимой с более старыми версиями Excel. В статье каждый подход рассматривается с пошаговыми инструкциями и полными примерами кода.
{{% /alert %}}

## **Введение**
Транспонирование диапазона означает его поворот таким образом, чтобы строка стала столбцом, а столбец — строкой; иными словами, данные отражаются относительно главной диагонали. В Microsoft Excel эту операцию выполняет функция рабочего листа `TRANSPOSE`, а концептуальное описание приведено в статье [https://support.microsoft.com/en-us/excel/functions/transpose-function](https://support.microsoft.com/en-us/excel/functions/transpose-function). Этот подход можно программно применить к диапазону ячеек, что полезно во многих сценариях бизнес-аналитики и отчетности.
- Изменение ориентации квартальных или годовых отчетов о продажах, в которых кварталы обычно располагаются поперек страницы, а регионы — вдоль страницы, или наоборот.
- Изменение ориентации осей на панелях мониторинга или диаграммах, чтобы временной ряд располагался вдоль страницы, а не поперек.
- Изменение структуры данных, импортированных из внешних систем, для соответствия макету, ожидаемому последующим анализом или шаблонам отчетности.
Чтобы сделать последующие примеры наглядными, в каждом из них используется небольшая таблица продаж по регионам и кварталам. В примере рабочей книге эта таблица занимает диапазон **A1:D5**, причем **A1** оставлен пустым в качестве левого верхнего угла, **B1:D1** содержит заголовки регионов, а **A2:A5** — заголовки кварталов.
| Регион           | Европа      | Азия        | Северная Америка |
|------------------|--------------|-------------|-------------------|
| 1-й квартал      | 21704714     | 8774099     | 12094215          |
| 2-й квартал      | 17987034     | 12214447    | 10873099          |
| 3-й квартал      | 19485029     | 14356879    | 15689543          |
| 4-й квартал      | 22567894     | 15763492    | 17456723          |
Затем в статье представлены три различных способа транспонирования этих данных с помощью Aspose.Cells for C++, каждый из которых подходит для определенной версии Excel и сценария использования.

## **Подход 1 — Транспонирование диапазона на месте (Range.Transpose)**
Этот подход подходит, если необходимо транспонировать данные без использования функции рабочего листа `TRANSPOSE`. Он работает в **каждой версии Excel** и не зависит от динамических массивов, поэтому является наиболее безопасным вариантом с точки зрения совместимости. Подход идеален, если требуется только получить транспонированный результат и не нужно сохранять исходную формулу `TRANSPOSE` в рабочей книге.

### **Используемый API**
`Range.Transpose()` — экземплярный метод класса `Aspose.Cells.Range`. Его вызов изменяет диапазон на месте, меняя местами строки и столбцы, поэтому строка становится столбцом, а столбец — строкой. Метод напрямую изменяет базовые ячейки, не записывая формулу.

### **Шаги**
1. Откройте исходную рабочую книгу, создав `Workbook(srcFile, LoadOptions(LoadFormat::Xlsx))`, где `LoadOptions` настроен на формат `.xlsx`.
2. Получите первый рабочий лист из рабочей книги с помощью `workbook.GetWorksheets().Get(0)`.
3. Получите доступ к коллекции ячеек рабочего листа через `worksheet.GetCells()`.
4. Создайте исходный диапазон, охватывающий **A1:D5**, вызвав `cells.CreateRange(u"A1:D5")`.
5. Вызовите `source.Transpose()`, чтобы повернуть диапазон на месте, поменяв строки и столбцы местами.
6. Сохраните рабочую книгу с помощью `workbook.Save(outputFile)`.

```cpp
#include "Aspose.Cells.h"
using namespace Aspose::Cells;
int main() {
    Aspose::Cells::Startup();
    U16String srcFile(u"source.xlsx");
    U16String outputFile(u"transposed.xlsx");
    LoadOptions loadOptions(LoadFormat::Xlsx);
    Workbook workbook(srcFile, loadOptions);
    Worksheet worksheet = workbook.GetWorksheets().Get(0);
    Cells cells = worksheet.GetCells();
    Range source = cells.CreateRange(u"A1:D5");
    source.Transpose();
    workbook.Save(outputFile);
    Aspose::Cells::Cleanup();
    return 0;
}
```

## **Подход 2 — Транспонирование с помощью формулы динамического массива (Excel 365 / 2021)**
Этот подход подходит, если необходимо сохранить формулу `=TRANSPOSE(A1:D5)` в виде активной формулы в результирующей рабочей книге, чтобы результат автоматически обновлялся при изменении исходных данных, при этом целевой файл Excel будет открываться в **Excel 365 / Excel 2021 или более поздней версии**, где поддерживаются динамические массивы и оператор раскрытия.

### **Используемый API**
`Cell.SetDynamicArrayFormula(const char* formula, FormulaParseOptions options, bool calculateValue)` — метод класса `Aspose.Cells.Cell`, который задает формулу ячейки как **формулу динамического массива**. Excel вычисляет формулу один раз и автоматически раскрывает результат в окружающие ячейки. Третий параметр при значении `true` указывает Aspose.Cells также вычислить результирующие значения при записи.

### **Шаги**
1. Загрузите исходную рабочую книгу, создав `Workbook(srcFile, LoadOptions(LoadFormat::Xlsx))`.
2. Получите первый рабочий лист через `workbook.GetWorksheets().Get(0)` и получите доступ к его коллекции `Cells` через `worksheet.GetCells()`.
3. Задайте формулу динамического массива в ячейке **A6**, расположенной непосредственно под исходным диапазоном, вызвав `cells.Get(u"A6").SetDynamicArrayFormula(u"=TRANSPOSE(A1:D5)", nullptr, true)`.
4. Аргумент `nullptr` передает значения `FormulaParseOptions` по умолчанию, а третий аргумент `true` указывает Aspose.Cells считать формулу динамическим массивом и вычислить ее, чтобы раскрытые значения были записаны в рабочую книгу.
5. Сохраните рабочую книгу с помощью `workbook.Save(outputFile)`.
Ячейка **A6** содержит формулу `=TRANSPOSE(A1:D5)`, а Excel автоматически раскрывает результат в диапазон **A6:D10** — блок размером 5 строк на 4 столбца, равный транспонированным данным.

{{% alert color="primary" %}}
Этот подход работает **только в Excel 365 / 2021 или более поздней версии**. Более старые версии Excel не выполняют корректное раскрытие формул динамических массивов.
{{% /alert %}}

```cpp
#include "Aspose.Cells.h"
#include <string>
using namespace Aspose::Cells;
int main() {
    Aspose::Cells::Startup();
    std::string srcFile = "source.xlsx";
    std::string outFile = "output_transpose_dynamic.xlsx";
    LoadOptions loadOptions(LoadFormat::Xlsx);
    Workbook workbook(U16String(srcFile.c_str()), loadOptions);
    Worksheet worksheet = workbook.GetWorksheets().Get(0);
    Cells cells = worksheet.GetCells();
    Cell cell = cells.Get(u"A6");
    FormulaParseOptions options;
    cell.SetDynamicArrayFormula(U16String("=TRANSPOSE(A1:D5)"), options, true);
    workbook.Save(U16String(outFile.c_str()), SaveFormat::Xlsx);
    Aspose::Cells::Cleanup();
    return 0;
}
```

## **Подход 3 — Транспонирование с помощью классической формулы массива (CSE)**
Этот подход подходит, если необходимо сохранить формулу `TRANSPOSE` в рабочей книге, но целевой файл Excel может открываться в **более старых версиях Excel (до 2021 года, включая 2019, 2016, 2013 и т. д.)**, где раскрытие динамических массивов не поддерживается. Классическая формула массива CSE (Ctrl+Shift+Enter) является совместимой со старыми версиями альтернативой, которую могут вычислять все версии Excel.

### **Используемый API**
`Cell.SetArrayFormula(const char* arrayFormula, int nRows, int nColumns)` — метод класса `Aspose.Cells.Cell`, который присваивает **классическую формулу массива (CSE)** опорной ячейке и задает размеры результирующего массива. Aspose.Cells записывает маркер формулы массива для нескольких ячеек, поэтому Excel вычисляет формулу как единое выражение массива, заполняющее заданный диапазон.

### **Шаги**
1. Получите первый рабочий лист через `workbook.GetWorksheets().Get(0)` и получите доступ к его коллекции `Cells` через `worksheet.GetCells()`.
2. Вызовите `cells.Get(u"A6").SetArrayFormula(u"=TRANSPOSE(A1:D5)", 4, 5)`. Второй аргумент `4` задает количество строк результирующего массива, а третий аргумент `5` — количество столбцов.
3. Сохраните рабочую книгу с помощью `workbook.Save(outputFile)`.
Ячейка **A6** является опорной ячейкой формулы массива, а вычисленный массив занимает 4 строки и 5 столбцов, начиная с A6, что соответствует транспонированным размерам исходного диапазона A1:D5. Excel записывает единый маркер формулы массива по всему результирующему диапазону, поэтому более старые версии Excel корректно вычисляют формулу.

{{% alert color="primary" %}}
Формулы массива CSE — классический способ вычисления выражения `TRANSPOSE` в Excel, и этот подход совместим со всеми версиями Excel.
{{% /alert %}}

```cpp
#include "Aspose.Cells.h"
#include <string>
using namespace Aspose::Cells;
int main() {
    Aspose::Cells::Startup();
    // Загрузить исходную книгу с помощью LoadOptions для xlsx
    std::string srcFile = "source.xlsx";
    Workbook workbook(U16String(srcFile.c_str()), LoadOptions(LoadFormat::Xlsx));
    // Получить доступ к первому листу и его коллекции Cells
    Worksheet worksheet = workbook.GetWorksheets().Get(0);
    Cells cells = worksheet.GetCells();
    // Установить классическую формулу массива CSE в ячейке A6.
    // Формула =TRANSPOSE(A1:D5) транспонирует исходный диапазон из 5 строк и 4 столбцов
    // в массив из 4 строк и 5 столбцов. Второй аргумент (4) задаёт количество строк,
    // а третий аргумент (5) — количество столбцов результирующего массива.
    // Aspose.Cells записывает маркер формулы массива CSE, чтобы Excel вычислял её как
    // единую многоячеечную формулу массива, совместимую со старыми версиями Excel
    // (2019, 2016, 2013 и т. д.), которые не поддерживают динамическое распространение массивов.
    cells.Get(u"A6").SetArrayFormula(u"=TRANSPOSE(A1:D5)", 4, 5);
    // Сохранить книгу, чтобы маркер формулы массива был записан в файл
    workbook.Save(u"output.xlsx");
    Aspose::Cells::Cleanup();
    return 0;
}
```

## **Сравнение — Когда использовать каждый подход**
| Подход | API / Метод | Версия Excel | Сохранена исходная формула? | Выходной диапазон |
|--------|-------------|---------------|----------------------------|------------------|
| Подход 1 — Транспонирование на месте | `Range.Transpose()` | Все версии Excel | Нет (только значения) | Начальный диапазон, 5×4 |
| Подход 2 — Формула динамического массива | `Cell.SetDynamicArrayFormula` | Excel 365 / 2021+ | Да (динамическое раскрытие) | Раскрывается от опорной ячейки |
| Подход 3 — Классическая формула массива (CSE) | `Cell.SetArrayFormula` | Все версии Excel | Да (формула массива для нескольких ячеек) | Явный размер, 4×5 |
Используйте **Подход 1**, если необходимо выполнить быстрое преобразование, совместимое со всеми версиями, и записать в файл только транспонированные значения. Используйте **Подход 2**, если гарантированно используется современная версия Excel и формула должна оставаться активной и обновляться при изменении исходных данных. Используйте **Подход 3**, если необходима максимальная совместимость при сохранении формулы во всех версиях Excel, включая старые выпуски, не поддерживающие динамические массивы.
