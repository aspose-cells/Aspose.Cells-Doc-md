{{% alert color="primary" %}}
Aspose.Cells for C++ поддерживает транспонирование (поворот) данных так, что строки становятся столбцами, а столбцы — строками, тремя различными способами. Первый подход использует метод `Range.Transpose()` на месте и работает в любой версии Excel, тогда как второй применяет `Cell.SetDynamicArrayFormula()` для записи современной формулы динамического массива `=TRANSPOSE(...)`, которая автоматически «разливается» в Excel 365 или Excel 2021. Третий подход использует `Cell.SetArrayFormula()` для записи классической формулы массива Ctrl+Shift+Enter (CSE), совместимой со старыми версиями Excel. В этой статье каждый подход рассматривается с пошаговыми инструкциями и полными примерами кода.
{{% /alert %}}

## **Введение**
Транспонирование диапазона означает его поворот так, чтобы то, что было строкой, стало столбцом, а то, что было столбцом, стало строкой, фактически отражая данные относительно их главной диагонали. В Microsoft Excel эту операцию выполняет функция рабочего листа `TRANSPOSE`, концептуальное описание которой задокументировано по адресу [https://support.microsoft.com/en-us/excel/functions/transpose-function](https://support.microsoft.com/en-us/excel/functions/transpose-function). Эту концепцию можно применять программно к диапазону ячеек, что полезно во многих бизнес-сценариях и сценариях отчётности.
- Изменение ориентации квартальных или годовых отчётов о продажах, где кварталы обычно идут по странице, а регионы — вниз по странице, или наоборот.
- Изменение ориентации осей на панелях мониторинга или в диаграммах, чтобы временной ряд шёл вниз по странице, а не поперёк.
- Изменение формы данных, импортированных из внешних систем, чтобы они соответствовали макету, ожидаемому нижестоящими шаблонами анализа или отчётности.
Чтобы сделать остальную часть статьи конкретной, во всех примерах используется следующая небольшая таблица продаж по регионам и кварталам. В примере рабочей книги эта таблица занимает диапазон **A1:D5**, при этом ячейка **A1** оставлена пустой как верхний левый угол, ячейки **B1:D1** содержат заголовки регионов, а ячейки **A2:A5** — заголовки кварталов.
| Регион           | Европа    | Азия      | Северная Америка |
|------------------|-----------|-----------|------------------|
| Квартал 1        | 21704714  | 8774099   | 12094215         |
| Квартал 2        | 17987034  | 12214447  | 10873099         |
| Квартал 3        | 19485029  | 14356879  | 15689543         |
| Квартал 4        | 22567894  | 15763492  | 17456723         |
Далее в статье представлены три различных способа транспонирования этих данных с помощью Aspose.Cells for C++, каждый из которых подходит для определённой версии Excel и варианта использования.

## **Подход 1 — Транспонирование диапазона на месте (Range.Transpose)**
Используйте этот подход, когда требуется транспонировать данные без обращения к функции рабочего листа `TRANSPOSE`. Он работает в **любой версии Excel** и не зависит от динамических массивов, что делает его самым безопасным кросс-версионным вариантом. Он идеально подходит, когда нужен только окончательный транспонированный результат и нет необходимости сохранять исходную формулу `TRANSPOSE` в рабочей книге.

### **Используемый API**
`Range.Transpose()` — это метод экземпляра класса `Aspose.Cells.Range`. При его вызове диапазон переворачивается на месте путём обмена его строк и столбцов: то, что было строкой, становится столбцом, а то, что было столбцом, становится строкой. Метод изменяет базовые ячейки напрямую, не записывая формулу.

### **Шаги**
1. Откройте исходную рабочую книгу с `LoadOptions`, установленными в формат `.xlsx`, путём создания `Workbook(srcFile, LoadOptions(LoadFormat::Xlsx))`.
2. Получите первый рабочий лист из рабочей книги с помощью `workbook.GetWorksheets().Get(0)`.
3. Получите доступ к коллекции ячеек рабочего листа через `worksheet.GetCells()`.
4. Создайте исходный диапазон, охватывающий **A1:D5**, вызвав `cells.CreateRange(u"A1:D5")`.
5. Вызовите `source.Transpose()`, чтобы повернуть диапазон на месте, поменяв местами строки и столбцы.
6. Сохраните рабочую книгу с помощью `workbook.Save(outputFile)`.

```cpp
#include "Aspose.Cells.h"
using namespace Aspose::Cells;
int main() {
    Aspose::Cells::Startup();
    U16String srcFile(u"source.xlsx");
    U16String outputFile(u"transposed.xlsx");
    LoadOptions loadOptions(LoadFormat::Xlsx);
    Workbook workbook(srcFile, loadOptions);
    Worksheet worksheet = workbook.GetWorksheets().Get(0);
    Cells cells = worksheet.GetCells();
    Range source = cells.CreateRange(u"A1:D5");
    source.Transpose();
    workbook.Save(outputFile);
    Aspose::Cells::Cleanup();
    return 0;
}
```

## **Подход 2 — Транспонирование с помощью формулы динамического массива (Excel 365 / 2021)**
Используйте этот подход, когда требуется сохранить формулу `=TRANSPOSE(A1:D5)` как «живую» формулу в выходной рабочей книге, чтобы результат автоматически обновлялся при изменении исходных данных, а целевой файл Excel будет открываться в **Excel 365 / Excel 2021 или более поздней версии**, где поддерживаются динамические массивы и оператор разлития.

### **Используемый API**
`Cell.SetDynamicArrayFormula(const char* formula, FormulaParseOptions options, bool calculateValue)` — это метод `Aspose.Cells.Cell`, который задаёт формулу ячейки как **формулу динамического массива**. Excel вычисляет формулу один раз и автоматически разливает результат в окружающие ячейки. Третий параметр, установленный в `true`, указывает Aspose.Cells также вычислить результирующие значения во время записи.

### **Шаги**
1. Загрузите исходную рабочую книгу, сконструировав `Workbook(srcFile, LoadOptions(LoadFormat::Xlsx))`.
2. Получите первый рабочий лист через `workbook.GetWorksheets().Get(0)` и получите доступ к его коллекции `Cells` через `worksheet.GetCells()`.
3. Поместите формулу динамического массива в ячейку **A6**, прямо под исходным диапазоном, вызвав `cells.Get(u"A6").SetDynamicArrayFormula(u"=TRANSPOSE(A1:D5)", nullptr, true)`.
4. Аргумент `nullptr` передаёт значения `FormulaParseOptions` по умолчанию, а третий аргумент `true` указывает Aspose.Cells обрабатывать формулу как динамический массив и вычислить её, чтобы разлитые значения были записаны в рабочую книгу.
5. Сохраните рабочую книгу с помощью `workbook.Save(outputFile)`.
Ячейка **A6** содержит формулу `=TRANSPOSE(A1:D5)`, и Excel автоматически разливает результат в область **A6:D10** — блок 5 строк на 4 столбца, равный транспонированным данным.

{{% alert color="primary" %}}
Этот подход работает **только в Excel 365 / 2021 или более поздней версии**. Более старые версии Excel не смогут корректно разливать формулы динамического массива.
{{% /alert %}}

```cpp
#include "Aspose.Cells.h"
#include <string>
using namespace Aspose::Cells;
int main() {
    Aspose::Cells::Startup();
    std::string srcFile = "source.xlsx";
    std::string outFile = "output_transpose_dynamic.xlsx";
    LoadOptions loadOptions(LoadFormat::Xlsx);
    Workbook workbook(U16String(srcFile.c_str()), loadOptions);
    Worksheet worksheet = workbook.GetWorksheets().Get(0);
    Cells cells = worksheet.GetCells();
    Cell cell = cells.Get(u"A6");
    FormulaParseOptions options;
    cell.SetDynamicArrayFormula(U16String("=TRANSPOSE(A1:D5)"), options, true);
    workbook.Save(U16String(outFile.c_str()), SaveFormat::Xlsx);
    Aspose::Cells::Cleanup();
    return 0;
}
```

## **Подход 3 — Транспонирование с помощью классической формулы массива (CSE)**
Используйте этот подход, когда требуется сохранить формулу `TRANSPOSE` в рабочей книге, но целевой файл Excel может быть открыт в **более старых версиях Excel (до 2021, включая 2019, 2016, 2013 и т. д.)**, где разлитие динамического массива не поддерживается. Классическая формула массива CSE (Ctrl+Shift+Enter) — это альтернатива, совместимая с предыдущими версиями, которую могут вычислить все версии Excel.

### **Используемый API**
`Cell.SetArrayFormula(const char* arrayFormula, int nRows, int nColumns)` — это метод `Aspose.Cells.Cell`, который присваивает **классическую формулу массива (CSE)** ячейке-привязке и объявляет размерности результирующего массива. Aspose.Cells записывает маркер многоячеечной формулы массива, чтобы Excel вычислял формулу как одно массивное выражение, заполняющее объявленный диапазон.

### **Шаги**
1. Загрузите исходную рабочую книгу, сконструировав `Workbook(srcFile, LoadOptions(LoadFormat::Xlsx))`.
2. Получите первый рабочий лист через `workbook.GetWorksheets().Get(0)` и получите доступ к его коллекции `Cells` через `worksheet.GetCells()`.
3. Вызовите `cells.Get(u"A6").SetArrayFormula(u"=TRANSPOSE(A1:D5)", 4, 5)`. Второй аргумент `4` — количество строк результирующего массива, а третий аргумент `5` — количество столбцов.
4. Сохраните рабочую книгу с помощью `workbook.Save(outputFile)`.
Ячейка **A6** является ячейкой-привязкой формулы массива, и вычисленный массив занимает 4 строки на 5 столбцов, начиная с A6, что соответствует транспонированным размерностям источника A1:D5. Excel записывает единый маркер формулы массива по всему результирующему диапазону, чтобы более старые версии Excel корректно её вычисляли.

{{% alert color="primary" %}}
Формулы массива CSE — это классический способ Excel для вычисления выражения `TRANSPOSE`, и этот подход универсально совместим со всеми версиями Excel.
{{% /alert %}}

```cpp
#include "Aspose.Cells.h"
#include <string>
using namespace Aspose::Cells;
int main() {
    Aspose::Cells::Startup();
    // Загружаем исходную книгу с параметрами загрузки xlsx
    std::string srcFile = "source.xlsx";
    Workbook workbook(U16String(srcFile.c_str()), LoadOptions(LoadFormat::Xlsx));
    // Получаем доступ к первому рабочему листу и его коллекции ячеек
    Worksheet worksheet = workbook.GetWorksheets().Get(0);
    Cells cells = worksheet.GetCells();
    // Устанавливаем классическую CSE формулу массива на ячейке A6.
    // Формула =TRANSPOSE(A1:D5) транспонирует исходный диапазон 5 строк x 4 столбца
    // в массив 4 строки x 5 столбцов. Второй аргумент (4) — это количество строк,
    // а третий аргумент (5) — количество столбцов результирующего массива.
    // Aspose.Cells записывает маркер CSE формулы массива, чтобы Excel вычислял её
    // как одну многоячеечную формулу массива, совместимую со старыми версиями Excel
    // (2019, 2016, 2013 и т.д.), которые не поддерживают динамическое распыление массива.
    cells.Get(u"A6").SetArrayFormula(u"=TRANSPOSE(A1:D5)", 4, 5);
    // Сохраняем книгу, чтобы маркер формулы массива был сохранён
    workbook.Save(u"output.xlsx");
    Aspose::Cells::Cleanup();
    return 0;
}
```

## **Сравнение — Когда использовать каждый подход**
| Подход | API / Метод | Версия Excel | Сохранена ли исходная формула? | Выходной диапазон |
|--------|-------------|--------------|-------------------------------|------------------|
| Подход 1 — Транспонирование на месте | `Range.Transpose()` | Все версии Excel | Нет (только значения) | Начальный диапазон, 5×4 |
| Подход 2 — Формула динамического массива | `Cell.SetDynamicArrayFormula` | Excel 365 / 2021+ | Да (разливается динамически) | Разливается из ячейки-привязки |
| Подход 3 — Классическая формула массива (CSE) | `Cell.SetArrayFormula` | Все версии Excel | Да (многоячеечная формула массива) | Явный размер, 4×5 |
Используйте **Подход 1**, когда требуется быстрое кросс-версионное преобразование и нужны только транспонированные значения, записанные в файл. Используйте **Подход 2**, когда гарантирован современный Excel и требуется, чтобы формула оставалась «живой» и обновлялась при изменении источника. Используйте **Подход 3**, когда требуется максимальная совместимость с сохранённой формулой во всех версиях Excel, включая старые выпуски, которые не поддерживают динамические массивы.
